# 不确定边界：9 张用户输入（review v1）

所有输入均以原始 JPEG 字节复制到 `sources/`；在主预览和 atlas 中以不裁切、原方向、原比例、原顺序显示。JPEG 没有透明 alpha。本草案不把黑色像素推断为透明背景、石块外轮廓、内部裂缝或 shared seam。

| 输入 | 黑底/边缘是否可可靠判定为石块外轮廓 | 未处理策略 |
| --- | --- | --- |
| 1 | 否。黑色区与石块边缘的归属没有 alpha 或标注。 | 保留完整不透明矩形；不裁切、不建 seam。 |
| 2 | 否。小尺寸输入没有可验证的边界标注。 | 保留完整不透明矩形；不裁切、不建 seam。 |
| 3 | 否。黑色边缘可能是背景也可能属于图像内容。 | 保留完整不透明矩形；不裁切、不建 seam。 |
| 4 | 否。长图边缘及黑色区无法判定。 | 保留完整不透明矩形；不裁切、不建 seam。 |
| 5 | 否。黑色底/边界没有人工确认。 | 保留完整不透明矩形；不裁切、不建 seam。 |
| 6 | 否。即使与其他输入视觉相近，仍是独立输入且边界未确认。 | 保留为独立第 6 项；不裁切、不建 seam。 |
| 7 | 否。竖向图的黑色边缘未提供轮廓真值。 | 保留完整不透明矩形；不裁切、不建 seam。 |
| 8 | 否。黑色区不具备可验证的透明含义。 | 保留完整不透明矩形；不裁切、不建 seam。 |
| 9 | 否。即使与其他输入视觉相近，仍是独立输入且边界未确认。 | 保留为独立第 9 项；不裁切、不建 seam。 |

在用户逐图确认石块 alpha/外轮廓及相接关系前，不能构造 shared seam；否则会把未确认黑色底误作苔藓、石块或新造边界。
