# 装备强化材料｜怪物掉落与结算规则确认稿

> 状态：用户已逐项确认；自 2026-09-24 起作为 [`角色等级、装备成长、强化与材料系统 V1`](../docs/character-equipment-progression-v1.md) 的权威材料附件。
>
> 文档性质：正式实现与验收依据；它仍不是“已经实现”的证明。
> 关联：本稿补充《装备强化系统：DNF 国服 60 级早期参考与项目适配审阅稿》第6节的材料来源，不修改已确认的强化成本、成功率或失败结果。

## 1. 核心边界

- 强化只受玩家当前拥有的金币和材料限制，不增加“必须战斗几局”、“必须通过几关”或“必须到达某层”的额外前置。
- 材料不足时不能发起强化；材料足够时可发起强化。
- 无论强化成功、降级、回到 +1 或永久碎装，本次金币与材料都正常消耗，不返还。
- 怪物直接掉落是材料来源之一；玩家主动分解装备仍是另一来源。
- 关卡结算不自动分解装备。
- 技能残页不用于装备强化，不进入普通怪物强化材料池；继续由技能相关奖励和装备分解产生。

## 2. 本局临时材料账本

- 合格怪物死亡时显示对应材料的掉落特效和名称。
- 材料无需玩家手动拾取，怪物死亡后立即记入“本局临时材料账本”。
- 怪物掉落不直接写入永久仓库；只在本局产生法定结果时结算。
- 通关成功：本局临时账本材料100%转入永久材料库。
- 正常战斗失败：每种本局新材料分别保留30%，逐项向下取整。
- 主动退出、强制退出、断网或异常中断：本局新材料全部丢失。
- 进入关卡前已经拥有的材料在任何结果下都不受影响。
- 未击杀的精英或 Boss 不产生其对应材料。

## 3. 确定性与反刷取

- 每个合格怪物实例只进行一次材料判定。
- 相同关卡种子和相同怪物实例必须得到相同结果，不使用无法复现的每帧随机。
- 只有关卡生成预算中的原始怪物可产生材料。
- 怪物召唤物、分裂后生成物、无限刷新的附属单位不产生材料，防止无限刷材料。
- 腐蚀史莱姆及其分裂体均不产生强化材料；继续沿用低蓝晶、低装备收益定位。

## 4. 难度倍率

| 难度 | 材料倍率 |
| --- | ---: |
| 普通 | ×1.00 |
| 困难 | ×1.25 |
| 地狱 | ×1.60 |
| 折磨 | ×2.10 |

应用规则：

- 普通怪、精英和 Boss 的概率掉落均由难度倍率放大概率，不同时再放大该次掉落数量。
- 难度只增加概率或数量中明确的一个维度，不双重放大。
- 难度倍率不让低阶怪物越级产生传承余烬或传奇星核。
- Boss 概率材料的最终概率上陕为95%。
- 所有关卡 Boss 固定产生本关印记×1，不受难度倍率影响。
- 传奇星核使用第10节的独立概率表，不使用本节倍率。

## 5. 普通怪与精英通用规则

### 普通怪基准

- 普通标准怪：普通难度基础概率8%，成功时掉落绑定材料×1。
- 高威胁、重甲或施法怪：普通难度基础概率12%，成功时掉落绑定材料×1。
- 小型群体、分裂型等数量怪：普通难度基础概率4%，成功时掉落绑定材料×1。

### 精英基准

| 难度 | 主要材料概率 | 次级材料概率 |
| --- | ---: | ---: |
| 普通 | 40% | 15% |
| 困难 | 50% | 18.75% |
| 地狱 | 64% | 24% |
| 折磨 | 84% | 31.5% |

- 主要与次级材料独立判定；精英不存在材料必掉。
- 铁屑、契约灰烬、精炼铁片、蓝晶粉尘、流派碎片作为主要材料判定成功时掉落×2；作为次级材料时掉落×1。
- 流派符文、传承余烬无论作为主要还是次级材料，每次判定成功最多掉落×1。
- 本关印记与传奇星核不进入精英掉落池。

## 10. 传奇星核

- 传奇星核不进入普通怪或精英掉落池。
- 除传奇装备主动分解外，只有契约巨龙和未来同级终局 Boss 可直接掉落。
- 每次合格 Boss 击杀只进行一次判定，成功时掉落×1，单次最多直接掉落1个。

| 难度 | 传奇星核概率 |
| --- | ---: |
| 普通 | 2% |
| 困难 | 5% |
| 地狱 | 12% |
| 折磨 | 25% |

- 传奇星核不再使用第4节的难度倍率。
- 第10关专项功能天赋“传奇星核收益 +15%”放大相对概率，不增加15个百分点；例如折磨难度为 `25% × 1.15 = 28.75%`。
- 其他明确写明“Boss 专项材料掉落提高”的天赋同样按相对概率放大；传奇星核最终掉落概率上限为50%。

## 11. 关卡材料功能天赋调整

- 第6关原“技能残页收益 +15%”改为该关怪物直接掉落的“流派符文收益 +15%”。
- 第7关原“流派符文收益 +15%”改为矿坑基础材料“铁屑、精炼铁片、蓝晶粉尘收益均 +15%”。
- 技能残页继续由技能相关奖励和装备分解产生，不再绑定某一关怪物。
- 第8关“本关印记收益 +15%”使用独立确定性余量：每次击杀第8关 Boss 获得基础印记×1，同时累计0.15；余量达到1.00时额外获得印记×1并扣除1.00。
- 第8关印记余量跨局、跨难度保存，但只属于第8关印记；未击杀 Boss 不累计余量。
- 第8关额外印记与基础印记都先进入本局临时材料账本，再按成功、失败或异常中断规则结算。

### 11.1 材料天赋与结算顺序

- 概率材料先按“基础概率 × 难度倍率 × 合法天赋相对倍率”完成一次掉落判定。
- 固定数量奖励按本稿规定结算；需要长期保留小数收益的项目使用确定性余量累计。
- 实际掉落先进入本局临时材料账本，再按成功100%、正常失败逐项30%向下取整、主动退出／强退／断网／异常中断0%处理。
- 废除“先执行失败30%保留，再应用难度或天赋加成”的旧顺序。

## 12. 已确认结论

本稿已完整确认：

1. 怪物材料自动记入本局临时账本，不需手动拾取；
2. 通关全额带回，正常失败保留30%，主动退出、强退、断网或异常中断为0；
3. 普通怪、精英、Boss、难度倍率和十关怪物材料绑定均按本稿执行；
4. 精英不存在材料必掉，Boss 除本关印记外也不存在其他必掉材料；
5. 传奇星核仅由传奇分解、契约巨龙和未来同级终局 Boss 产生；
6. 第6、7、8、10关材料天赋的特殊处理按本稿执行。

本附件已纳入正式权威文档；实现状态仍须由固定实现角色交付并经 C／D 独立验收后更新。
