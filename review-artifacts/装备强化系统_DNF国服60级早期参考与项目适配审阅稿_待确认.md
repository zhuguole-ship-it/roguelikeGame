## 1. 年代口径校正

DNF 国服不是 2000 年左右上线。国服于 2008 年进入公测，公测上限为 Lv.60；2011 年 6 月进入 Lv.70 时代。因此本次所说的“早期国服、最高等级 60 级”应锁定为约 2008～2011 年，而不是 2000 年前后。

## 2. 早期国服强化规则：历史事实

2008 年公开资料记录的规则为：

| 阶段 | 成功后 | 失败后 |
| --- | --- | --- |
| +1～+3 | 强化等级 +1 | 不会失败 |
| +4～+7 | 强化等级 +1 | 当前强化等级降低 1 级 |
| +8～+10 | 强化等级 +1 | 强化等级归零 |
| +11及以上 | 强化等级 +1 | 装备消失／分解 |

对应公开成功率为：

| 强化尝试 | 历史公开成功率 |
| --- | ---: |
| +0 → +1 | 100% |
| +1 → +2 | 100% |
| +2 → +3 | 100% |
| +3 → +4 | 95% |
| +4 → +5 | 90% |
| +5 → +6 | 80% |
| +6 → +7 | 75% |
| +7 → +8 | 62.1% |
| +8 → +9 | 53.7% |
| +9 → +10 | 41.4% |
| +10 → +11 | 33.9% |
| +11 → +12 | 28% |
| +12 → +13 | 20.7% |

2010 年国服资料进一步明确：从 +10 强化至 +11 时，失败会导致装备消失。2011 年玩家进行的 2347 次强化实验也观察到低强化稳定、中段降级／归零、高强化碎装的结构。

### 与原记忆的差异

原记忆：

- +1～+5 必定成功；
- +5～+10 失败回到 +1；
- +11、+12、+13 分别约为属性 2、3、4 倍。

历史资料更接近：

- 早期资料明确安全的是 +1～+3，不是 +1～+5；
- +4～+7 失败降 1 级；
- +8～+10 失败归零，而不是回到 +1；
- +11 起失败碎装；
- 高强化强化的是武器无视防御攻击、装备防御等“强化追加值”，没有证据表明整件装备的全部属性、词条、单件效果和套装效果一起翻 2／3／4 倍。

2011 年实验中的防具强化追加减伤从 +10 的 0.8%，上升到 +11 的 1.6%、+12 的 2.4%、+13 的 3.6%。它支持“+11 后强化收益陡增”，但不支持把整件装备全部数值直接乘 2／3／4。

## 3. 不建议原样照搬的原因

早期 DNF 的高强化损失建立在可交易市场、长期金币循环、大量重复装备和在线游戏经济上。本项目是以约 40 小时完整成长为目标的单机 Roguelike：

1. 原样采用 +3 后即可能失败，会让前期刚获得的装备过早产生挫败；
2. +8～+10 归零会重复消耗大量低价值操作时间；
3. 如果 +13 再把整件装备所有属性乘 4，多槽位叠加会击穿现有生命、护甲、攻速、移速和射程护栏；
4. 如果所有稀有度都能冲 +13，会削弱史诗、传承、传奇的长期价值；
5. +11～+13 碎装可以保留，但必须是可选的终局追求，不能成为通关普通主线的硬门槛。

因此建议保留早期 DNF 的风险曲线和情绪，但不照抄全部惩罚。

## 4. 本项目建议版强化阶段

### 4.1 强化上限

| 稀有度 | 强化上限 | 定位 |
| --- | ---: | --- |
| 破碎／普通 | +5 | 安全过渡装备 |
| 优质 | +7 | 允许体验降级风险 |
| 精良（蓝） | +10 | 允许中段高风险，不进入碎装区 |
| 史诗（紫） | +13 | 可进入终局碎装区 |
| 传承 | +13 | 可进入终局碎装区 |
| 传奇 | +13 | 可进入终局碎装区 |

这样特殊蓝装仍可强化至 +10，但不会因为尝试 +11 而把极稀有的 +1%～+50% 特殊蓝装直接摧毁。真正的碎装博弈只面向史诗、传承和传奇。

### 4.2 成功率与失败结果

| 当前 → 目标 | 成功率 | 失败结果 |
| --- | ---: | --- |
| +0 → +1 | 100% | 无失败 |
| +1 → +2 | 100% | 无失败 |
| +2 → +3 | 100% | 无失败 |
| +3 → +4 | 100% | 无失败 |
| +4 → +5 | 100% | 无失败 |
| +5 → +6 | 80% | 降至 +4 |
| +6 → +7 | 75% | 降至 +5 |
| +7 → +8 | 62.1% | 回到 +1 |
| +8 → +9 | 53.7% | 回到 +1 |
| +9 → +10 | 41.4% | 回到 +1 |
| +10 → +11 | 33.9% | 装备永久破碎，不返还任何材料 |
| +11 → +12 | 28% | 装备永久破碎，不返还任何材料 |
| +12 → +13 | 20.7% | 装备永久破碎，不返还任何材料 |

设计取舍：

- +1～+5 采用用户提出的安全区，保证前期强化可理解、可持续；
- +6～+7 使用早期 DNF 的失败降 1 级；
- +8～+10 采用“回到 +1”而不是历史上的归零，保留失败冲击但保留最低成果；
- +11 起完整保留早期国服的碎装风险；
- 成功率参考早期公开表，不引入现代 DNF 的安全强化、失败补正或保底条。

### 4.3 高强化的真实稀有程度

从一件已经 +10 的装备开始，且每次失败都会碎装：

| 最终目标 | 单段成功率 | 同一件 +10 装备连续到达概率 |
| --- | ---: | ---: |
| +11 | 33.9% | 33.9% |
| +12 | 28% | 9.49% |
| +13 | 20.7% | 1.96% |

所以即使 +12 → +13 的单段概率是 20.7%，一件 +10 装备连续冲到 +13 的总体概率也只有约 1.96%，已经属于极低概率。没有必要再把单段概率压到 5% 左右，否则对于无交易市场的单机项目会过度惩罚。

## 5. 强化属性增幅

### 5.1 强化只影响哪些属性

强化主属性：

- 固定攻击；
- 固定最大生命；
- 护甲。

稀有强化候选：

- 普通攻击速度；
- 移动速度；
- 攻击／技能射程。

强化永远不影响：

- 力量、智力、耐力、精神、敏捷及其百分比；
- 命中、技能释放急速；
- 生命／法力／体力百分比；
- 固定法力、固定体力；
- 装备等级、穿戴等级、词条品质；
- 单件说明、单件固定效果、协同散件效果；
- 套装件数和套装效果；
- 触发概率、内部 CD、持续时间；
- 特殊蓝装伤害类型与 +1%～+50% 数值。

### 5.2 +1～+10 的强化主属性

强化主属性使用掉落时初值计算，不逐级复利：

```text
1～+10强化追加值 = 掉落初值 × 8% × 强化等级
1～+10最终值 = 掉落初值 + 强化追加值
```

| 强化等级 | 强化追加值 | 最终强化主属性 |
| --- | ---: | ---: |
| +0 | 0% | 初值 ×1.00 |
| +1 | 初值的 8% | 初值 ×1.08 |
| +5 | 初值的 40% | 初值 ×1.40 |
| +8 | 初值的 64% | 初值 ×1.64 |
| +10 | 初值的 80% | 初值 ×1.80 |

### 5.3 +11～+13 的高强化跃升

“2倍／3倍／4倍”只放大 +10 时的强化追加值，不放大装备掉落初值，也不放大其他词条和装备机制：

| 强化等级 | 相对 +10 强化追加值 | 最终强化主属性 |
| --- | ---: | ---: |
| +10 | ×1 | 初值 + 80%初值 = 初值 ×1.80 |
| +11 | ×2 | 初值 + 160%初值 = 初值 ×2.60 |
| +12 | ×3 | 初值 + 240%初值 = 初值 ×3.40 |
| +13 | ×4 | 初值 + 320%初值 = 初值 ×4.20 |

这样保留了早期 DNF“高强追加值突然跃升”的体验，也避免把整件装备上的攻速、移速、射程、五维、套装效果和特殊蓝装增伤全部乘 4。

### 5.4 稀有强化保持独立

每次强化成功仍有 35% 概率触发一次稀有强化：

1. 只在装备已经拥有的普通攻击速度、移动速度、射程中随机选择一项；
2. 被选属性增加其掉落初值的 10%；
3. 没有候选属性时不触发，不临时新增词条；
4. 稀有强化不受 +11／+12／+13 的 2／3／4 倍追加值影响；
5. 属性最终仍受攻速、移速和射程的项目护栏限制。

每个强化等级只保存一条对应的稀有强化结果。失败降级或回到 +1 时，失去等级对应的稀有强化记录同步删除；重新升回该等级时重新判定，不能通过来回强化无限累积稀有属性。

### 6.3 装备等级成本系数

基础成本表以 Lv.60 装备为标准成本。低等级装备按以下公式计算：

```text
levelCostFactor = 0.5 + 0.5 × (itemLevel - 1) / 59
```

| 装备等级 | 成本系数 |
| --- | ---: |
| Lv.1 | ×0.50 |
| Lv.10 | ×0.58 |
| Lv.20 | ×0.66 |
| Lv.30 | ×0.75 |
| Lv.40 | ×0.83 |
| Lv.50 | ×0.92 |
| Lv.60 | ×1.00 |

### 6.4 稀有度成本系数

| 稀有度 | 成本系数 |
| --- | ---: |
| 破碎 | ×0.75 |
| 普通 | ×0.80 |
| 优质 | ×0.90 |
| 精良 | ×1.00 |
| 史诗 | ×1.15 |
| 传承 | ×1.30 |
| 传奇 | ×1.50 |

### 6.5 最终成本公式

```text
finalUpgradeCost = ceil(
  baseUpgradeCost
  × levelCostFactor
  × rarityCostFactor
  × talentDiscountFactor
)
```

每种基础成本不为零的材料最终至少消耗 1 个。金币与每一种材料分别计算并向上取整。

### 6.6 功能天赋「强化基础」

| 天赋等级 | 强化金币与材料消耗 |
| --- | ---: |
| Lv.0 | 不减耗 |
| Lv.1 | -3% |
| Lv.2 | -6% |
| Lv.3 | -9% |
| Lv.4 | -12% |
| Lv.5 | -15% |

- 只降低金币和材料消耗；
- 不提高强化成功率；
- 不改变失败降级、回到 +1 或永久碎装；
- 多个合法减耗来源按项目统一规则合并，最终成本不得低于基础成本的 50%。

### 6.7 成本示例

Lv.20 精良装备从 +9 强化至 +10：蓝晶粉尘 15 个、流派符文 2 个、金币约 2,777G；成功率 41.4%，失败回到 +1。

Lv.60 史诗装备从 +10 强化至 +11：流派符文 5 个、传承余烬 3 个、本关印记 2 个、金币 8,050G；成功率 33.9%，失败永久碎装。

Lv.60 传奇装备从 +12 强化至 +13：传奇星核 3 个、传承余烬 12 个、本关印记 6 个、金币 30,000G；成功率 20.7%，失败永久碎装。

### 6.8 其他成本边界

- 碎装后不返还装备材料，不触发自动分解，不增加分解计数；
- 锁定状态只防止误分解；主动进行 +11～+13 强化必须经过危险确认；
- 不开放失败补正、强化保底、保护券和碎装返还；
- 强化消耗不改变装备掉落、手动分解、成功／失败结算和7日暂存区规则。

## 7. UI 与防误触

### +1～+5

- 显示“成功率 100%”；
- 普通确认即可。

### +6～+10

- 明确显示成功率；
- 明确显示失败后实际等级，例如“失败：+8 → +1”；
- 玩家确认一次后执行。

### +11～+13

- 使用红色危险确认；
- 固定显示“失败后装备永久破碎；不返还装备或材料”；
- 显示本次成功率和当前装备完整名称；
- 要求二次确认，不能连续点击直接跳过；
- 强化界面不得用模糊的“可能损坏”替代“永久破碎”。

## 8. 游戏平衡定位

- 主线普通到折磨难度的基础平衡不要求 +11 以上；
- +5 是所有玩家可稳定获得的基础强化目标；
- +7 是常规成长目标；
- +10 是高投入但不碎装的实际毕业线；
- +11 是自愿进入高风险终局；
- +12 是极稀有展示级成果；
- +13 是长期追求和战利品荣誉，不作为 40 小时角色满级的必要条件。

强化必须提高已有装备的价值，但不能替代：

- 角色等级；
- 五维属性成长；
- 装备等级；
- 词条组合；
- 套装和技能构筑；
- 特殊蓝装的元素／物理增伤选择。

## 9. 与第二组装备数值稿的替换关系

本稿确认后已经完成以下审阅稿关系修正：

1. 第二组审阅稿第 11 节原有的“最高 +8、强化永不失败”规则已经废弃；
2. 第二组第 11 节改为引用本稿第 4～8 节；
3. 第二组审阅稿其他已确认章节保持不变；
