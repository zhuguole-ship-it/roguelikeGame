# 01 功能天赋84


## 通用功能天赋｜12个


### 功能权重边界

- FT001／FT004／FT005只影响技能奖励三选一中的候选权重
- 不影响蓝晶升级产生的战斗天赋三选一
- 不改变主流派、副流派或路线节点的出现权重
- 不突破技能合法性、前置条件、槽位与进化条件

### FT001 契约记忆


#### FT001 契约记忆｜3级

- 提高当前技能栏中已拥有技能的后续成长候选权重：
- Lv1：升级与进化候选相对权重 +8%
- Lv2：+16%
- Lv3：+24%
- 具体规则：
- 只影响当前仍持有技能的Lv2、Lv3、进化和Lv5成长候选。
- 不提高该技能所属整个流派的其他技能权重。
- 技能被替换后，立即停止获得该权重加成。
- 不影响新增技能候选和替换候选。
- 不保证候选必定出现，也不突破等级、进化或其他前置条件。
- 多个功能天赋同时修改候选权重时，按已经提出的“百分比加算”处理，不做乘法叠加。
- 完全不影响战斗天赋三选一。
- 这样它的作用是帮助玩家继续培养已有技能，而不会通过主流派锁定间接操纵技能牌池。

### FT002 初始重掷｜2级

- Lv1：开局三轮技能选择中的每一轮增加1次重掷
- Lv2：开局三轮技能选择中的每一轮增加2次重掷
- 每轮独立计算，不共享次数
- 只作用于开局三轮技能选择
- 不影响蓝晶战斗天赋三选一，也不增加后续技能奖励重掷次数

### FT003 封存选择


#### FT003 封存选择｜3级

- Lv1：解锁1个封存槽。
- Lv2：共2个封存槽。
- Lv3：共3个封存槽。
- 每个槽封存的是一个**完整技能家族**，包括基础技能及其全部进化。
- 被封存技能家族不会出现在开局技能选择或后续技能奖励中。
- 不影响已经开始的战斗；封存配置只能在战斗外修改，并在下一局生效。
- 不能封存基础攻击，也不能封存装备、套装或天赋自动触发的技能。
- 不影响战斗天赋候选；但因为玩家无法获得该技能，其对应路线可能无法满足“至少拥有一个兼容技能”的锁定条件。
- 如果封存后剩余合法技能不足以生成完整三选一，出战前直接提示玩家调整封存配置，不在战斗中偷偷忽略封存。
- 封存配置永久保存，直到玩家主动修改。

### FT004 流派偏向


#### FT004 流派偏向｜3级

- 玩家在战斗前选择一个目标技能流派：
- 穿透猎杀
- 散射压制
- 区域控制
- 野兽伙伴
- 效果：
- Lv1：该流派技能候选相对权重 +10%
- Lv2：+20%
- Lv3：+30%
- 具体规则：
- 同时影响该流派的新增技能、已有技能升级和合法进化候选。
- 每个技能家族必须拥有唯一的主流派标签，不能因为兼容多条战斗天赋路线而重复计算。
- 只提高相对权重，不保证必定出现。
- 玩家可以在每局开始前重新选择目标流派。
- 选择目标流派不等于锁定本局主流派，也不占用主／副流派名额。
- 战斗中即使最终锁定了其他主流派，偏向配置也不自动改变。
- 与 FT001 契约记忆、后续其他技能权重效果采用加算。
- 不影响战斗天赋候选权重。

### FT005 契约回响


#### FT005 契约回响｜3级

- 当前技能栏中，某一流派累计达到3点技能投入后，该流派后续技能候选权重：
- Lv1：+5%
- Lv2：+10%
- Lv3：+15%
- 投入计算：
- 获得一个Lv1技能：1点。
- 升至Lv2：该技能共2点。
- 升至Lv3：共3点。
- 完成进化：共4点。
- 升至Lv5：共5点。
- 同流派多个当前技能的投入相加。
- 三个同流派Lv1技能也正好是3点。
- 其他规则：
- 只统计当前技能栏中仍然持有的技能。
- 技能被替换后，旧技能投入立即移除，新技能按自身当前等级重新计算。
- 达到门槛后，同时提高该流派新增、升级和进化候选权重。
- 与 FT001、FT004按百分比加算。
- 不影响战斗天赋候选，也不自动锁定主／副流派。
- 套装自动技能、装备效果和战斗天赋生成的攻击不计入。

### FT006 蓝晶亲和｜5级

- 蓝晶经验获取 +3% / +6% / +9% / +12% / +15%。只增加蓝晶经验，不增加拾取半径，不直接调整技能或战斗天赋候选权重。

### FT007 分解熟练


#### FT007 分解熟练｜5级

- 装备分解产出的材料：
- +5% / +10% / +15% / +20% / +25%
- 作用范围：
- 只增加装备分解结果中明确标记为 dismantleMaterial 的材料。
- 包括普通材料、流派材料，以及传承／传奇装备分解时原本就会产出的稀有材料。
- 不增加金币、功能天赋点、关卡首通奖励、装备掉落或战斗内掉落。
- 不会让原本不产出某种材料的装备凭空产出该材料。
- 低数量结算建议采用确定性余数累计：
- 每种材料独立保存奖励小数余量。
- 例如基础获得1个、加成5%，累计0.05；累计达到1.00时额外发放1个并扣除1.00。
- 不使用随机概率决定是否多掉材料。
- 余数跨分解操作和重新登录保留。
- 批量分解与逐件分解的最终收益完全一致。

### FT008 强化基础


#### FT008 强化基础｜5级

- 装备强化消耗：
- -3% / -6% / -9% / -12% / -15%
- 具体规则：
- 同时降低装备强化所需的金币和强化材料。
- 适用于全部强化等级，不再沿用旧规则中仅影响 +1～+5 的限制。
- 不影响副属性重铸、Boss传承重铸、锁词、天赋重置或其他消费。
- 各类材料和金币分别计算，最终数量向上取整，不能出现免费强化。
- 与其他强化折扣在同一层先相加。
- 所有来源合计后，实际强化成本最低不得低于基础成本的50%。
- 只影响执行强化时的实时价格，不修改装备自身数据；重置天赋后价格立即恢复。

### FT009 结算清算


#### FT009 结算清算｜5级

- 局后基础结算资源：
- +4% / +8% / +12% / +16% / +20%
- 只增加：
- 本局结算获得的基础金币；
- 本局战斗进度产生的普通结算材料。
- 不增加：
- 功能天赋点；
- 首通奖励；
- 装备数量或装备稀有度；
- 自动分解产物，避免与 FT007 分解熟练重复放大；
- 传承余烬、传奇星核、本关印记等专项稀有资源；
- 蓝晶经验或战斗天赋奖励。
- 结算顺序：
- 1. 先计算本局基础资源。
- 2. 再应用正常结算100%、死亡／失败30%或主动放弃0%。
- 3. 最后对保留下来的基础金币和普通材料应用本天赋加成。
- 4. 每种资源独立向下取整，不使用随机补偿。

### FT010 精英记录


#### FT010 精英记录｜5级

- 所有精英敌人直接产出的基础材料：
- +3% / +6% / +9% / +12% / +15%
- 固定精英和精英突袭均适用。
- Boss不算精英。
- 不提高装备掉率、装备稀有度、技能奖励或蓝晶经验。
- 材料小数采用与 FT007相同的确定性余数累计。
- Lv5额外效果：
- 每种唯一精英原型首次完成击败记录时，额外获得1点功能天赋点。
- 按稳定的 eliteArchetypeId统计，不按难度、关卡或精英词缀重复计算。
- 同一种精英在不同难度只奖励一次。
- 已有旧存档击败记录的玩家，在解锁Lv5时补发尚未领取的对应点数。
- 补发和新击败都写入独立记录，不能通过重置天赋、重复解锁或读档再次领取。
- 重置 FT010不会收回已经获得的记录奖励。

### FT011 Boss追忆


#### FT011 Boss追忆｜5级

- 每个“关卡＋难度”的Boss首次通关长期资源奖励：
- +4% / +8% / +12% / +16% / +20%
- 可增加：
- 首通功能天赋点；
- 首通金币；
- 首通普通与Boss专项材料。
- 不增加：
- 保底装备件数；
- 装备稀有度；
- 传承／传奇硬掉率；
- 技能奖励、蓝晶经验或战斗伤害。
- 旧记录及升级处理：
- 以每个“关卡＋难度”的首次Boss击杀记录独立计算。
- 已经完成首通的旧存档不会失去收益。
- 解锁或升级该天赋时，根据该记录的基础首通资源，补发“新等级应得加成－此前已领取加成”的差额。
- 每条Boss首通记录保存已结算的 bossMemoryRank，防止重置、重复升级或读档反复领取。
- 重置天赋不收回已经结算的奖励；再次点回原等级也不会重复发放。
- 未来新增关卡和无限关卡Boss按各自稳定Boss记录ID接入，不依赖固定层数。

### FT012 仓库整理


#### FT012 仓库整理｜3级

- 仓库容量：
- Lv1：基础仓库容量 +10%
- Lv2：+20%
- Lv3：+30%
- 增加后的容量向下取整，至少保证每级都会增加1格。
- 只增加物品仓库，不增加玩家随身装备／战利品临时背包容量。
- 功能解锁：
- Lv2解锁“一键整理”：
- 按装备槽位；
- 稀有度；
- 套装／散件身份；
- 强化等级；
- 装备评分；
- 依稳定顺序重新排列。
- 一键整理不自动分解、不自动装备，也不改变锁定状态。
- Lv3解锁组合筛选：
- 流派；
- 套装；
- 装备槽位；
- 稀有度；
- 是否锁定；
- 是否已装备。
- 多个筛选条件可以同时使用。
- 重置后的容量规则沿用刚才确认的口径：超出新容量的现有装备不删除、不移位，但在占用量降回容量以内前禁止继续存入。

## 四流派功能天赋｜40个


### 四流派共用6个基础节点模板（每流派各一套，均3级）

- 确认采用“6个对称基础节点＋4个流派特色进阶节点”。

#### 1. **流派寻迹**

- 本流派“新增技能”候选相对权重：
- +5% / +10% / +15%
- 不影响已有技能升级或进化。

#### 2. **成长记忆**

- 当前持有的本流派技能，其升级与进化候选相对权重：
- +5% / +10% / +15%
- 与 FT001 契约记忆等效果加算。

#### 3. **契约校正**

- 当玩家已拥有本流派技能，或战斗前通过 FT004将其设为偏向流派时，如果连续多次技能奖励完全没有本流派合法候选：
- Lv1：连续4次未出现后，下次保底1张。
- Lv2：连续3次未出现后保底。
- Lv3：连续2次未出现后保底。
- 保底只替换三张候选中的一张，不增加卡牌数量。
- 重掷不增加或清空计数；保底触发后，重掷结果仍保留至少一张，直到玩家完成本次选择。
- 出现过本流派合法候选后计数归零，无论玩家是否选择。
- 如果不存在合法候选，则暂停计数，不生成非法卡牌。

#### 4. **猎具辨识**

- 已经确定产生装备奖励时，本流派装备的候选相对权重：
- +5% / +10% / +15%
- 不增加装备掉落次数或稀有度。

#### 5. **拆解归流**

- 分解带有本流派标签的装备时，其对应流派材料收益：
- +5% / +10% / +15%
- 与 FT007加算；
- 使用相同的确定性材料余数累计；
- 不增加金币和非本流派材料。

#### 6. **传承追踪**

- 本流派明确列出的套装件、协同散件和替代专属武器，在本流派装备候选中的相对权重：
- +5% / +10% / +15%
- 可以与“猎具辨识”叠加。
- 只调整已经合法的装备候选，不提高传承／传奇硬掉率，也不把其他装备推断成套装件。

### 穿透猎杀：4个特色进阶节点

- 确认四流派共用的6个基础功能天赋模板。

#### 1. 进化演算｜3级

- 当前持有的穿透猎杀技能达到Lv3，但连续技能奖励未出现其合法进化时：
- Lv1：连续3次后，下次保底1张该技能进化。
- Lv2：连续2次后保底。
- Lv3：连续1次后保底。
- 若多个穿透技能同时满足条件，优先等待最久的技能；同轮仍只保底1张。
- 重掷不能移除当前已触发的保底。
- 不改变两条进化原有内容或权重关系。

#### 2. 轨迹承接｜3级

- 使用一个穿透猎杀技能替换另一个穿透猎杀技能时：
- 新技能可以直接从Lv2开始。
- Lv1／Lv2／Lv3每局分别可使用1／2／3次。
- 每次替换前由玩家确认是否消耗次数。
- 不保留旧技能的进化、Lv5效果、冷却或战斗状态。
- 跨流派替换不能使用。

#### 3. 猎装补位｜3级

- 装备奖励已经生成穿透猎杀装备候选时：
- 当前没有装备史诗及以上穿透装备的槽位，候选权重 +10% / +20% / +30%。
- 只影响槽位补全，不保证套装、不增加候选数和稀有度。
- 所有槽位都已满足后，该效果暂停。

#### 4. 裂甲重铸｜3级

- 重铸带有穿透猎杀标签的装备时：
- 材料消耗 -5% / -10% / -15%
- 金币手续费不变。
- 适用于副属性重铸和对应流派传承重铸。
- 不提高优质词缀概率，也不自动锁定词缀。
- 与其他重铸折扣加算，最终材料成本不得低于基础值的50%。

### 散射压制：4个特色进阶节点


#### 1. 异域补全｜3级

- 当前持有至少1个区域控制技能、但少于2个不同区域技能家族时：
- 尚未拥有的区域技能家族，其新增候选权重 +8% / +16% / +24%
- 获得第2个不同区域技能家族后暂停。
- 技能被替换导致重新少于2个时恢复。
- 只按基础技能家族统计；同一技能的不同进化不算两个家族。
- 不直接创建Field，也不产生领域能量或套装进度。

#### 2. 场域演算｜3级

- 区域控制技能达到Lv3，但连续技能奖励未出现合法进化时：
- Lv1：连续3次后，下次保底1张进化。
- Lv2：连续2次后保底。
- Lv3：连续1次后保底。
- 多个技能同时满足时，优先等待最久者。
- 重掷不能移除已触发保底。
- 不改变技能原有Field数量、范围或持续时间。

#### 3. 界域补给｜3级

- 装备奖励已经生成区域控制装备候选时：
- 当前缺少史诗及以上区域控制装备的槽位，候选权重 +10% / +20% / +30%
- 同时适用于「契约领域」套装件及已确认的6件协同散件。
- 所有槽位满足后暂停。
- 不提高装备掉率、稀有度或套装硬概率。

#### 4. 领域维护｜3级

- 重铸区域控制标签装备时：
- 材料消耗 -5% / -10% / -15%
- 金币手续费不变。
- 适用于副属性重铸与契约领域相关传承重铸。
- 不提高区域词缀数值、共鸣概率或优质词缀概率。
- 与其他折扣加算，最终材料成本不得低于基础值的50%。

### 区域控制：4个特色进阶节点


#### 1. 异域补全｜3级

- 当前持有至少1个区域控制技能、但少于2个不同区域技能家族时：
- 尚未拥有的区域技能家族，其新增候选权重 +8% / +16% / +24%

- 两个路线基础节点都至少选择1次；
- 路线基础节点累计投入至少3点。

- 对应路线已锁定；

- 至少选择1个深层节点。

#### 第3阶入口


##### PT001 穿透猎手｜1级

- 所有穿透猎杀技能：

- 弹体、返程或追击移动速度+10%；

#### 路线A：贯穿破甲

- 核心体验：
- 直线贯穿／去返双程 → 积累贯体 → 轨迹破甲 → 终点回响 → 无限贯线
- 适用：
- 穿刺箭、风切箭、贯日长虹；
- 反曲回箭、双星追击、苍穹审判。

##### 贯体事件定义

- 穿刺箭：
- 弹体命中目标后仍能继续穿透，计1次贯体事件。
- 反曲回箭：
- 每支箭第一次合法返程命中，计1次贯体事件；
- 同一支箭后续返程命中不重复提供贯体；
- 去程和返程仍分别保留原命中规则。
- 每次施法最多产生4次贯体事件。

##### 第4阶

- PT101 贯体积累｜3级
  - 每次贯体事件获得1层贯体，最多4层。
  - 下一次贯穿破甲技能每层伤害：
  - Lv.1：+3%
  - Lv.2：+4%
  - Lv.3：+5%
  - 释放后清空。
- PT102 破甲轨迹｜3级
  - 以下命中施加“轨迹破甲”：
  - 穿刺箭已经穿过至少1个目标后的后续命中；
  - 反曲回箭的合法返程命中。
  - 目标受到贯穿破甲路线伤害：
  - Lv.1：+4%
  - Lv.2：+7%
  - Lv.3：+10%
  - 持续3秒。
  - 只增强贯穿破甲路线，不增加其他流派伤害。

##### 第5阶

  - Lv.3：+12%
  - 持续4秒。
- PT202 贯穿回响｜1级

  - 穿刺箭：在最终结束位置触发；
  - 反曲回箭：在最远折返点触发；
  - 造成角色攻击力×70%伤害；
  - 半径2.5米；
  - 每次技能最多触发一次。
  - 回响不产生领域能量、套装进度或新的贯体。

  - Lv.1：宽度+10%，伤害+8%

  - Lv.3：宽度+20%，伤害+16%

  - 对精英或Boss连续有效命中5次：
  - 获得2层贯体；

  - 去程与返程均可计数，但同一次碰撞不能重复登记。

##### 第6阶关键天赋

- PT301 无限贯线｜1级

#### 路线B：迂回弹道

- 螺旋破空、交叉切射、血嗅追猎。

##### 轨迹转折定义

- 跳弹羽箭：
- 从当前目标弹向下一目标，计1次转折。
- 螺旋破空：
- 完成一次真实命中后转向下一目标，计1次转折。
- 以下不计数：
- 渲染插值点；
- 视觉弧线路径；
- 同一目标上的碰撞停留；
- 转折震击和万径归一产生的附加伤害。

- 第二个问题：普通技能奖励是否继续保留每局基础1次重掷，并与FT002的初始技能草稿重掷完全分开？

### 所有技能奖励统一三选一

- 我赞成统一改成三选一。这样奖励界面规则更一致，也能让每次选择更有压力。但候选从5张降到3张后，必须加强保底，否则原来的五阶段技能成长很容易被随机数卡住。

#### 2026-09-15 补充确认：技能奖励允许主动放弃

- 所有普通技能奖励均提供明确的“放弃技能奖励”操作，包括固定层技能奖励、精英突袭技能奖励及后续新增的同类技能奖励。
- 放弃后不获得新技能、不替换已有技能、不提升等级、不选择进化；本次技能奖励立即消费并关闭，流程恢复到奖励出现前应继续的战斗或过层状态。
- 若玩家已经从三选一进入满槽替换二次确认，仍可放弃整个本次技能奖励；不得强迫替换已有技能。
- 若本次技能奖励为 Lv.4 进化候选，仍允许放弃整个本次技能奖励；放弃不会修改技能等级、进化分支或后续保底状态之外的战斗数据。
- 放弃不视为重掷，不消耗重掷次数，也不触发任何“选择／获得／升级／进化技能”联动。
- 蓝晶升级产生的 V3 战斗天赋三选一仍必须立即选择并消费 1 点，不能放弃、跳过或储存。
- 战前连续三轮初始技能草案仍必须各选择 1 项；该独立流程不提供“放弃技能奖励”，只能按既有规则通过放弃整局退出。

#### 统一三选一

- 所有技能选择界面统一为三选一：
- 开局三轮技能草案：三选一。
- 固定层数技能奖励：三选一。
- 精英突袭技能奖励：三选一。
- 其他后续新增的技能奖励：三选一。
- 蓝晶升级：仍然是战斗天赋三选一，不进入技能池。
- 开局第一轮没有已有技能，因此只会出现新增技能。获得技能后，后续奖励才同时开放新增、替换和升级。

#### 技能奖励使用统一合法池

- 每次技能奖励先建立一个合法候选池，包含：
- 新增：尚未拥有的核心技能。
- 替换：主动技能槽已满时，新增技能自动进入替换流程。
- 升级：已有技能的Lv.2、Lv.3或Lv.5升级。
- 进化：Lv.3技能的两个进化方向。
- 被动升级：例如「鹰眼专注」。
- 然后从统一池中加权抽取3张并随机排列，不固定：
- 第一张必须升级；
- 第二张必须新增；
- 第三张必须替换。
- 这样不会出现某个固定位置对应的牌池先被抽空。
- “新增”和“替换”不需要成为两种独立候选类型：
- 技能槽未满：选择新技能就是新增。
- 技能槽已满：选择同一个新技能后，再让玩家选择替换哪个旧技能。

#### 保留原技能成长线路

- 完整成长路线仍然是：
- 获得Lv.1 → Lv.2 → Lv.3 → 选择进化 → Lv.5
- 不改变技能等级、进化条件或基础技能内容。
- 对于Lv.3进化，我建议保留一个特殊规则：
- 一旦某个Lv.3技能被抽中作为进化候选，它的两个进化分支同时出现；
- 第三张牌再从其他合法候选中抽取；
- 两个进化分支的位置随机，不固定左右。
- 否则只随机出现其中一个分支，会让玩家无法真正选择进化方向。

#### 三选一后的权重与保底

- 因为选择从5张降到3张，我建议使用动态权重：
- 已有技能升级：基础权重3。
- 与当前构筑方向一致：额外提高权重。
- 新技能：基础权重2。
- 被动升级：基础权重1。
- 长时间未出现升级候选时，逐次提高升级权重。
- 同时增加最低保障：
- 每次三选一至少有1张是“当前可推进成长的候选”，包括升级、进化或Lv.5。
- 如果当前没有任何可升级技能，才允许3张全部为新技能。
- 同一面板中，普通情况下不重复同一个核心技能家族。
- Lv.3的两个进化分支是允许重复同一技能家族的唯一例外。
- 继续保留第5、第10、第15次固定奖励的Lv.5路线保障。
- 这样既不是固定“新增/升级/替换”三个槽位，也不会连续几轮只出现新技能，导致已有构筑无法成长。

#### 刷新规则

- 继续按刚才确认的规则：
- 每次普通技能奖励基础1次刷新。
- 刷新整组三张候选。
- 刷新后的候选仍遵守升级保障和合法性检查。
- 战斗天赋三选一不能刷新。
- FT002只影响开局技能草案，不影响后续技能奖励。

#### 我的整体判断

- 这套调整会比当前系统更统一：
- 所有界面都是三选一；
- 玩家每次都可能看到新增或成长机会；
- 不再区分“这次只能升级”“这次才能获得新技能”；
- 精英突袭也会成为真正完整的技能奖励；
- 原有技能等级和进化线路无需重做。
- 但它会覆盖当前“精英突袭只能升级已有技能，不能新增或替换”的规则。
- 下一个需要你确认的问题是：

##### 精英突袭奖励是否也完全进入统一技能池，允许新增技能，并在技能槽已满时触发替换？

- 我的建议是确认统一，否则“所有技能奖励规则一致”仍会留下一个明显例外。

### 技能候选去重与进化分支

- 建议：
- 新增、替换、升级、进化全部进入同一个合法候选池，三张牌完全打乱，不固定卡位职责。
- 同一技能家族在同一轮通常最多出现1张，避免三张牌被同一技能占满。
- 唯一例外是Lv.3进化选择：同一技能的不同合法进化可以同时出现，让玩家能够直接比较路线。
- 已拥有技能：
- Lv.1 → 只生成升至Lv.2候选；
- Lv.2 → 只生成升至Lv.3候选；
- Lv.3 → 生成不同进化分支候选；
- 已进化Lv.4 → 只生成对应进化升至Lv.5候选；
- Lv.5 → 不再生成升级候选。
- 未拥有技能：
- 有空槽时显示“新增”；
- 槽位已满时显示“替换”；
- 两者使用同一新增技能权重，不建立两套技能池。
- 主副流派及路线锁定不禁止其他流派技能出现，也不改变技能奖励权重。
- 功能天赋的封存、流派偏向、契约记忆、契约回响、补全和进化保底，只修改合法候选及相对权重。
- 普通技能奖励保留基础1次重掷；重掷尽量排除刚才的三张候选，合法池不足时允许重复。
- 初始三轮额外重掷只由FT002提供，不影响后续奖励。
- 如果合法候选不足3张，就展示全部合法候选，不用无效占位卡凑满三张；仍必须从中选择1张。

### Q/E/R满槽后的两步替换

- 建议采用两步式：
- 1. 三选一界面仍然展示“新增某技能”，不提前绑定替换目标。
- 2. 玩家选中新增技能后，进入Q/E/R替换选择界面。

#### 3. 界面同时展示：

- 新技能Lv.1效果；
- 三个现有技能的当前等级、进化路线；
- 替换后会失去的成长和相关联动；
- 哪些已选战斗天赋会暂时休眠。
- 4. 玩家可以返回上一层重新查看三张候选，但不能关闭整个奖励界面。
- 5. 确认替换后，新技能默认从Lv.1开始。
- 6. 只有已确认的「轨迹承接」等功能天赋满足条件时，新技能才能从Lv.2开始，并消耗本局对应次数。
- 7. 被替换技能的等级、进化、冷却、充能和临时状态全部移除，不转移给新技能。
- 8. 已锁定的主/副流派和路线不退款、不改变；如果失去最后一个兼容技能，对应路线效果休眠。
- 9. 后续重新获得兼容技能时，休眠路线自动恢复。

#### 10. 替换完成后才处理队列中的下一轮奖励，因此下一轮候选会根据新技能栏重新计算。


### 奖励队列与暂停

- 建议采用严格队列：
- 1. 新开局的三轮初始技能选择最优先，全部完成后才开始战斗。
- 2. 战斗中如果同一更新周期同时产生“技能奖励”和“蓝晶升级战斗天赋”，先处理技能奖励。
- 3. 技能奖励完成后，再逐个处理战斗天赋三选一。
- 4. 一次获得大量蓝晶并连续升3级，就依次弹出3轮战斗天赋三选一；每轮必须选择，不能合并成一轮。
- 5. 整个奖励队列处理期间暂停战斗、敌人、投射物、持续伤害、区域和计时器。
- 6. 每一轮候选只在该轮真正打开时生成，必须基于上一轮选择后的最新技能、路线和天赋状态。
- 7. 如果上一轮技能奖励新增了兼容技能，紧接着的战斗天赋候选可以出现该技能对应的路线入口。
- 8. 如果中途点满所有当前合法有限节点，队列中剩余的升级立即改从无限成长池生成三选一。
- 9. 保存或刷新页面后，恢复当前未完成的奖励轮次和固定候选，不允许通过重载刷新选项。

#### 10. 所有奖励按触发顺序FIFO处理；相同时间戳时，技能奖励优先于战斗天赋奖励。

- 确认路线首次选择条件：
- 必须拥有至少1个与该路线兼容的核心技能或进化；
- 没有兼容技能的路线不会进入候选池；
- 路线选定后锁定对应主流派；
- 后续替换掉全部兼容技能时，路线不重置、不退款；
- 路线效果暂时休眠，重新获得兼容技能后恢复；
- 路线仍不影响技能奖励权重。

#### 不绑定关卡层数后，路线应如何解锁？

- 1. 玩家拥有某主流派的至少1个核心技能；
- 2. 从战斗天赋三选一中获得该主流派的“流派入口”；
- 3. 流派入口获得后，当前拥有兼容技能的路线入口进入合法候选池；
- 4. 玩家第一次选择某条路线的入口节点时，该主流派正式锁定该路线；

#### 5. 另外两条路线立即从本局候选池移除。

- 例如：
- 玩家拥有毒藤箭；
- 获得“区域掌控”流派入口；

- 这套规则：
- 不绑定地图第几层；
- 不绑定未来关卡总层数；
- 无限层也能正常工作；
- 不需要固定0/5/12/18等累计点数门槛；
- 路线选择仍发生在正常的随机三选一中，不额外弹出专用路线菜单。

# 03 无限成长

## 有限阶段的流派无限成长插入机制

### 触发条件与计数口径

- 无限成长不再只在有限战斗天赋全部点满后出现；它会在有限树成长过程中按流派投入进度穿插出现。
- 每个流派分别维护“本局累计投入的有限战斗天赋点数”，主流派与副流派独立计数、独立触发。
- 某个流派每新增投入1点有限战斗天赋，都会为该流派生成1次待处理的无限成长插入机会。
- “第1点、第2点、第3点”只是连续触发的起始示例；第4点、第5点及之后每一点同样继续触发，不设置次数上限。
- 首次选择一个新节点和提升已有节点等级都按本次实际投入点数计数；一次投入1点只增加1次触发。
- 以下有限节点计入所属流派累计投入：
  - 流派公共入口节点：`PT001`、`ST001`、`AT001`、`BTB001`；
  - 已锁定路线的基础节点、深层节点与关键节点；
  - 上述节点的每次合法升阶；
  - 首次选择并锁定主流派或副流派路线的那一点。
- 通用“猎手基础／战斗本能”节点不计入任何流派的插入计数。
- 无限成长选择、技能奖励、装备奖励、套装自动效果及其他非有限战斗天赋来源不计入该计数，也不能递归生成新的插入机会。

### 插入轮候选结构

- 插入机会绑定到奖励队列中的“下一次实际战斗天赋三选一”。
- 技能奖励、装备奖励、楼层结算或其他奖励即使先发生，也不会消耗该插入机会。
- 一次普通有限阶段的插入轮固定生成3张候选：
  - 1张来自触发流派的合法无限成长池；
  - 2张来自当前全局合法有限战斗天赋池。
- 三张候选最终位置完全打乱；无限成长候选不固定在任何槽位。
- 触发流派的无限成长池由两部分组成：
  - 该流派的公共无限成长；
  - 该流派当前已锁定路线的路线专属无限成长。
- 所有合法无限成长选项按单个选项等权抽取，不采用“公共池50%／路线池50%”等分类权重。
- 未选择路线的路线专属无限成长不得进入候选；已达硬上限、当前不兼容或当前不可生效的选项必须从池中剔除。
- 另外2张有限候选仍从通用、主流派、副流派构成的全局合法有限池抽取，继续遵守既有前置、互斥、路线锁定、权重、冷却和同轮不重复规则；它们不要求来自本次触发流派。

### 选择、消费、回池与连续触发

- 插入机会只有在对应候选实际展示给玩家时才被消费。
- 候选展示后，无论玩家是否选择其中的无限成长，该次插入机会都立即消耗，不在下一轮强制保留，也不追补。
- 如果玩家选择插入的无限成长：
  - 该选择占用本轮唯一奖励；
  - 本轮不获得有限战斗天赋点；
  - 不生成新的插入机会。
- 如果玩家选择有限候选：
  - 正常获得该有限节点的1点投入；
  - 若该点属于某个流派，则为该流派再登记1次待处理插入机会；
  - 因此允许形成“有限点 → 下一轮插入 → 再选有限点 → 再下一轮插入”的连续节奏。
- 一次经验结算跨越多个蓝晶等级时，仍按奖励队列逐轮处理；每轮完成选择后再生成下一轮候选，不能提前把后续轮次一次性固化。
- 已展示但未选择的无限成长选项立即回到合法池；只有被选择的无限成长选项进入1个战斗天赋奖励轮的抽取冷却。
- 完整无限成长阶段沿用相同的1轮冷却规则；达到硬上限的选项永久退出本局候选池。
- 冷却只影响该具体无限成长选项，不影响同流派其他无限成长，也不影响有限战斗天赋候选。

### 有限候选不足与完整无限阶段

- 在普通有限阶段，除以下两种情况外，无限成长不会自然进入候选池：
  - 存在待处理的流派插入机会；
  - 当前合法有限候选不足3张，需要用合法无限成长补位。
- 插入轮中若合法有限候选不足2张：
  - 先放入全部可用有限候选；
  - 剩余空位从当前合法的通用、主流派和副流派无限成长池补齐；
  - 同轮候选不得重复。
- 如果玩家选择的最后一个合法有限点同时生成了插入机会，则下一轮直接进入完整无限成长三选一：
  - 至少1张保证来自触发流派；
  - 另外2张从通用、主流派和副流派合法无限成长池抽取；
  - 完成该保证轮后，后续完整无限成长轮不再提供流派保底。
- 当本局所有仍合法的有限战斗天赋均已点满或被互斥永久关闭时，蓝晶升级持续进行，候选系统切换为完整无限成长三选一。
- 若后续获得新技能使新的有限节点重新变为合法，系统暂时离开完整无限成长阶段；之后每次新选择的流派有限点仍按本节规则生成下一轮插入机会。

### 兼容性、跨层与存档

- 待处理插入机会在生成候选时重新校验当前构筑，而不是保存生成当时的具体卡牌。
- 若触发流派仍兼容，则正常从该流派公共无限成长与已锁定路线无限成长的合法合集抽取。
- 若已锁定路线暂时不兼容、但该流派仍有其他兼容技能，则过滤路线专属选项，仅保留当前确实可生效的流派公共无限成长。
- 若整个触发流派已无任何兼容技能，则取消并消费该次插入机会，本轮恢复为普通有限战斗天赋三选一；该机会不在以后追补。
- 待处理插入机会跨楼层保留，并作为本局运行状态写入存档；读取存档后继续等待下一次实际战斗天赋三选一。
- 旧存档历史上已经投入的流派有限点不追溯补发插入机会。
- 旧版进行中战斗天赋迁移为新版必须选择的奖励轮时，迁移后新选择的流派有限点按新规则正常触发。
- 旧存档只恢复真实保存的待处理插入状态，禁止根据历史累计点数反推或补造插入次数。

## 有限树点满后切换完整无限成长

- 确认，作为当前设计草案保留：
- 战斗天赋树是有限的；
- 玩家点满后，蓝晶升级不会停止；
- 后续每次升级切换为“无限成长三选一”；
- 无限成长可重复选择，只在本局有效；
- 仍需立即三选一，不能关闭、存点或刷新；
- 不修改基础技能数据；
- 本节现已写入权威口径并进入实现阶段。
- 我的建议：
- 玩家将本局路线选择后仍然合法的全部战斗天赋点满，即视为有限战斗天赋树点满。
- 具体包括：
- 已选路线中的所有可用节点；
- 允许跨流派投入后仍然合法的节点；
- 通用战斗天赋；
- 已解锁且没有被互斥规则排除的节点。
- 不包括：
- 与已选路线互斥的另外两条路线；
- 因关键天赋互斥而永久关闭的节点；
- 当前构筑永远无法再选择的节点。
- 否则互斥节点永远无法获得，系统也就永远不能进入无限成长阶段。

### 无限成长采用硬上限还是递减收益？

- 我的建议采用混合规则。
- 可以长期成长的属性采用递减收益、不设绝对等级上限：
- 全局伤害；
- 最大生命；
- 基础攻击伤害；
- 穿透、散射、区域、野兽等流派伤害。
- 建议节奏：
- 第1～10次：获得完整数值；
- 第11～25次：每次效果降为原来的60%；
- 第26次以后：每次效果降为原来的30%。
- 这些属性可以一直选择，保证无限层永远有成长空间。
- 容易破坏机制或性能的属性采用硬上限，达到上限后从候选池移除：
- 攻击速度；
- 移动速度；
- 暴击率；
- 冷却恢复；
- 伤害减免；
- 区域范围；
- 区域持续时间；
- 野兽攻击速度；
- 野兽复苏速度；
- 投射物宽度或数量等几何属性。
- 这样可以避免无限层后期出现：
- 攻击间隔接近零；
- 技能无冷却；
- 移动速度失控；
- 区域覆盖整个地图；
- 野兽或投射物数量导致性能问题；
- 减伤接近100%。

## 所有技能选择统一三选一

- 我赞成统一改成三选一。这样奖励界面规则更一致，也能让每次选择更有压力。但候选从5张降到3张后，必须加强保底，否则原来的五阶段技能成长很容易被随机数卡住。

### 统一三选一

- 所有技能选择界面统一为三选一：
- 开局三轮技能草案：三选一。
- 固定层数技能奖励：三选一。
- 精英突袭技能奖励：三选一。
- 其他后续新增的技能奖励：三选一。
- 蓝晶升级：仍然是战斗天赋三选一，不进入技能池。
- 开局第一轮没有已有技能，因此只会出现新增技能。获得技能后，后续奖励才同时开放新增、替换和升级。

### 技能奖励使用统一合法池

- 每次技能奖励先建立一个合法候选池，包含：
- 新增：尚未拥有的核心技能。
- 替换：主动技能槽已满时，新增技能自动进入替换流程。
- 升级：已有技能的Lv.2、Lv.3或Lv.5升级。
- 进化：Lv.3技能的两个进化方向。
- 被动升级：例如「鹰眼专注」。
- 然后从统一池中加权抽取3张并随机排列，不固定：
- 第一张必须升级；
- 第二张必须新增；
- 第三张必须替换。
- 这样不会出现某个固定位置对应的牌池先被抽空。
- “新增”和“替换”不需要成为两种独立候选类型：
- 技能槽未满：选择新技能就是新增。
- 技能槽已满：选择同一个新技能后，再让玩家选择替换哪个旧技能。

### 保留原技能成长线路

- 完整成长路线仍然是：
- 获得Lv.1 → Lv.2 → Lv.3 → 选择进化 → Lv.5
- 不改变技能等级、进化条件或基础技能内容。
- 对于Lv.3进化，我建议保留一个特殊规则：
- 一旦某个Lv.3技能被抽中作为进化候选，它的两个进化分支同时出现；
- 第三张牌再从其他合法候选中抽取；
- 两个进化分支的位置随机，不固定左右。
- 否则只随机出现其中一个分支，会让玩家无法真正选择进化方向。

### 三选一后的权重与保底

- 因为选择从5张降到3张，我建议使用动态权重：
- 已有技能升级：基础权重3。
- 与当前构筑方向一致：额外提高权重。
- 新技能：基础权重2。
- 被动升级：基础权重1。
- 长时间未出现升级候选时，逐次提高升级权重。
- 同时增加最低保障：
- 每次三选一至少有1张是“当前可推进成长的候选”，包括升级、进化或Lv.5。
- 如果当前没有任何可升级技能，才允许3张全部为新技能。
- 同一面板中，普通情况下不重复同一个核心技能家族。
- Lv.3的两个进化分支是允许重复同一技能家族的唯一例外。
- 继续保留第5、第10、第15次固定奖励的Lv.5路线保障。
- 这样既不是固定“新增/升级/替换”三个槽位，也不会连续几轮只出现新技能，导致已有构筑无法成长。

### 刷新规则

- 继续按刚才确认的规则：
- 每次普通技能奖励基础1次刷新。
- 刷新整组三张候选。
- 刷新后的候选仍遵守升级保障和合法性检查。
- 战斗天赋三选一不能刷新。
- FT002只影响开局技能草案，不影响后续技能奖励。

### 我的整体判断

- 这套调整会比当前系统更统一：
- 所有界面都是三选一；
- 玩家每次都可能看到新增或成长机会；
- 不再区分“这次只能升级”“这次才能获得新技能”；
- 精英突袭也会成为真正完整的技能奖励；
- 原有技能等级和进化线路无需重做。
- 但它会覆盖当前“精英突袭只能升级已有技能，不能新增或替换”的规则。
- 下一个需要你确认的问题是：

#### 精英突袭奖励是否也完全进入统一技能池，允许新增技能，并在技能槽已满时触发替换？

- 我的建议是确认统一，否则“所有技能奖励规则一致”仍会留下一个明显例外。

## 技能候选去重／进化／新增／替换／升级

- 建议：
- 新增、替换、升级、进化全部进入同一个合法候选池，三张牌完全打乱，不固定卡位职责。
- 同一技能家族在同一轮通常最多出现1张，避免三张牌被同一技能占满。
- 唯一例外是Lv.3进化选择：同一技能的不同合法进化可以同时出现，让玩家能够直接比较路线。
- 已拥有技能：
- Lv.1 → 只生成升至Lv.2候选；
- Lv.2 → 只生成升至Lv.3候选；
- Lv.3 → 生成不同进化分支候选；
- 已进化Lv.4 → 只生成对应进化升至Lv.5候选；
- Lv.5 → 不再生成升级候选。
- 未拥有技能：
- 有空槽时显示“新增”；
- 槽位已满时显示“替换”；
- 两者使用同一新增技能权重，不建立两套技能池。
- 主副流派及路线锁定不禁止其他流派技能出现，也不改变技能奖励权重。
- 功能天赋的封存、流派偏向、契约记忆、契约回响、补全和进化保底，只修改合法候选及相对权重。
- 普通技能奖励保留基础1次重掷；重掷尽量排除刚才的三张候选，合法池不足时允许重复。
- 初始三轮额外重掷只由FT002提供，不影响后续奖励。
- 如果合法候选不足3张，就展示全部合法候选，不用无效占位卡凑满三张；仍必须从中选择1张。

## 奖励队列与多级升级处理

- 建议采用严格队列：
- 1. 新开局的三轮初始技能选择最优先，全部完成后才开始战斗。
