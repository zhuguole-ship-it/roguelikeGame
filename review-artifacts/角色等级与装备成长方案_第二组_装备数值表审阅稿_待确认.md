# 角色等级与装备成长方案｜第二组：装备数值表确认稿

> 状态：用户已确认；自 2026-09-24 起作为 [`角色等级、装备成长、强化与材料系统 V1`](../docs/character-equipment-progression-v1.md) 的权威数值附件。
>
> 文档性质：文件名中的“审阅稿／待确认”为历史名称，正文表格、公式和边界均属于实现与验收依据。
> 前置：第一组角色经验曲线已由用户确认。本稿只完成装备等级、部位、品质、五维、直接属性、强化和固定效果随装备等级成长的数值口径。

## 1. 不变边界

- 当前所有装备实例都增加装备等级，合法范围为 Lv.1–60。
- 角色等级低于装备等级时不能穿戴，但可以保存该装备。
- 弓箭手武器、弓箭手套装核心件和明确服务弓箭手流派的协同散件为职业专属。
- 其余非武器装备为跨职业通用装备；允许出现当前职业低收益或无效的五维词条。
- 装备强化与装备等级是两套系统：高装备等级代表新掉落实例的基础质量，强化只处理该实例允许强化的面板直接属性。
- 强化不增加力量、智力、耐力、精神、敏捷，不强化固定说明、单件独立效果或套装效果。
- 装备等级可以使单件独立效果和套装效果变强，但必须按本稿的独立等级缩放处理，不能借用强化等级。
- 关卡结算不再自动分解任何装备；分解只由玩家主动操作。

## 2. 掉落装备等级

根据角色当前等级确定掉落档位：

```text
dropBandMin = max(1, floor(playerLevel / 5) × 5)
dropBandMax = min(60, dropBandMin + 5)
```

特殊处理：角色 Lv.1–4 时，`dropBandMin = 1`、`dropBandMax = 5`。

| 角色等级示例 | 可掉落装备等级 |
| ---: | --- |
| 1–4 | Lv.1–5 |
| 5–9 | Lv.5–10 |
| 10–14 | Lv.10–15 |
| 15–19 | Lv.15–20 |
| 20–24 | Lv.20–25 |
| 25–29 | Lv.25–30 |
| 30–34 | Lv.30–35 |
| 35–39 | Lv.35–40 |
| 40–44 | Lv.40–45 |
| 45–49 | Lv.45–50 |
| 50–54 | Lv.50–55 |
| 55–59 | Lv.55–60 |
| 60 | Lv.60 |

这满足已经确认的示例：角色 Lv.18 掉 Lv.15–20；Lv.20 掉 Lv.20–25；Lv.21 掉 Lv.20–25；Lv.26 掉 Lv.25–30。装备最多可高于角色当前等级 5 级，作为短期追求目标。

装备等级在掉落时固定。强化、重铸、穿戴、放入仓库或跨局均不能改变装备等级。

## 3. 稀有度与普通词条数量

| 稀有度 | 普通随机词条数 | 固定机制 |
| --- | ---: | --- |
| 破碎 | 1 | 无 |
| 普通 | 1 | 无 |
| 优质 | 2 | 无 |
| 精良（蓝） | 3 | 特殊蓝装判定成功时额外增加1条伤害类型增幅，不占这3条 |
| 史诗（紫） | 4 | 可以拥有技能或流派机制词缀 |
| 传承 | 5 | 可以拥有固定单件效果、套装身份或Boss专属效果 |
| 传奇 | 5 | 可以拥有改变技能或构筑结构的固定效果 |

规则：

- 同一件装备不能重复出现完全相同的普通词条。
- 同一五维不能在同一件装备上同时出现“固定点数”和“百分比增幅”。
- 固定单件效果、套装身份、套装效果和特殊蓝装额外伤害词条都不占普通词条数。
- 稀有度主要决定词条数量、机制上限和优质词条概率，不再用一套额外的稀有度总倍率把所有新词条重复放大。

## 4. 普通词条质量

- 每条普通词条在自己“装备等级＋词条类型”的合法区间内独立 roll。
- 高品质词条：落在合法区间的前 10%。
- 完美词条：落在合法区间的前 1%。
- 精良（蓝）装备：每条普通词条有 25% 概率进入高品质区间；自然完美概率为每条 2.5%。
- 史诗、传承、传奇：每条普通词条有 10% 概率进入高品质区间；自然完美概率为每条 1%。
- 破碎、普通、优质：按完整合法区间均匀 roll，不额外提高高品质概率。
- 特殊蓝装的 +1%～+50% 伤害类型增幅不是普通词条的“完美词条”，不触发或重置普通完美词条保底。

## 6. 五维百分比词条

五种核心属性都允许出现百分比增幅。先汇总角色基础值、升级自动分配和装备固定点数，再乘百分比：

```text
finalCoreStat = floor((classBase + levelAllocated + flatEquipmentStat) × (1 + coreStatPercentSum))
```

| 装备等级 | 单条五维百分比 |
| --- | ---: |
| Lv.1–9 | +1%～+2% |
| Lv.10–29 | +2%～+3% |
| Lv.30–49 | +3%～+5% |
| Lv.50–59 | +4%～+7% |
| Lv.60 | +6%～+10.5% |

五维收益按以下精确换算执行：

| 五维 | 每1点收益 | 作用边界 |
| --- | --- | --- |
| 力量 | 近距离攻击强度 +0.30% | 只放大被定义为近战的伤害 |
| 智力 | 法术伤害 +0.30%；最大法力 +2 | 当前弓箭手没有法力与法术链，因此对弓箭手可为无效收益 |
| 耐力 | 最大生命 +1.5；体力恢复速度 +0.25% | 体力指闪避所消耗的战斗资源 |
| 精神 | 法力恢复速度 +0.35%；玩家移动限制类控制时长 -0.20% | 只缩短眩晕、禁锢等限制玩家移动的持续时间 |
| 敏捷 | 远距离攻击强度 +0.25%；暴击率 +0.04个百分点 | 暴击只作用于玩家可暴击的攻击 |

统一规则：

- 五维每点收益线性叠加，不使用边际递减。
- 普通暴击率最终上限为75%。
- 精神与其他来源合计的移动限制类控制时长缩减上限为60%。
- 敏捷提供的暴击率不让野兽伙伴、DoT Tick、反射、环境伤害或明确不可暴击的效果获得暴击。
- 野兽伙伴使用各自独立暴击链，不继承玩家敏捷暴击。

## 7. 装备固有基础属性

装备固有属性不占普通词条数。其掉落初值按装备等级线性成长：

```text
levelFactor = 1 + (itemLevel - 1) / 59
baseProperty = round(slotLevel1Base × levelFactor)
```

因此 Lv.60 的装备固有基础属性约为 Lv.1 的 2 倍。实际实例仍可在对应稀有度的主属性区间内 roll；下表是 roll 前基准。

| --- | --- | ---: | ---: |
| 武器 | 攻击 | 6 | 12 |
| 武器 | 射程 | 10 | 20 |
| 头盔 | 护甲 | 22 | 44 |
| 胸甲 | 护甲 | 32 | 64 |
| 胸甲 | 最大生命 | 12 | 24 |
| 护肩 | 护甲 | 18 | 36 |
| 手腕 | 护甲 | 9 | 18 |

| 腿部 | 护甲 | 28 | 56 |
| 腿部 | 最大生命 | 10 | 20 |
| 鞋子 | 护甲 | 12 | 24 |
| 鞋子 | 移动速度 | 3 | 6 |

| 披风 | 移动速度 | 2 | 4 |
| 戒指1／戒指2／项链 | 无固有护甲 | 0 | 0 |

护甲严格只出现在非武器、非饰品的防具上。胸甲、腿部和头盔最高；护肩、披风其次；手部、鞋子、手腕依次降低。

## 10. 护甲结算

所有防具固有护甲相加后，先处理破甲／护甲穿透，再计算护甲减伤：

```text
armorAfterFlatBreak = max(0, totalArmor - flatArmorBreak)
effectiveArmor = armorAfterFlatBreak × (1 - percentArmorPenetration)

armorDamageReduction = min(
  70%,
  0.70 × effectiveArmor / (effectiveArmor + 100 + 10 × damageSourceLevel)
)
```

- 护甲同时减少物理、火、电、冰、水、自然、风、光伤害。
- 先扣固定破甲，再计算百分比护甲穿透；百分比护甲穿透最终上限为80%。
- 有效护甲最低为0，不允许负护甲通过该公式反向放大伤害。
- 现有“受到伤害 +X%”易伤效果不自动改名或换算成护甲削减。
- 护甲减伤上限 70%；与其他减伤层乘法结算后，最终总减伤上限 80%。
- 特殊蓝装伤害增幅位于普通伤害、护甲和其他减伤结算之后。

## 11. 装备强化

本节旧版“最高 +8、强化永不失败”方案已经废弃。强化完整规则以同目录下已经确认的《装备强化系统_DNF国服60级早期参考与项目适配审阅稿》为唯一有效来源。

确认后的核心口径为：

- 破碎／普通最高 +5，优质最高 +7，精良最高 +10，史诗／传承／传奇最高 +13；
- +1～+5 必定成功；+6～+7 失败降低1级；+8～+10 失败回到 +1；+11～+13 失败永久碎装且无返还；
- +11／+12／+13 的高强化跃升只放大 +10 的强化追加值，不放大整件装备的所有属性和机制；
- 强化主属性只有固定攻击、固定最大生命和护甲；普通攻击速度、移动速度、射程沿用独立的35%稀有强化判定；
- 五维、命中、急速、资源百分比、装备说明、单件效果、套装效果和特殊蓝装增伤绝不受强化影响；
- +1～+13材料、金币、装备等级系数、稀有度系数和功能天赋减耗均按该确认稿执行。

## 12. 单件效果与套装效果的装备等级缩放

### 单件和协同散件

- 单件独立效果读取该装备自身等级。
- 协同散件的固定效果读取该散件自身等级。
- 强化等级不参与计算。

### 套装

套装件数只统计新规格明确列出的核心套装件和已经确认的替代武器。协同散件及其他装备不增加套装件数。

```text
rawAverageLevel = 套装生效件的装备等级总和 / 生效件数
setEffectLevel = max(1, floor(rawAverageLevel / 5) × 5)
```

例如穿戴 5 件等级为 20、20、25、25、30 的兽王套装，平均等级为 24，套装效果按 Lv.20 结算。

### 数值缩放分类

伤害、治疗、护盾、伤害增幅、减伤幅度及明确的数值型强化：

```text
magnitudeScale(L) = 1 + (L - 1) / 59
```

Lv.1 为基准值 1.00 倍，Lv.60 为基准值 2.00 倍。

触发概率：

```text
triggerScale(L) = 1 + 0.5 × (L - 1) / 59
```

Lv.1 为基准概率，Lv.60 为基准概率 1.50 倍，最终概率不超过 100%。

以下结构值默认不随装备等级变化，除非某件装备规格明确写出成长规则：

- 套装所需件数；
- 最大层数、目标数量、箭矢数量；
- 内部 CD 和技能基础 CD；
- 触发阈值；
- 控制持续时间；
- 领域、状态和召唤物的基础持续时间；
- “是否生成”“是否复苏”“是否保留层数”等布尔机制。

这样可以保证装备等级提高时效果确实增强，同时不让高等级装备把 3 秒内部 CD、5层阈值或套装件数等结构性护栏破坏。

## 13. 普通无效词条保底

- 通用装备允许对当前弓箭手出现智力、法力和法力%等无效词条。
- 只有本局结算后依法带回的装备才进入保底统计；失败丢弃、主动退出丢弃、暂存区过期移除的装备不计。
- 每获得 1 件“至少含1条当前职业无效普通词条，且没有当前职业适用完美普通词条”的合法装备，计数 +1；每件最多计1次。
- 累计到 10 次后，下一件合法掉落的通用精良或更高装备保证至少出现1条当前职业有效的完美普通词条。
- 如果累计期间自然出现当前职业有效的完美普通词条，计数立即归零。
- 保底被消费后归零。
- 保底不额外生成装备、不提高装备稀有度、不替换固定机制、不改变特殊蓝装伤害增幅。

## 14. 特殊蓝装

- 只有精英和 Boss 掉落且已经判定为精良（蓝色）的装备，才进行特殊蓝装判定。
- 精英蓝装成为特殊蓝装的概率为 5%；Boss 蓝装为 10%。
- 不额外制造掉落，只转换该件已经生成的蓝装。
- 额外伤害类型共8种且等权：物理、电、火、冰、水、自然、风、光，各12.5%。
- 增幅 roll：+1%～+10%占65%；+11%～+20%占15%；+21%～+30%占10%；+31%～+40%占5%；+41%～+49%占3%；恰好+50%占2%。区间内部等概率。
- 该值掉落后固定，不随装备等级、强化或重铸变化。
- 同时最多装备2件特殊蓝装；尝试装备第3件时直接阻止，不自动替换。
- 同类型多件连乘；混合伤害各自只吃对应类型增幅。
- 增幅在普通伤害修正与护甲／减伤结算后再计算；仍属于同一次命中，不额外触发印记、能量或命中事件。
- 增幅后的实际伤害用于击杀归属、伤害统计和原本依赖实际伤害的效果判定。
- 不增加特殊角标；详情只正常显示伤害类型和数值。
- 当前弓箭手没有水系技能或普通攻击链，因此水系特殊蓝装对当前弓箭手是无效词条装备。
- 水系无效词条装备合法带回时，可进入第13节的10次无效词条保底计数；后续角色或技能若实际存在水系伤害，则按当时职业有效性重新判定。

## 15. 装备取得和结算边界

- 成功通关：本局新获得装备全部带回；容量不足时进入结算暂存区。
- 战斗失败：只带回死亡时实际穿戴的本局新装备；本局背包内装备及替换下来的本局新装备直接丢弃，不分解。
- 主动退出、强退或断网：本局新装备不带回。
- 进入关卡前已经拥有的仓库、背包和已穿戴装备永不因失败删除。
- 暂存区装备保留7个自然日，超时后直接移除，不自动分解。
- 所有分解由玩家主动操作。

## 16. 已确认结论

采用本稿作为第二组装备数值方案，重点包括：

1. 5级掉落档位和最多高于角色5级；
2. 各稀有度普通词条数量；
3. 五维固定点数和百分比区间；
4. 八个防具部位的固有护甲表；
5. 生命／法力／体力固定值与百分比区间；
6. 命中、攻速、急速三档以及 Lv.60 的1.5倍档；
7. 强化系统改由第11节引用的独立确认稿完整覆盖，旧“最高+8、永不失败”规则废弃；
8. 固定数值效果 Lv.60 为基准2倍，触发概率 Lv.60 为基准1.5倍，结构性数值默认不缩放；
9. 套装平均等级向下落到5级档位；
10. 无效词条保底、特殊蓝装和成功／失败装备结算继续沿用已确认规则。
11. 五维每点精确换算、命中／闪避和护甲／破甲公式按本稿执行。
12. 当前弓箭手的水系特殊蓝装属于无效词条装备，但保留为未来职业的通用掉落。
