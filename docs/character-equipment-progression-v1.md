## 2. 不可变边界

- 角色经验是局外长期成长；蓝晶经验仍只服务单局战斗天赋，两者完全分离。
- 弓箭手升级后的五维由系统自动分配，不增加手动属性加点。
- 装备等级与强化等级是两套系统。
- 强化只影响允许强化的面板直接属性，不提高五维、装备等级、词条品质、单件说明、协同散件效果、套装效果、特殊蓝装增伤或结构机制。
- 单件、协同散件和套装固定效果只按装备等级缩放；强化等级不参与。
- 关卡结算不自动分解装备；分解只能由玩家主动操作。
- 现有技能、套装和战斗天赋的具体机制保持不变，除非本文明确规定其数值接口或伤害类型。
- 未明确分类的技能或效果不得因为颜色、名称或旧标签被默认视为物理、元素或法术伤害。

## 3. 装备与材料结算总顺序

### 3.1 装备

- 通关成功：本局新获得装备全部带回；容量不足时进入结算暂存区。
- 正常失败：只带回死亡时实际穿戴的本局新装备；本局背包内装备和替换下来的本局新装备直接丢弃，不分解。
- 主动退出、强制退出、断网或异常中断：本局新装备全部丢弃。
- 入局前已有的仓库、背包和已穿戴装备永不因本局失败删除。
- 暂存区保存七个自然日，超时直接移除，不自动分解。

### 3.2 材料

概率材料严格按以下顺序结算：

```text
最终掉落概率 = 基础概率 × 难度倍率 × 合法天赋相对倍率
```

1. 先完成怪物实例的一次性掉落判定；
2. 固定数量奖励按权威附件规定处理，需长期小数收益的项目使用确定性余量累计；
3. 实际掉落进入本局临时材料账本；
4. 通关成功保留 100%；正常失败对每种实际材料分别保留 30% 并向下取整；主动退出、强退、断网或异常中断为 0；
5. 废除“先按失败保留30%，再计算难度或天赋收益”的旧顺序。

腐蚀史莱姆及其分裂体不掉落任何强化材料；继续沿用其低蓝晶、低装备收益定位。技能召唤物、怪物召唤物、分裂生成物和无限刷新附属单位同样不得产生强化材料。

## 4. 特殊蓝装伤害类型权威补充

特殊蓝装的八类增伤为物理、电、火、冰、水、自然、风、光。混合伤害统一拆分为 `50% 物理 + 50% 对应元素`，两部分分别消费对应增伤，最后仍合并为同一次命中。

当前明确的弓箭手混合伤害：

| 技能／效果 | 伤害类型 | 形态边界 |
| --- | --- | --- |
| 风切箭 | 50%物理＋50%风 | 保留穿刺／风刃行为 |
| 雷链鸣矢 | 50%物理＋50%电 | 必须是跳弹羽箭的电系跳弹进化，不使用旧独立雷箭说明 |
| 霜咬箭 | 50%物理＋50%冰 | 必须是跳弹羽箭的冰系跳弹进化，不使用旧独立冰箭说明 |
| 火羽爆箭 | 50%物理＋50%火 | 爆裂、灼烧按实际伤害段分类 |
| 炽阳扫射 | 50%物理＋50%火 | 每次合法扫射伤害段消费对应增伤 |
| 荆羽呼啸 | 50%物理＋50%自然 | 自然在当前弓箭手体系中代表毒性／荆毒伤害 |
| 星火坠矢 | 50%物理＋50%火 | 落点、持续伤害和结束爆发按各自合法伤害段消费 |
| 冰锁囚笼 | 50%物理＋50%冰 | 冰牢伤害段适用，纯控制事件不制造伤害 |
| 圣光爆点 | 50%物理＋50%光 | 仍是原技能／进化产生的同一次伤害事件 |
| 裂界风暴 | 50%物理＋50%光 | 风暴 Tick 按同一分类，不因名称自动改成风系 |

统一继承规则：

- 主动技能的直接命中、多段、爆炸和持续 Tick 在各自实际伤害段应用一次对应类型增伤，不额外制造命中事件。
- 自然系增伤同时放大中毒状态和合法的额外毒伤 Tick。
- 增幅后的最终实际伤害用于击杀归属、伤害统计和原本依赖实际伤害的效果判断。
- 野兽普通攻击不获得特殊蓝装伤害增幅。
- 群兽号令、万兽行军、兽潮连击、荒野无尽四项独立野兽天赋维持原伤害规则，不获得特殊蓝装伤害增幅。
- 装备、套装或领域自动生成的独立攻击不因复用技能动画而自动继承特殊蓝装增伤；只有权威技能伤害事件明确标记可继承时才适用。
- 水系特殊蓝装对当前弓箭手仍是合法但无效的通用词条，可按附件规则参与无效词条保底。

- 自动化通过不能替代真实浏览器验收。C 负责战斗、掉落、失败／通关和强化链；D 负责数据、存档、装备／强化 UI、响应式和资产验收。

## 7. 强化操作反馈

- 强化按钮不得在材料或金币不足时形成“点击无反馈”。资源不足时允许玩家触发该操作，但不得消耗资源、不得进入强化判定，也不得打开危险强化确认框。
- 强化卡片必须就地显示准确原因：分别列出缺少的材料、缺少的金币以及对应的“当前持有／本次需要”数量；该反馈须支持 `aria-live`，键盘与指针操作结果一致。
- 装备达到稀有度强化上限时可以保持按钮禁用，但卡片必须明确显示“已达到该稀有度强化上限”，不得只依赖按钮禁用态表达。
- 资源充足时沿用既有流程：`+6～+10` 使用普通强化确认，`+11～+13` 使用红色永久碎装风险确认；不得借本条修改概率、成本、失败降级／回到 `+1`／永久碎装、退款或属性倍率。
- 每次实际强化尝试结束后，同一强化区域必须显示成功、失败降级／回到 `+1` 或永久碎装结果，避免结果只存在于不可见的全局消息中。
