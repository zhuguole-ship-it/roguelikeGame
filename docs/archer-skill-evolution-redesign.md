# 弓箭手核心技能、进化、天赋与装备联动重构

更新日期：2026-08-12

## 1. 权威范围

本文件记录用户在 2026-08-12 确认的弓箭手构筑重构，是以下范围的最新权威：

- 主动技能从 `55` 个收敛为 `21` 个核心技能。
- 核心技能 `Lv.1-Lv.5` 成长、`Lv.4` 二选一进化及 `42` 个进化形态。
- 原主动技能退出基础池后的归属、历史存档迁移和技能家族继承。
- 原 `40` 个局内战斗天赋的前置与候选修正。
- 装备核心词缀、套装、相关性判断与技能家族继承。
- 首页图鉴中的进化发现记录、未发现状态和说明交互。
- 程序绘制技能特效与野兽进化的视觉规则。

本文件覆盖旧文档中与 `55/56` 技能基础池、旧 `Lv.1-Lv.5` 线性成长、旧独立技能 ID、旧技能图鉴数量和旧装备技能白名单冲突的内容。未被本文件明确修改的关卡、怪物、掉落概率、装备位、稀有度、强化、分解、重铸、角色选择页冻结坐标和既有 HUD 规则保持不变。

## 2. 已确认的产品目标与输入边界

- 游戏方向为“自动循环、构筑决定胜负”。
- `Q / E / R` 始终由玩家手动释放；不得新增自动施法、自动替玩家选择技能或冷却结束后自动释放。
- 自动化只发生在合法施法之后的构筑链路，例如标记、流血、魂爆、追击、区域联动、野兽协同和终结器。
- 玩家继续通过鼠标方向 / 落点决定技能施放方向和区域；原键位、三技能槽和暂停语义不变。
- 每局最多装备 `3` 个核心主动技能。技能等级、进化选择和局内战斗天赋只在本局有效，回村 / 结束 / 放弃 / 正式重开时清空。
- 进化“发现记录”永久保存，仅用于图鉴收集和说明展示，不提供永久战力、不提高候选权重，也不保证下一局出现。

## 3. 通用成长与进化规则

| 等级 | 固定职责 |
| --- | --- |
| Lv.1 | 获得核心技能基础形态。 |
| Lv.2 | 增加功能性或建立循环条件，不允许只加伤害。 |
| Lv.3 | 提前获得最终质变的低阶版本；限制应来自频率、目标数、持续时间或不可连锁。 |
| Lv.4 | 固定出现两个互斥进化分支，玩家必须二选一；选择后立即更名、更换图标 / 名称占位和特效。 |
| Lv.5 | 只强化已经选择的 Lv.4 分支，不再进行第二次路线选择。 |

实现规则：

- 当一个 `Lv.3` 技能通过奖励升级到 `Lv.4` 时，先暂停原奖励推进，打开只含该技能两个分支的强制二选一；完成选择后才结算 Lv.4 并继续流程。
- 进化分支不能作为 `new-active` 进入基础技能池，也不能占用额外主动槽。
- 运行时保持稳定 `familyId`（即 21 个核心技能 ID），另存 `evolutionId`。展示名称、图标、特效与行为读取 `evolutionId`；奖励、天赋、装备相关性和自动分解读取 `familyId + evolutionId`，不得只依赖当前显示名称。
- 两个分支均继承核心技能家族的装备、套装和天赋；分支可显式转换不适用的效果。例如聚焦分支遇到“扇面扩大”时，转换为中心箭密度 / 伤害，不能重新扩大角度。
- Lv.5 只升级当前 `evolutionId`。未选择分支的 Lv.5 效果不得同时生效。

## 5. 穿透 / 死契技能设计

### 5.1 穿刺箭

- Lv.1：发射直线箭，穿透 `2` 名敌人。
- Lv.2：每穿透一名敌人，后续命中伤害提高 `8%`，最多 `24%`。
- Lv.3：最后一名被穿透的敌人额外受到 `20%` 伤害。
- Lv.4 `风切箭`：高速青绿色风刃；命中附加 `2s` 流血，首个目标禁锢 `0.5s`。
- Lv.5 `风切箭`：禁锢提高至 `1s`；流血持续 `4s`、总伤害为本次命中的 `45%`；穿透 3 名敌人后自动追加一道 `45%` 伤害风刃。
- Lv.4 `贯日长虹`：变成长距离金色贯穿线，将普通怪拉向箭轨；精英只吃一半拉力，Boss 不位移。
- Lv.5 `贯日长虹`：射程进一步提高；对精英 / Boss 伤害 `+30%`；最后一名被穿透敌人额外受到 `35%` 伤害。
- 特效：基础为金黄细长箭线和白色穿透火花；风切为青绿风刃、切割残影和脚下风环；贯日为粗金色光线、两侧吸附轨迹和命中冲击环。

### 5.2 重矢狙击

- Lv.1：射出超远距离高伤重箭。
- Lv.2：只命中一个目标时伤害 `+15%`。
- Lv.3：命中远距离或低血目标时伤害 `+25%`。
- Lv.4 `破晓圣矢`：距离越远伤害越高，最高 `+55%`。
- Lv.5 `破晓圣矢`：最远距离增伤提高至 `+80%`；在最高增伤区命中精英 / Boss 时返还 `15%` 冷却。
- Lv.4 `弱点追索`：自动追踪范围内生命百分比最低目标；目标低于 `30%` 生命时伤害 `+30%`。
- Lv.5 `弱点追索`：目标低于 `20%` 生命时伤害 `+50%`；击杀后向另一名低血敌人追加一支 `55%` 伤害追索箭。
- 特效：基础为方向蓄力线和粗重箭；破晓为白金长箭且随飞行距离增亮 / 增宽；弱点为紫色锁定圈、弯曲追踪线和低血裂纹。

### 5.3 反曲回箭

- Lv.1：箭矢去程与返程各可命中一次。
- Lv.2：返程箭轻微追踪最近敌人。
- Lv.3：同一敌人同时被去程 / 返程命中时，第二次伤害 `+25%`。
- Lv.4 `双星追击`：变为两枚独立星矢，返程分别寻找目标。
- Lv.5 `双星追击`：同目标被第二枚星矢命中时伤害 `+50%`；有其他目标时优先分散追击。
- Lv.4 `苍穹审判`：变为 `3` 条平行审判箭线，全部拥有去程与返程。
- Lv.5 `苍穹审判`：增加至 `5` 条；去返程交汇处产生爆点并留下 `2s` 星火区域，吸收原`星羽裁决`机制。
- 特效：基础去程亮黄、返程半透明弧线；双星为白金星点和弧形返程；苍穹为平行金轨、交汇爆光和星火圆区。

### 5.4 跳弹羽箭

- Lv.1：射出 `2` 枚羽箭，每枚独立弹跳 `3` 次。
- Lv.2：不会立即重复弹回刚命中的目标，优先寻找新敌人。
- Lv.3：每完成第 `3` 次弹跳产生一次 `25%` 伤害小范围震击。
- Lv.4 `雷链鸣矢`：变为雷矢，可连续弹跳 `5` 次，每次产生小范围电击。
- Lv.5 `雷链鸣矢`：增加至 `6` 次；每第 `3` 次弹跳眩晕周围普通怪 `1s`，精英减半，Boss 只短暂减速；吸收原`震荡箭`机制。
- Lv.4 `霜咬箭`：每次弹跳施加一层 `15%` 减速，最多 `3` 层。
- Lv.5 `霜咬箭`：3 层冻结普通怪 `1.2s`；冻结目标死亡时向附近敌人传播 `2` 层霜咬。
- 特效：基础为黄色折线跳跃轨迹；雷链为蓝白电弧和圆形震击波；霜咬为淡蓝弹道、冰晶碎片、叠层外框和冻结表现。

### 5.5 猎杀印记

- Lv.1：标记目标；后续主动技能命中触发小爆裂，内置冷却 `2s`。
- Lv.2：优先标记精英、Boss 或尚未标记的高血目标。
- Lv.3：标记累计受到 `3` 次主动技能命中后进入暗蚀，下一次命中产生强化爆裂；目标死亡时标记转移给最近敌人。吸收原`暗蚀影箭`机制。
- Lv.4 `裂甲钉矢`：标记目标每次受到主动技能命中时获得 `4%` 易伤，最多 `3` 层。
- Lv.5 `裂甲钉矢`：每层提高至 `5%`、最多 `4` 层；死亡时标记最多扩散给 `3` 名敌人；精英 / Boss 遵守易伤上限。
- Lv.4 `火羽爆箭`：标记爆裂附加灼烧；标记目标死亡时产生火焰爆炸。
- Lv.5 `火羽爆箭`：爆炸范围提高；最多向 `3` 名敌人传播灼烧和低阶标记。
- 特效：基础为黑红脚下符文和内缩爆裂；裂甲为黑铁钉矢、逐层裂甲纹与碎甲粒子；火羽为橙红羽箭、火焰爆点和飞散火羽。

## 6. 散射 / 血羽技能设计

### 6.1 三连快射

- Lv.1：连续射出 `3` 支高速箭。
- Lv.2：第 3 支额外穿透 `1` 名敌人。
- Lv.3：变为 `4` 连射，最后一箭暴击率 `+30%`。
- Lv.4 `疾风连矢`：变为 `7` 连高速细箭；同目标命中 3 次后流血。
- Lv.5 `疾风连矢`：变为 `9` 连射；每第 3 次命中自动产生一支 `50%` 伤害侧向细箭。
- Lv.4 `终幕追射`：变为 `5` 连追踪箭，优先攻击生命最低目标；低于 `30%` 生命时伤害 `+25%`。
- Lv.5 `终幕追射`：最后一箭必定暴击；低于 `20%` 生命时总伤害 `+45%`；击杀后向下一名低血目标追加 2 箭。
- 特效：基础为三条短黄拖尾；疾风为青色密集细箭和侧向残影；终幕为金色锁定圈、弯曲追踪线和最后一箭高亮。

### 6.2 扇形散射

- Lv.1：向前方扇形射出 `5` 支箭。
- Lv.2：中心箭伤害 `+15%`。
- Lv.3：扇面收窄 `10%`，中心箭伤害提高至 `+25%`。
- Lv.4 `双月弧矢`：变为左右两道宽弧箭幕，交汇位置可重复命中。
- Lv.5 `双月弧矢`：弧矢末端向内回折；交汇区命中附加 `25%` 减速。
- Lv.4 `鹰翼掠射`：两翼箭列向中心夹击，范围较窄但中心命中密度提高。
- Lv.5 `鹰翼掠射`：两翼各追加一列箭羽；夹击区伤害 `+40%` 并短暂施加破绽。
- 特效：基础为黄色扇形预览；双月为淡紫月牙箭轨；鹰翼为白金羽翼轮廓和向中心收束的箭列。

### 6.3 箭幕推进

- Lv.1：射出 `8` 支平行箭，形成推进箭墙。
- Lv.2：箭墙命中造成 `10%` 短暂减速。
- Lv.3：`0.4s` 后自动复制一轮 `30%` 伤害次级箭墙。
- Lv.4 `月碎连矢`：变为两轮冰冷箭墙，每轮命中叠加减速。
- Lv.5 `月碎连矢`：增加至三轮；最后一轮使已减速敌人产生月碎爆裂。
- Lv.4 `炽阳扫射`：变为横向扫过的炽热箭列，命中附加灼烧。
- Lv.5 `炽阳扫射`：第一次扫射结束后从反方向追加一轮 `60%` 伤害扫射；灼烧目标死亡留下小型火点。
- 特效：基础为向前移动的半透明平行箭墙；月碎为蓝紫多轮箭墙和月牙碎片；炽阳为橙红扫线、火焰拖尾和反向箭墙。

### 6.4 残影齐射

- Lv.1：连续多段延迟射出同向箭列。
- Lv.2：后续箭列轻微追踪第一轮命中的目标。
- Lv.3：结束 `0.5s` 后自动复制一次 `30%` 伤害残影。
- Lv.4 `光羽裂变`：残影箭命中后裂变为 `2` 支小箭。
- Lv.5 `光羽裂变`：裂变为 `4` 支；多枚小箭命中同一区域时产生圣光爆点。
- Lv.4 `连锁折射`：残影箭命中后向附近敌人折射 `2` 次。
- Lv.5 `连锁折射`：提高至 `4` 次；折射轻微牵引下一目标，并优先寻找未命中的敌人。
- 特效：基础实体箭列后叠递减透明残影；光羽为白金分叉细箭；折射为连接目标的蓝色折线和短光点。

### 6.5 螺旋破空

- Lv.1：召唤旋转箭束环绕玩家并向外扩张。
- Lv.2：同敌人被多枚旋转箭命中时后续伤害逐步提高，最多 `20%`。
- Lv.3：每第 `3` 次释放自动追加一轮 `50%` 伤害螺旋残影。
- Lv.4 `交叉切射`：改为在敌人最密集处形成 X 形交叉箭轨。
- Lv.5 `交叉切射`：追加一个旋转 `45°` 的第二组 X；交点爆裂并附加流血。
- Lv.4 `血嗅追猎`：螺旋箭束脱离玩家，追踪流血或低血敌人。
- Lv.5 `血嗅追猎`：目标死亡后剩余箭束转移给下一目标，并返还 `30%` 冷却；每次释放最多触发一次。
- 特效：基础为围绕玩家旋转并外扩的箭束；交叉为红色 X 轨和中心爆点；血嗅为深红箭环和目标间追猎轨迹。

## 7. 控制 / 蓝晶技能设计

### 7.1 箭雨坠落

- Lv.1：在目标区域周期降下箭雨。
- Lv.2：区域中心伤害 `+20%`。
- Lv.3：每第 `3` 轮落箭追加一支 `160%` 伤害中心重箭。
- Lv.4 `流星箭簇`：区域缩小，周期坠落 `3` 支高伤流星箭。
- Lv.5 `流星箭簇`：增加至 `5` 支；落地后裂成 `4` 枚低伤碎箭。
- Lv.4 `千羽暴雨`：区域扩大 `25%`，落箭密度提高，单支伤害略低。
- Lv.5 `千羽暴雨`：每轮追加中心主箭；结束时所有箭羽向中心收束一次。
- 特效：基础为黄色预警圆和周期细箭；流星为金橙坠落线、爆点和四向碎箭；千羽为大范围白色细雨和中心收束。

### 7.2 毒藤箭

- Lv.1：生成持续毒伤和减速区域。
- Lv.2：敌人在区域内停留越久，毒伤越高，最多 `3` 层。
- Lv.3：两个毒藤区域重叠时触发小型荆毒缠绕，内置冷却 `2s`。
- Lv.4 `荆羽呼啸`：区域边缘生成荆棘；敌人离开区域时短暂束缚。
- Lv.5 `荆羽呼啸`：区域重叠触发强化荆毒爆发；中毒敌人死亡后向附近射出 `3` 枚荆刺。
- Lv.4 `星火坠矢`：毒藤转为火焰区域，取消减速并改为叠加灼烧。
- Lv.5 `星火坠矢`：区域结束时爆发；灼烧敌人死亡留下 `1.5s` 小型星火区域，同屏数量有上限。
- 特效：基础为半透明绿色毒区、毒雾与藤纹；荆羽为边缘藤条和外射荆刺；星火为橙色燃烧区、暗红火点和结束爆发。

### 7.3 猎网箭

- Lv.1：生成束缚网区域，持续减速。
- Lv.2：敌人首次进入中心区域时被轻微向内牵引。
- Lv.3：区域结束时收网，使残留普通怪定身 `0.6s`。
- Lv.4 `绊索箭`：圆区改为长绊索；敌人跨越时受到伤害和定身。
- Lv.5 `绊索箭`：绊索可重新武装 `2` 次；同敌人触发 3 次后定身 `1.2s`。
- Lv.4 `冰锁囚笼`：变为冰冷圆形囚笼；区域命中累积冰锁层数。
- Lv.5 `冰锁囚笼`：3 层冻结普通怪 `1.5s`；区域结束时囚笼碎裂并造成范围伤害。
- 特效：基础为灰白网格圆区和中心牵引线；绊索为地面直线和收紧闪光；冰锁为淡蓝圆环、冰柱和碎裂粒子。

### 7.4 陷坑钉射

- Lv.1：生成延迟触发的地刺陷阱。
- Lv.2：地刺命中施加短暂破甲。
- Lv.3：陷阱结束时向前后释放两条低伤地刺线。
- Lv.4 `死线锁定`：改为依次触发 `3` 条平行地刺线。
- Lv.5 `死线锁定`：增加至 `5` 条；中心线追加处刑主箭，对低血目标伤害提高。
- Lv.4 `穹顶压制`：扩大为穹顶区域，地刺从边缘向中心收缩。
- Lv.5 `穹顶压制`：结束时中心收束爆发，并将普通怪拉向中心。
- 特效：基础为棕黑陷坑和上弹地刺；死线为红色预警线和依次升起的黑刺；穹顶为暗金透明圆顶和内缩地刺环。

### 7.5 裂界风暴

- Lv.1：生成大型持续风暴领域。
- Lv.2：两个风暴重叠时，重叠区攻击频率提高 `15%`，不可无限叠加。
- Lv.3：风暴结束时向外释放 `6` 枚低伤风刃。
- Lv.4 `旋羽风暴`：风暴缓慢追踪敌人最密集区域。
- Lv.5 `旋羽风暴`：结束时释放 `12` 枚风刃；同敌人被 3 枚命中后流血。
- Lv.4 `苍穹连雨`：风暴固定，中心每 `1.2s` 坠落一支蓝羽主箭。
- Lv.5 `苍穹连雨`：每次主箭落地产生蓝晶脉冲；区域重叠时脉冲范围提高。
- 特效：基础为紫色旋流、低透明风暴和闪电粒子；旋羽为粉白移动旋风与环形风刃；苍穹为深蓝领域、垂直主箭和脉冲环。

## 8. 野兽伙伴技能设计

野兽共同规则：

- 首次释放召唤对应野兽，后续手动释放改为下达专属指令。
- 野兽自动攻击，倒地后按既有复苏系统返回；不需要玩家重复获得技能。
- 单体首领进化在战斗渲染中的可见体型为基础野兽的 `2.0x`，保持原脚点 / 锚点，不改变碰撞体、受击范围、寻路半径或数值，除非具体技能条款另有明确机制。
- 群体 / 变体进化保持基础野兽体型；群体路线常驻同屏上限 `3` 只。

### 8.1 霜狼护阵

- Lv.1：召唤霜狼环绕玩家并攻击最近敌人。
- Lv.2：攻击附加 `10%` 减速。
- Lv.3：每完成 5 次攻击自动嚎叫，使附近敌人减速 `20%`，持续 `2s`。
- Lv.4 `寒月狼王`：单只狼王，获得攻速光环与更强减速。
- Lv.5 `寒月狼王`：嚎叫冻结普通怪 `1s`；玩家与其他野兽攻速 `+10%`，持续 `3s`。
- Lv.4 `霜牙狼群`：替换为 2 只各 `60%` 强度霜狼，自动夹击同一目标。
- Lv.5 `霜牙狼群`：增加至 3 只各 `55%` 强度；三狼同时攻击触发协同撕咬。
- 特效：基础蓝白狼影与冰爪；狼王为大型狼影、月环和冰霜嚎叫圈；狼群为基础体型狼影、三角夹击线和撕咬闪光。

### 8.2 灵鹿庇护

- Lv.1：召唤灵鹿，每 `6s` 为玩家生成最大生命 `6%` 护盾。
- Lv.2：护盾期间提高少量移动速度。
- Lv.3：护盾被打破时恢复 `3%` 最大生命，内置冷却 `8s`。
- Lv.4 `圣角灵鹿`：单只圣角灵鹿，护盾提高至 `10%`，并清除一次减速或束缚。
- Lv.5 `圣角灵鹿`：护盾破裂时产生治疗脉冲，同时保护附近野兽。
- Lv.4 `幻林鹿群`：2 只幻鹿，在路径留下短暂加速区域。
- Lv.5 `幻林鹿群`：增加至 3 只；幻鹿致命伤时留下治疗区域，并略微缩短其他野兽复苏时间。
- 特效：基础米白鹿影、金角和透明护盾；圣角为大型金角鹿、白金护盾和绿波；鹿群为基础体型半透明鹿影、绿色足迹与治疗区。

### 8.3 林熊护卫

- Lv.1：召唤林熊，自动嘲讽附近近战敌人。
- Lv.2：受到的近战伤害降低 `15%`。
- Lv.3：累计承受 5 次攻击后自动践踏，击退附近普通怪。
- Lv.4 `铁壁熊王`：单只熊王，扩大嘲讽范围并获得 `25%` 减伤。
- Lv.5 `铁壁熊王`：玩家受到高额伤害时自动拦截一次并立刻践踏，内置冷却 `12s`。
- Lv.4 `狂怒战熊`：嘲讽范围缩小、攻速提高；生命越低伤害越高。
- Lv.5 `狂怒战熊`：低于 `40%` 生命时连续践踏 3 次，随后获得短暂护盾。
- 特效：基础深绿棕熊、嘲讽红圈与盾牌闪光；熊王为大型轮廓、盾符文和震波；战熊保持基础体型并显示红棕怒气与连续震环。

### 8.4 毒蛇伏击

- Lv.1：召唤毒蛇伏击目标区域，攻击并叠加中毒。
- Lv.2：中毒最多 `3` 层。
- Lv.3：达到 3 层时产生小型毒爆。
- Lv.4 `蚀骨蛇后`：单只蛇后，毒爆附加破甲。
- Lv.5 `蚀骨蛇后`：毒爆消耗层数后立即补回 1 层；精英 / Boss 获得受上限约束的持续蚀骨易伤。
- Lv.4 `万毒蛇巢`：变为固定蛇巢，周期召唤 2 条临时小蛇攻击不同目标。
- Lv.5 `万毒蛇巢`：最多 3 条小蛇；中毒敌人死亡时小蛇立即转移并传播 1 层毒。
- 特效：基础黄绿蛇影、曲线路径和毒圈；蛇后为大型蛇影、黑绿毒牙和毒爆圈；蛇巢保持基础体型小蛇、地面巢穴和多条追踪曲线。

### 8.5 野猪冲阵

- Lv.1：召唤野猪沿直线冲锋并击退普通怪。
- Lv.2：冲锋附加短暂破甲。
- Lv.3：主野猪冲锋后自动追加一只 `35%` 伤害残影野猪。
- Lv.4 `破阵獠王`：单只巨大獠王，冲锋距离和击退能力提高。
- Lv.5 `破阵獠王`：冲锋结束自动折返一次；同敌人被去返程命中时受到额外破甲伤害。
- Lv.4 `山崩兽潮`：一次召唤 3 只基础体型野猪并排冲锋。
- Lv.5 `山崩兽潮`：每第 3 次释放额外产生一轮垂直方向兽潮，形成交叉冲阵。
- 特效：基础为金棕轮廓、直线尘土与撞击碎石；獠王为大型轮廓、粗尘浪和折返线；兽潮为三条平行轨迹与交叉尘浪。

### 8.6 猛禽俯冲

- Lv.1：召唤猛禽沿直线俯冲。
- Lv.2：优先攻击精英、Boss 或被标记敌人。
- Lv.3：只命中一个目标时自动折返一次，折返造成 `35%` 伤害。
- Lv.4 `天穹鹰王`：单只鹰王，俯冲伤害提高并施加猎杀破绽。
- Lv.5 `天穹鹰王`：命中精英 / Boss 后追加第二次俯冲；命中破绽目标时给玩家短暂暴击率。
- Lv.4 `暗夜隼群`：3 只基础体型暗隼，分别追击低血或被标记敌人。
- Lv.5 `暗夜隼群`：目标死亡后未完成攻击的暗隼自动转移；三隼集中同一目标时触发暗夜撕裂。
- 特效：基础金色鸟影和垂直锁定线；鹰王为大型金鹰、俯冲爆光和破绽符号；隼群为三个紫黑鸟影、追踪曲线和暗色裂痕。

## 9. 百兽协猎传奇战斗天赋

- `百兽协猎`不再作为主动技能，也不占技能槽。
- 候选前置：本局至少拥有 `2` 种不同野兽核心技能，且至少一只野兽完成 Lv.4 进化。
- 效果：每完成 `3` 次野兽指令，自动召唤两种未装备野兽的幻影协助 `6s`。
- 当已装备野兽达到 Lv.5 条件时，幻影可继承对应野兽的低阶专属动作，但不继承完整首领光环。
- 内置冷却 `18s`；幻影数量、持续时间与同屏召唤遵守既有上限，不得形成永久无限兽群。
- 特效：玩家脚下白色环形契约符文；幻影为半透明白色并保留物种边缘色，结束前淡出为粒子。

## 10. 原 40 个战斗天赋的最小调整

原 `40` 个节点保留，不整体删除或重写；本轮只修复无效前置和候选锁死问题。已暂缓的旧“新增 32 个形态天赋”不进入本轮实现；技能 Lv.4 进化是技能系统，不复用那 32 个天赋节点。

### 10.1 前置与即时有效性

- 所有候选在玩家选中后必须立即产生有效战斗作用；依赖尚未拥有的启动器、技能家族或数量条件时不得出现。
- 通用 8 节点保持独立，不增加互相前置。
- 死契：`处刑线 / 穿透魂火 / 标记扩散 / 贯穿审判`要求`死契标记`；`魂爆初醒`要求`死契标记`；`精英破契`要求`魂爆初醒`；`死契连锁`要求`标记扩散 + 魂爆初醒`。
- 血羽：`暴击羽裂 / 血羽连射`要求`血羽印记`；`血裂追击 / 精英放血`要求`流血箭簇`；`血羽风暴`要求`血羽印记 + 血羽连射`；`散射织网`保持独立，但只在拥有散射核心技能时出现。
- 兽王：所有兽王节点要求至少拥有 1 个野兽核心技能；`指令突袭 / 护主本能 / 复苏律令`要求`主兽绑定`；`协同撕咬`额外要求拥有至少 2 种野兽核心技能；`Lv5 首领化`要求`主兽绑定`且至少一只野兽技能达到 Lv.4；`光环扩散`要求`Lv5 首领化`；`百兽合围`要求`协同撕咬`且拥有 3 种野兽核心技能。
- 蓝晶：`冷却导流 / Lv5 蓝晶过载`要求`蓝晶充能`；`脉冲共鸣`要求`Lv5 蓝晶过载`；`领域延展 / 精英缓蚀 / 晶域连锁`要求至少拥有 1 个控制 / 领域核心技能，其中`精英缓蚀`要求`领域延展`。
- 局内等级门槛继续保留，但“达到等级”不能替代上述机制前置。Lv.5 保证位若突破节点前置不满足，应保证一个可立即生效的启动器，而不是强塞无效突破节点。

### 10.2 候选生成

- 删除“所有非开局流派统一 `-25`”规则和“最多只允许一个跨流派候选”的硬限制。
- 开局流派只影响本局前 `2` 次战斗天赋候选，之后归零；不得永久锁定整局。
- 当前拥有的核心技能家族、已选进化、已选天赋链和装备标签决定实时相关性，权重高于开局流派。
- 三候选默认角色：至少 1 个强化当前有效循环；至少 1 个提供合法转型 / 次流派路线；最多 1 个通用生存、经济或便利节点。若对应池为空，可用其他立即有效的战斗节点补位。
- 元天赋提供第四候选时，第四位从所有立即有效节点中按实时相关性抽取，不破坏上述三类保底。
- 跨流派节点只有在与当前技能 / 进化 / 装备完全无关时才降低相关性；存在真实标签关联时正常参与，不因“不是开局颜色”被处罚。
- 已有两次没有当前主要循环候选时，下一次保证 1 个当前循环候选；该保证不能绕过前置。

## 11. 装备与套装联动

### 11.1 保留的装备底层

以下内容不因本轮重做：12 装备位、开放节奏、7 档稀有度、装备分数、掉率、Boss 传承保底、10 把 Boss 武器、强化、分解、材料、重铸、锁定和四套装备名称 / 美术主题。

### 11.2 必须调整的联动层

- 所有技能专属装备从“旧独立技能 ID 白名单”迁移为“核心技能家族 + 可选进化分支”匹配。
- 旧技能成为进化后自动继承其核心家族装备；装备不能直接解锁进化、不能绕过 Lv.4 二选一，也不能让两个互斥分支同时生效。
- `审判之弦`改为作用于合法直线核心家族及其进化；不得继续引用已退出基础池的孤立 ID。
- `扇面扩张`只扩大宽扇分支；对聚焦分支转换为中心箭密度 / 中心伤害，不能重新扩大总夹角。
- `千羽王令`只服务散射循环：每 3 次散射施法后下一次重复 / 残影；移除其对穿透系跳弹羽箭的混合绑定。
- `万兽赦令`通过野兽指令循环触发；存在`百兽协猎`传奇天赋时获得额外幻影强化，但装备本身不能赠送该传奇天赋。
- 装备相关性、黄色构筑符文提示、定向掉落、装备对比和自动分解保护必须读取核心家族、进化分支和实际循环标签。任何强化当前进化的装备都不能因旧 ID 不匹配被当作无关装备分解。

### 11.3 套装机制

四套装备继续使用`docs/campaign-progression-equipment-redesign.md`既有的机制型 `2 / 4 / 6` 件表：死契标记 / 魂爆 / 处刑破契，血羽流血 / 追击 / 风暴，兽魂复苏 / 协同 / 首领赦令，吸晶加速 / 过载脉冲 / 蓝晶领域。当前运行时若仍是纯数值 2 / 4 件效果，应迁移到该机制表，不另造第二套倍率。

同一机制同时来自天赋和套装时：

- 只创建一份规范化战斗状态和一次触发事件。
- 第二来源作为触发率、数量、半径、持续时间、内置冷却或上限内强度的增强，不得重复建立标记、重复魂爆、重复扣充能或双倍召唤。
- Boss 不吃处刑秒杀、无限控制、永久减速或无限冷却返还；既有软 / 硬上限继续有效。

- 发现记录只存稳定 `evolutionId` 集合；缺字段的旧存档迁移为空集合。正式回村清空本局 `evolutionId` 时不得清空发现集合。

## 13. 特效清晰度与程序绘制验收

- 初期使用引擎绘制的直线、弧线、圆环、透明领域、拖尾、粒子、残影、简化兽影和状态符号；不得用无限粒子数量冒充精细度。
- 每个技能至少包含“施法预告 / 弹道或领域主体 / 命中反馈”三层；进化后至少有颜色、轨迹或触发节奏中的两项明显变化。
- 四流派主色必须稳定：死契黑红 / 金、血羽深红 / 紫、蓝晶蓝 / 青、野兽按物种边缘色；同屏混合时仍可一眼分辨来源。
- 程序线条、圆环和文字在 `390×844`、`1280×720`、`1920×1080` 下必须清楚，不出现半像素抖动、裁切、坏图、整块不透明背景或提示层超出视口。
- 大范围箭雨、风暴、兽群和连锁不得遮蔽敌人轮廓、危险预警、玩家位置和 Boss 关键动作；高亮集中在命中瞬间，持续区域降低透明度。
- 单体首领野兽 `2.0x` 只改变战斗可见体型，保持底部脚点，不裁掉头部 / 尾部，不改变碰撞、寻路和图鉴适配尺寸；群体 / 变体保持基础体型。
- 弹道、区域、连锁目标、临时召唤、残影和粒子均需硬上限；高密度战斗不允许无界数组、永久对象或按全实体无界 `O(n²)` 查找。
- 开发完成后必须进行实机视觉迭代；仅通过单元测试不能宣称特效精细度和清晰度已验收。

## 14. 旧局内存档迁移

- 30 个已转为进化的旧主动技能：迁移为对应核心 `familyId`，保留原进化身份；为保证身份有效，迁移后等级至少为 Lv.4，原等级更高时保留至 Lv.5 上限。
- `震荡箭`迁移为`跳弹羽箭 + 雷链鸣矢`；`暗蚀影箭`迁移为至少 Lv.3 的`猎杀印记`；`星羽裁决`迁移为 Lv.5 的`反曲回箭 + 苍穹审判`。
- 旧`百兽协猎`主动技能迁移为`猛禽俯冲`同等级（最高 Lv.5）并授予本局`百兽协猎`传奇天赋；只迁移当前局，不写入局外永久战力。
- 迁移不得产生第四主动槽、重复同一核心家族或破坏冷却序列。发生家族冲突时保留等级 / 进化更高者，另一个槽按安全规则空出并由后续奖励补齐。
