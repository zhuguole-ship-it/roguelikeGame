## 一句话定义

高细节像素插画风格的古老地牢界面：被黑铁与旧铜铸成的建筑式外框包裹，嵌入蓝晶石，置于潮湿石墙、拱门和幽绿火把的空间中；整体庄重、幽暗、有重量，但关键交互保持清楚可读。

## 视觉语法

### 材质与颜色

- 主底色是近黑绿的石墙、阴影与湿冷空气，不使用纯黑的大块留白代替环境。
- 框架以锻造黑铁、枪灰金属和磨损古铜构成，需要可读的亮边、暗面、铆钉、接缝、划痕或裂纹。
- 蓝晶石是常规交互、选中、结构节点与低频强调色；只能作为局部镶嵌和克制的微光，不能扩散成大面积霓虹蓝。
- 金色/旧铜用于标题、关键边框、稀有奖励和完成状态；红色只用于危险、失败、伤害或敌对状态；幽绿色仅用于火把、苔痕或环境魔法。
- 同一画面必须同时保留深色基底、暖色金属高光和冷色蓝晶石，避免单一色相统治整个界面。

### 构图与层级

- 页面由一圈完整的建筑式外框收束，背景需要有可见的地牢环境深度，而不是悬浮在纯色页面上的卡片集合。
- 大标题或当前章节使用居中的金属铭牌；主要内容使用少量层级清晰的大面板，而不是均匀分布的 Dashboard 卡片。
- 主内容可采用“一块重点展示区 + 一列或两列功能区”的非对称构图；次级信息放入相同材质的小面板，保持共同边线和角饰节奏。
- 面板内优先使用明确的图标、短标题、关键数值和一层说明。常驻战斗 HUD 继续让出地图中心与下中部，不能因装饰吞没可玩区域。
- 圆角、玻璃拟态、渐变色块、无边框悬浮卡、现代 SaaS 表格和普通浏览器按钮不属于该风格。

### 像素与文本

- 轮廓、金属高光、晶石切面和石墙纹理都要有像素插画的硬边与分层，不使用模糊照片、平滑矢量渐变或低细节矩形替代。
- 动态中文文本保持真实文字以支持可读性和响应式布局；标题可以用金色像素字或金属铭牌承载，正文用高对比、克制的浅灰/暖白文字。
- 文字不得被花纹、边框或环境装饰挤压。窄屏时优先重排与收起次要内容，不能等比缩小到不可读。

### 状态与动效

- 普通悬停/聚焦使用细微边框提亮、蓝晶石微光或压下反馈；危险、失败、奖励和升级才使用更强的红/金闪现。
- 火把、晶石、环境雾和奖励光粒可以低频呼吸或闪烁；禁止所有控件同时漂浮、弹跳或持续发光。
- 尊重 `prefers-reduced-motion`，非必要光效和动画必须可静止。

## 各场景落地

| 场景 | 必须保留的风格特征 | 需要避免 |
| --- | --- | --- |
| 首页、村庄入口、角色/装备页 | 地牢建筑式外框、环境石墙/拱门、居中铭牌、少量大面板 | 把森林村庄改成室内地牢；把概念中的多职业当成功能范围 |
| 战斗 HUD | 黑铁细边、古铜关键框、蓝晶石状态点、明确像素图标 | 宽大的上下黑条、覆盖地图中心的复杂面板、纯 CSS 占位条 |
| 暂停、奖励、结算 | 居中标题铭牌、分层深色面板、金色奖励/红色失败状态 | 现代白底模态框、廉价彩虹发光、无层级的等宽卡片阵列 |
| 地穴、Boss 场景 | 潮湿石材、拱门、火把、苔痕、幽绿环境光与黑铁遗迹细节 | 无解释的纯黑边界、平铺单色地面、与 UI 脱节的明亮卡通背景 |

## 资产与实现边界

- 权威锚点只用于审美判断和构图参考，禁止整张图、整块棋盘底或白底直接进入运行时画面。
- 这张源图目前没有 Alpha 通道。若需复用其中的局部素材，必须复制到项目受控目录后完成裁切、去底、透明 PNG 导出、命名、尺寸记录和运行时相对路径接入。
- UI 优先使用项目内透明资产、CSS 布局和真实文本；不得通过截图拼接、外部绝对路径读取或把文字烘焙到不可访问的位图中规避布局问题。
- 所有新页面与现有 HUD 在 `2560x1440`、`1600x1000`、`1280x720`、`1024x768`、`768x1024`、`390x844` 下都必须保持文字、控件和地图可达，不重叠、不裁切、无横向滚动。

## 设计评审清单

- 截图脱离文字后，是否仍能读出黑铁、古铜、蓝晶、地牢石墙与火把的共同世界观？
- 是否有完整外框、足够的材质细节和深浅层次，而不是一组普通深色矩形？
- 关键交互、危险和奖励是否在色彩与层级上清楚，同时没有抢走战斗可读性？
- 是否保留了当前产品已确认的题材、流程、功能边界和响应式要求？
- 是否只消费项目内受控、透明且可追溯的资产？
