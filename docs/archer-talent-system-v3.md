## 2. 覆盖范围

本文及其权威正文完整覆盖项目中旧弓箭手功能天赋、局内战斗天赋、旧固定奖励职责、旧五选一、有限树结束规则、无限成长触发规则，以及它们与技能奖励、装备、套装、战斗奖励、存档迁移、猎手之家和战斗 UI 的冲突条款。

本版本固定为：

- 84 个功能天赋；永久、战斗外学习与配置。
- 102 个逐项确认的有限战斗天赋；此前“97 个”仅为已废弃的早期统计标题。
- 独立的通用、流派级与已锁定路线级无限成长池。
- 每局最多锁定 1 个主流派与 1 个副流派；每个已锁定流派各自固定 1 条路线。
- 蓝晶升级只产生强制、立即消费的战斗天赋三选一；所有技能奖励统一为新增、替换、升级、进化共同参与的三选一。
- 普通技能奖励允许玩家主动选择“放弃技能奖励”；放弃后不获得、不替换、不升级、不进化任何技能，并正常消费本次技能奖励、关闭奖励层、恢复此前战斗／过层流程。该规则覆盖固定层、精英突袭及后续同类技能奖励，也覆盖已经进入 Lv.4 进化二选一或满槽替换二次确认的本次技能奖励。
- “放弃技能奖励”不适用于蓝晶升级产生的 V3 战斗天赋三选一，也不适用于战前连续三轮初始技能草案；这两类仍必须选择 1 项。技能奖励的重掷、候选合法性、保底、FIFO、奖励来源与战斗结算规则不因放弃能力而改变。
- 某流派每新增投入 1 点有限战斗天赋，都会在下一次实际战斗天赋三选一中插入 1 张该流派合法无限成长候选；主、副流派分别计数。
- 有限树当前全部合法节点点满后切换为完整无限成长三选一；新技能重新开放有限节点时允许动态返回有限阶段。
- `兽王契约`、`契约领域`、技能、装备与奖励的联动必须采用运行时 Modifier 与触发隔离，不得永久回写基础技能数据。
- 区域控制三条路线的路线专属无限成长已正式锁定：`天降轰炸` 6 项、`封锁陷阱` 7 项、`风暴领域` 7 项；具体名称、数值、上限及触发隔离以权威正文对应三节为准。
- 战斗中 V3 天赋三选一卡片按用户标注移除类型、身份元信息、等级进度、“当前未选 →”及底部重复描述／标签／`LV.` 文案；保留名称、本次实际增益和非重复规则说明。该调整只改可见文案，所有选择、升级、锁定、消费、插入、存档与 Modifier 逻辑保持。
- 整局成功／失败结算不再显示独立“V3 战斗天赋”摘要栏。所有本局实际选择的有限 V3 天赋与无限成长天赋必须在状态清理前冻结，并与主动技能、旧兼容局内天赋一起显示在同一个“技能与天赋”面板；每个节点显示一次图标、名称和最终选择次数／等级。该合并只改变结算数据投影与展示位置，不改变任何天赋效果、候选、奖励、HUD、暂停页或猎手之家图鉴。

- 不生成新的 AI 图标；准确匹配的旧图标可复用，缺失项使用程序化流派徽记及 `BRANCH`／`DEEP`／`KEY` 标识。
- C 负责真实浏览器战斗、技能奖励、蓝晶升级、路线锁定、插入轮、完整无限阶段和战斗隔离验收。

- Z5 只维护文档、派发与汇总结论，不直接修改业务代码、UI、资产、测试或运行时配置。
