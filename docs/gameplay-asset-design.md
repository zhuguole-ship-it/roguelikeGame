# 像素 Roguelike 玩法与资产设计

## 当前项目定位

这款游戏目前已经具备一个清晰的骨架：玩家在村庄篝火旁苏醒，通过传送门进入契约战场，用弓箭手职业进行自动射击和 Q / E / R 主动技能清场，击败指定数量敌人后推进层数，回村后分解装备、强化装备，并围绕 Boss 掉落的武器和套装继续提升构筑。

推荐将游戏定位为：

> 黑暗幻想题材的伪无限地图弓箭 Roguelite。玩家扮演被释放的死契奴隶，在不同怪物势力占据的契约战场中逐层清剿怪潮，收集蓝晶、爆装备、组合箭术技能，并在每个大关卡第 22 层面对 Boss 审判。

核心体验关键词：

- 高可读性像素战斗
- 弓箭职业构筑
- 短局推进与长期装备刷取
- 村庄作为安全区和成长中心
- 敌人类型靠轮廓、颜色和预警动作快速识别

## 核心玩法循环

### 体验目标

核心循环要让玩家一直处在三个问题之间：

- 这一层我该怎么活下来？
- 这次奖励会把我的构筑推向哪个方向？
- 回村后我该继续刷哪一个契约关卡、强化哪一套装备？

短期目标是完成当前层的击杀契约，中期目标是完成一套技能组合和装备临时强度，长期目标是通关 10 个独立契约关卡并刷出史诗以上核心装备。

### 循环总览

1. 村庄准备：查看金币、装备仓库、关卡完成记录，在铁匠铺分解或强化装备。
2. 选择关卡：从传送门选择要进入的 10 个契约关卡之一。
3. 无限战场生存：移动、瞄准、滑步、自动普攻，处理怪潮、障碍和环境机制。
4. 击杀推进：击杀数量达到本层目标后进入短暂停顿。
5. 普通层轻结算：自动吸附蓝晶、记录掉落、显示紫色以下装备的自动分解预估。
6. 节点奖励：精英层、Boss 前置层和 Boss 层提供技能、补给或关键战利品选择。
7. 单关推进：每关 22 层，第 3 / 6 / 9 / 12 / 15 / 18 / 21 层为精英层，第 22 层为 Boss。
8. 本关结算：通关 Boss、死亡或放弃时结算金币、材料、保留装备和通关记录。
9. 回村重选：通关第 22 层后返回首页 / 村庄，由玩家重新选择下一个关卡。

### 村庄准备阶段

村庄不是菜单背景，而是玩家每局之间的“呼吸点”。玩家在这里做三个明确决定：

- 是否分解不需要的史诗以上装备。
- 是否强化当前武器、胸甲、鞋子、戒指等核心装备。
- 是否立刻进入传送门开启下一轮。

当前代码中已经有篝火、传送门、铁匠铺、职业告示牌等交互点。建议给每个点固定功能：

| 村庄点位 | 功能 | 玩家决策 | 反馈资产 |
| --- | --- | --- | --- |
| 篝火 | 查看上一局记录、恢复状态 | 是否重新挑战 | 火焰循环、结算面板 |
| 传送门 | 选择并进入 10 个契约关卡 | 刷哪一关、追哪套装备 | 蓝色传送门发光、进入音效 |
| 铁匠铺 | 分解装备、强化装备 | 把材料投给哪件装备 | 铁砧火光、锻造火花、材料音效 |
| 职业告示牌 | 查看职业和被动 | 理解弓箭手成长 | 职业图标、被动说明 |

铁匠铺不出售武器。武器属于 12 装备位中的 `武器` 位，和胸甲、头盔、戒指一样通过怪物、精英和 Boss 掉落获得，也参与稀有度、强化、套装和词缀系统。金币主要作为强化手续费、重铸手续费和高价值分解确认成本，而不是直接购买战力。

村庄阶段应给玩家清楚的“下一步入口”。例如传送门常亮，铁匠铺在有可强化装备或可分解装备时出现金属火花提示。

### 入场阶段

玩家进入契约战场后，先出现 0.8-1.2 秒的入场节奏：

- 玩家生成在当前层起始安全区。
- 屏幕显示当前层数和一句危险提示。
- 周围短暂无敌，避免刚入场被怪物贴脸。
- 第一波敌人从视野外刷新环生成。

入场提示可以直接复用现有 message 系统，例如：

- 第 3 层：冲锋怪加入，观察蓄力后滑步闪避。
- 第 4 层：远程怪加入，保持移动并用鼠标准星处理弹幕源。
- 第 7 层：分裂怪加入，不要在角落击杀。
- 第 9 层：爆裂怪加入，击杀后远离红色预警圈。

### 无限战场战斗阶段

战斗地图采用“受控伪无限地图”结构。玩家可以朝任意方向移动，镜头跟随玩家，看不到传统硬墙或矩形房间边框；但系统只保留玩家周围有限区块，用区块生成和回收控制性能。

无限战场由五个并行压力组成：

- 空间压力：程序化障碍、环境危险和软边界改变走位。
- 数量压力：怪物持续从视野外刷新环进入。
- 类型压力：不同敌人迫使玩家改变优先级。
- 冷却压力：滑步和主动技能不能无限使用。
- 方向压力：玩家持续直线逃跑时，侧翼和前方会出现拦截怪群或主题环境机制。

推荐战斗中的玩家决策：

- 是否绕障碍拉开距离并把怪潮聚到技能范围内。
- 是否用鼠标准星先处理弹幕怪或高威胁怪。
- 是否保留滑步等冲锋预警。
- 是否把区域技能丢在敌人汇聚点。
- 是否主动靠近血包，承担短暂风险换恢复。

战斗反馈需要做到非常直接：

- 敌人受击闪黄。
- 玩家受伤闪红。
- 滑步出现蓝色残影。
- 精英/Boss 使用更宽血条。
- 危险爆炸必须先显示预警圈，再造成伤害。

### 击杀推进阶段

每层不需要清空无限敌潮，而是完成明确击杀目标。这个设计适合当前代码里的 `levelTargetKills` 和 `remainingToSpawn`。

建议每层节奏：

- 开局给玩家 2-3 秒建立站位。
- 中段提高同时在场敌人数。
- 目标击杀数接近完成时减少新敌生成。
- 达成目标后停止普通刷怪，并在玩家附近生成契约裂隙进入结算。

当击杀目标完成时，建议出现：

- 契约裂隙在玩家附近安全位置打开。
- 屏幕中心短文字“契约层净化”。
- 所有剩余普通敌人短暂减速、撤离或被裂隙吸收，减少奖励前的混乱。
- 远处蓝晶自动吸附。
- 玩家恢复少量生命，鼓励继续推进。

### Boss 层防跳关规则（2026-07-21 用户确认）

- Boss 层指每个大关卡的第 `22` 层。进入 Boss 层后，玩家必须实际完成该层的 Boss 战；不得通过契约裂隙、路线目标、自动层结算、超时、触碰区域或任何其他楼层推进入口跳过 Boss、直接进入后续楼层或返回村庄。
- 普通层进入第 `22` 层时，只能在该普通层的击杀目标、必要奖励处理和既有结算流程真实完成后，按正常楼层推进进入 Boss 层。不得在 Boss 层入口额外生成、遗留或激活契约裂隙、蓝晶裂点、契约火印、遗物碎箱或其他可推进楼层的交互物。
- 当前层为 Boss 层时，运行时必须清理并禁止创建、更新或消费所有会触发楼层推进的契约裂隙和路线目标；Boss 层的地图边界、缩圈或其他 Boss 机制只能施加战斗压力，不能调用楼层推进或结算。
- Boss 层唯一合法结算顺序为：Boss 被真实击杀 -> Boss 奖励 / 战利品按既有流程处理 -> 返回村庄结算。Boss 存活、护卫仍在场、奖励未处理或 Boss 战未完成时，任何“下一层”或“返回村庄”结果均视为跳关错误。
- 本地战斗测试可以提供 Boss 生成入口，但不得把测试入口、重开或退出测试写成正式 Boss 层已完成；正式关卡与本地测试都不得因为契约裂隙或路线目标改变 Boss 战完成条件。

### 奖励选择阶段

奖励选择仍然是构筑形成的核心，但不应该每层都强制弹出复杂三选一。普通层只做轻结算，精英层、Boss 前置层和 Boss 层才提供明确奖励选择。

普通层轻结算：

- 自动吸附剩余蓝晶。
- 显示本层金币、局内经验和局内等级进度。
- 显示本层装备掉落数量。
- 紫色以下装备只显示最终结算时的自动分解预估；通关完整收益，死亡 / 失败只保留 30%，主动退出为 0。
- 如果掉落史诗及以上装备，才弹出关键战利品提醒。

节点奖励仍保留三类奖励模式：

- `new-active`：获得新的主动技能。
- `upgrade-active`：升级已有主动技能。
- `upgrade-passive`：升级职业固定被动或本局构筑被动，不提供基础属性自动成长。

推荐奖励池规则：

- 前 2 次奖励至少出现 1 个新主动技能，保证玩家形成玩法。
- 如果玩家主动技能槽未满，提高 `new-active` 权重。
- 如果玩家已有 2 个同流派技能，提高同流派升级权重，帮助构筑成型。
- 精英奖励优先给升级或稀有技能，不要只给普通属性。
- Boss 前置层可以给短期补给，例如回血、下一层输出强化或 Boss 掉落权重提升。
- Boss 后奖励以本关大结算为主，保底展示传承装备和史诗以上可保留装备。

奖励卡片信息结构：

- 技能名
- 流派标签：穿透、散射、野兽、区域、陷阱、护盾
- 当前等级到下一等级的变化
- 等级变化只描述技能 / 被动构筑变化，不显示生命、攻击、攻速、移速等基础属性上涨
- 颜色和图标
- 简短战术描述

示例：

| 奖励 | 类型 | 描述 |
| --- | --- | --- |
| 穿刺箭 Lv.2 | 主动升级 | 伤害提升，穿透更强，适合清理直线怪群 |
| 毒藤箭 Lv.1 | 新主动 | 在落点生成减速区域，适合控制分裂怪 |
| 鹰眼专注 Lv.3 | 固定被动 | 普攻射程提升，基础箭矢获得穿透 |

### 层数推进阶段

每一层应该有轻微变化，但不要让玩家觉得规则突然换了。

推荐变化维度：

- 击杀目标增加。
- 生成间隔缩短。
- 最大在场敌人数增加。
- 障碍数量和布局变化。
- 新敌人按层数解锁。
- 精英和 Boss 改变房间节奏。

层数推进的节奏可以设计为：

| 层数段 | 主要体验 | 设计重点 |
| --- | --- | --- |
| 1-2 | 认识本关怪物 | 少量主题怪，低障碍 |
| 3 | 第一次精英检验 | 1 只精英，测试基础输出 |
| 4-8 | 翻倍预热和混合怪潮 | 怪物数量逐步提高，新行为逐步加入 |
| 9-15 | 构筑成型检验 | 多精英预算、环境机制和混合敌群 |
| 16-21 | 高压刷装 | 高经验、高掉落、Boss 前最终考试 |
| 22 | 本关 Boss | 击败后结算本关并返回首页 |

### 刷怪爽感与炮灰怪潮

当前战斗爽感的核心目标是让玩家能通过 Q / E / R 主动技能制造“聚怪、出手、清屏、蓝晶吸附”的爆点。

所有炮灰怪统一使用此前设计的腐蚀史莱姆：

- 腐蚀史莱姆是跨关卡通用低威胁炮灰。
- 它负责数量和清屏爽感，不替代每关主题普通怪。
- 不同关卡可以有轻微颜色污染或环境附着物，但动作和死亡反馈基底保持一致。
- 腐蚀史莱姆应该低血、数量多、死亡反馈明显，被主动技能成片清掉。

同屏怪物体验目标：

| 关卡段 | 常态同屏 | 爆点同屏 | 硬上限 |
| --- | ---: | ---: | ---: |
| 第 1-2 关 | 30-45 | 55-70 | 80 |
| 第 3-5 关 | 50-75 | 85-115 | 130 |
| 第 6-8 关 | 75-110 | 120-160 | 180 |
| 第 9-10 关 | 110-155 | 170-230 | 260 |

当前版本需要提高怪潮密度：所有非 Boss 层的总击杀目标和普通怪刷怪预算在现有实现基础上整体翻倍。这个调整服务“持续聚怪、主动技能清片、蓝晶吸附”的爽感；同屏上限可按性能小幅提高，但不能让怪物遮住敌方预警、蓝晶轨迹和玩家技能特效。

怪潮构成建议：

- 60%-70% 腐蚀史莱姆，负责被技能成片清掉。
- 20%-30% 主题普通怪，负责关卡特色。
- 5%-10% 高威胁怪，负责远程、冲锋、爆裂、控制等优先级压力。
- 1%-3% 精英，负责真正的打法考试。

主动技能清怪目标：

| 技能等级 | 一次主动技能理想清怪数 |
| --- | ---: |
| 0 投入 / Lv.1 | 4-8 只腐蚀史莱姆 |
| 初步成长 / Lv.2 | 8-15 只腐蚀史莱姆 |
| 中期构筑 / Lv.3 | 15-28 只腐蚀史莱姆 |
| 成型构筑 / Lv.4 | 25-45 只腐蚀史莱姆 |
| Lv.5 质变 | 40-70 只腐蚀史莱姆 |
| 橙装 / 传奇联动爆发 | 80-120 只腐蚀史莱姆 |

爽感循环：

```text
拉怪
-> 腐蚀史莱姆聚成怪潮
-> 手动释放 Q / E / R
-> 成片死亡和爆浆
-> 蓝晶大面积吸附
-> 构筑未完成时保留主题怪 / 精英继续制造压力
-> 构筑成型后关键技能可连带轰掉一片低 / 中预算精英
```

无限地图中的短时路线目标：

```text
看见路线目标
-> 判断是否绕过去冒险激活
-> 触发额外怪潮 / 主题危险
-> 用 Q / E / R 打出更高收益的一波清怪
-> 蓝晶、材料、掉落权重或临时强化回收
-> 回到主击杀目标
```

路线目标用于打破单纯绕圈，不用于强制玩家完成。每个目标的奖励必须有上限，带来的压力不能通过隐藏移速倍率实现，而要通过额外怪潮、主题怪、地形危险或短时间站位要求制造。

爽感解锁原则：

- 第 1 关前几层只给“小爽”，让玩家知道主动技能能清怪，但不能一发清半屏。
- 第 3-5 关开始给“成片清怪”，需要 Lv.3-Lv.4 技能和基础装备支持。
- 第 6-8 关需要成型构筑，否则腐蚀史莱姆数量变多但不会轻松秒光。
- 第 9-10 关提供终局大怪潮，只有 Lv.5 质变、橙装 / 传奇联动和良好聚怪才能打出大清屏。

构筑完成度对应的清屏边界：

| 构筑状态 | 一次关键技能目标 | 不能突破的底线 |
| --- | --- | --- |
| 构筑未完成 | 清掉一片炮灰，精英仍需要补技能和走位 | 不能顺手清空精英层 |
| 构筑成型中 | 清炮灰并压低精英血线 | 精英仍要看冷却、站位和目标选择 |
| 核心装备 + 核心技能正确搭配 | 清一片炮灰，并轰掉一片低 / 中预算精英 | 爽感必须依赖正确流派、Lv.5 质变、装备词缀和释放窗口 |
| Boss 战 | 高构筑可以明显压血和缩短阶段 | Boss 技能仍有致死风险，不能被构筑直接跳过机制 |

难度和爽感要形成反复阶梯，而不是线性变简单：

```text
打不过
-> 回村分解、强化、调整装备
-> 勉强打过
-> 技能和套装成型后清屏爽
-> 进入更高关卡或更深层再次打不过
-> 再刷装、强化、优化技能循环
-> 再次打得过并获得更大爽感
```

每个关卡都允许玩家提前尝试，但系统不硬锁。低于推荐战力进入高关卡时，应表现为怪物更硬、更疼、主题机制更难处理，而不是普通怪永久高速贴脸。高于推荐战力回刷低关卡时，允许玩家快速清怪和刷材料。构筑未完成时精英仍是打法考试；核心装备和技能搭配正确后，玩家可以用关键技能轰掉一片低 / 中预算精英；Boss 仍必须保留机制压力和致死风险。

单层战斗节奏建议拆成三段：

| 阶段 | 体验目标 | 怪物表现 | 玩家行为 |
| --- | --- | --- | --- |
| 压迫段 | 让玩家感到危险正在聚拢 | 多方向进入、主题怪开始施压 | 走位、聚怪、保留关键冷却 |
| 破局段 | 让 Q / E / R 成为操作爆点 | 炮灰密集，高威胁怪露出破绽 | 朝鼠标准星释放技能，打穿怪潮 |
| 收割段 | 释放清屏和吸晶爽感 | 炮灰大量死亡，蓝晶吸附 | 补刀、拾取、准备下一波 |

怪物属性随关卡和层数成长：

```text
最终属性 = 怪物定位基础值 x 关卡强度系数 x 层数强度系数
```

腐蚀史莱姆在所有关卡中都保持相对炮灰定位，但高关卡腐蚀史莱姆的绝对生命和攻击会明显高于第 1 关，避免玩家 0 时间投入就获得终局清屏爽感。

同屏密度也要随层数递进：

| 层段 | 同屏密度比例 |
| --- | ---: |
| 1-2 | 目标密度的 35%-45% |
| 3 | 目标密度的 45%-55% |
| 4-8 | 目标密度的 60%-70% |
| 9-15 | 目标密度的 75%-90% |
| 16-21 | 目标密度的 100% |
| 22 Boss | 按 Boss 阶段召唤 |

腐蚀史莱姆收益控制：

- 单只腐蚀史莱姆只给低经验小晶石。
- 腐蚀史莱姆极低概率掉装备，主要提供视觉爽感和蓝晶轨迹。
- 真正的装备收益主要来自主题普通怪、高威胁怪、精英和 Boss。

角色、怪物与装备的数值护栏：

- 角色成长分为局内技能等级、紫色以上装备形态变化、套装/橙装联动和后续天赋四层；蓝晶经验不再直接提高基础属性，不能靠吃经验包把基础攻击力、生命、攻速或移速线性堆爆。
- 玩家每次对局结束返回首页 / 村庄后，局内经验和局内等级清零；通关时按本局累计经验、最高局内等级、到达层数、精英击杀和 Boss 击杀完整换算天赋点，死亡 / 失败只保留 30% 经济收益，主动退出不发放天赋点、金币、材料或装备收益。
- 天赋点属于局外长期资源；第一版局内 40 个节点、局外 84 个节点、四难度关卡系数和天赋数值以 `campaign-progression-equipment-redesign.md` 为准。天赋应优先解锁机制、提高构筑效率、强化刷装目标和提供高难保底，不应成为无上限基础属性堆叠。
- 怪物成长优先提高生命、攻击、抗性、技能频率和组合复杂度；当前版本允许对所有普通怪做一次常态移速手感上调，但仍必须受类别软上限控制，冲锋/扑击必须有前摇、预警和结束硬直。
- 同战力下，腐蚀史莱姆应在普攻 1-2 下或一次主动技能中成片死亡；主题普通怪应需要 3-5 次普攻或 1 次主动技能配合补刀；高威胁怪需要 1-2 个主动技能或持续风筝；构筑未完成时精英怪需要 2-4 轮技能循环；核心装备 + Lv.5 技能搭配正确后，关键技能可以击杀一片低 / 中预算精英，但高预算精英仍需要处理。Boss 以机制考试为主，不靠单纯堆血拖时间，也不能被构筑直接跳过核心阶段。
- 第 1-2 关允许玩家用 Lv1-Lv2 技能获得小规模清屏，但第 6 关之后必须依赖 Lv4-Lv5、紫装/橙装联动和主动聚怪才能打出大清屏。
- 紫色词缀提供 +8%-15% 等效输出或等价控制/生存；橙色词缀提供 +18%-30% 等效输出但需要触发条件；亮橙词缀可以改变循环，但必须有冷却、持续时间、次数或召唤上限。
- 同一技能的弹道、区域、召唤数量都要有硬上限，避免装备、Lv5 和套装叠加后出现无限箭矢、全屏区域或永久兽群。
- 数值验收以“未成型时炮灰能被成片清掉、精英仍要处理；成型后关键技能能轰掉一片炮灰和一片低 / 中预算精英”为目标；如果成型前就能无脑清空精英层，或成型后可以无视高威胁怪、高预算精英和 Boss 机制，就说明构筑已失控。

近战普通攻击规则：

- 所有怪物的近战普通攻击触发距离、命中距离、站位距离、windup、active 和 recovery 以 `campaign-progression-equipment-redesign.md` 的“近战普通攻击站位与锁定”表为准，不再使用“当前实现 x 2”这类相对规则。目标是让近战怪在“武器范围”内挥击，而不是身体压进玩家坐标后靠重叠扣血。
- 该规则只作用于普通近战攻击；冲锋、扑击、旋风斩、Boss 技能和范围技能仍按各自技能范围、前摇和预警执行。
- 任何怪物播放普通攻击动画时都不能移动。进入 attack windup / attack active 后，位置和朝向锁定到攻击开始时的状态，不允许继续追踪、滑步、碰撞挤压或左右频繁翻转。
- 普通攻击伤害只能在攻击动画命中帧结算一次。windup 未完成前不能扣血；如果玩家离开命中距离，本次攻击可以落空，怪物收招后再重新追踪。

### 精英阶段

精英房的作用不是只提高血量，而是给玩家一个“打法考试”。

推荐精英设计：

- 体型比普通怪大 50%。
- 至少带一个普通敌人的强化行为。
- 入场时清楚标注“精英来袭”。
- 击败后立刻弹出额外奖励选择。

可选精英词缀：

| 词缀 | 效果 | 视觉 |
| --- | --- | --- |
| 疾行 | 移速更快 | 蓝色脚下残影 |
| 硬壳 | 生命更高 | 紫色护甲边框 |
| 繁殖 | 周期召唤小怪 | 绿色孢子环 |
| 弹幕 | 周期发射扇形弹 | 蓝色施法光 |
| 狂暴 | 低血时加速 | 红色闪烁 |

### Boss 阶段

每个大关卡第 22 层是 Boss 层，关卡结构、Boss 数值和阶段机制以 `campaign-progression-equipment-redesign.md` 为准。本文件只保留视觉和资产节奏要求。Boss 建议使用三段行为循环：

1. 追踪移动：缓慢逼近玩家，给玩家输出窗口。
2. 蓄力冲锋：朝玩家方向显示红色预警线，随后高速冲锋。
3. 扇形弹幕：停下并朝玩家方向释放 3-5 发弹体。

Boss 血量阶段可以做成：

- 100%-60%：只使用追踪和冲锋。
- 60%-30%：加入扇形弹幕。
- 30%-0%：冲锋冷却缩短，弹幕数量增加。

Boss 奖励建议高于普通层：

- 大量金币。
- 稀有技能升级。
- 本关传承装备保底。
- 通关时史诗以上装备保留到长期仓库；死亡 / 失败时本局获得的史诗、传承、传奇地下城装备不带出。
- 通关时紫色以下装备自动分解为材料；死亡 / 失败时自动分解材料只保留 30%；主动退出不触发自动分解材料收益。
- 首次击败时记录本关契约完成，并返回首页 / 村庄重新选择关卡。

### 失败与结算阶段

失败不应该只显示“游戏结束”，而是把玩家本局的进步讲清楚。

结算信息：

- 到达层数
- 击杀数量
- 本局累计蓝晶经验
- 本局最高局内等级
- 结算获得天赋点
- 获得金币
- 自动分解获得材料
- 保留的史诗、传承、传奇装备
- 存活时间
- 本关是否首次通关
- 本局主要技能构筑

结算状态口径：

- 通关：完整结算，按既有通关、解锁、战利品、金币、天赋点和自动分解材料规则发放。
- 死亡 / 失败：金币、天赋点、自动分解材料等经济收益统一只保留 30%；本局获得的史诗、传承、传奇地下城装备不带出；局内经验和局内等级清零。
- 主动退出：0 收益；不带出任何本局地下城战利品；不触发自动分解材料；不产生可刷的天赋点、金币、装备、材料或进度收益。
- 历史记录如保留，只用于展示 / 回顾，不能解锁关卡、发放收益或触发长期成长。

结算后给玩家两个强按钮：

- 回到村庄
- 选择关卡

如果本局获得了大量分解材料、Boss 武器或高价值套装件，结算页可以提示“铁匠铺可强化当前装备”或“仓库有新传承装备可查看”。

结算规则：

- 玩家返回首页 / 村庄时，本局经验和本局等级必须清零。
- 本局经验和最高局内等级只作为天赋点结算依据，不作为下一局基础属性保留。
- 死亡 / 失败局的天赋点、金币和自动分解材料按 30% 结算；主动退出不获得天赋点、金币、材料、装备或进度收益，防止普通难度未通关就通过失败 / 退出刷满局外天赋。
- 天赋点消耗、节点 ID、前置规则、存档字段、候选生成、重掷边界和效果汇总接口以 `campaign-progression-equipment-redesign.md` 的“第一版局内天赋池”“2026-07-23 权威覆盖：四流派战斗天赋形态扩充”和“第一版局外天赋树”章节为准。目标局内战斗天赋为 72 个节点、局外功能天赋为 84 个节点；四个契约流派的 5 级联动、形态二选一和装备 / 套装承接关系必须避免退化为纯属性成长。

### 关卡独立与四难度摘要

10 个关卡彼此独立，所有关卡普通难度默认开放。每个关卡内部按 `普通 -> 困难 -> 地狱 -> 折磨` 递进解锁：通关第 N 关普通，只解锁第 N 关困难，不影响其他关卡。关卡数字越大，普通难度也越强；第 10 关普通应明显强于第 1 关普通。

四难度体验：

| 难度 | 体验定位 |
| --- | --- |
| 普通 | 熟悉关卡主题，完成基础 Build。 |
| 困难 | 需要装备强化和明确流派方向。 |
| 地狱 | 需要核心技能 Lv5、紫 / 橙装联动和套装件。 |
| 折磨 | 终局追求，需要完整流派、强化装备、熟悉 Boss 机制。 |

高难不靠怪物乱飞制造压力，而靠生命、攻击、机制组合、精英预算、Boss 阶段压迫和奖励追求递进。炮灰仍负责清屏爽感，小怪负责主题识别，精英负责打法考试，Boss 负责操作压力。

### 契约流派与局内 5 级联动方向

四个流派用于给每局构筑一个清晰锚点。局内等级 5 是第一轮核心联动点：玩家应开始看到流派循环成型，但还不能直接跳过精英和 Boss 机制。

| 流派 | 局内天赋核心 | 局内 5 级联动 | 装备 / 套装变化 |
| --- | --- | --- | --- |
| 死契处刑 | 死契标记、处刑线、穿透魂火、击杀魂爆 | 形成“标记 -> 击杀 -> 魂爆 -> 再标记”循环；穿透 Lv5 可强化下一段穿透伤害 | `死契处刑者` 从穿透加成升级为标记、魂爆、精英破防和 Boss 易伤承接 |
| 血羽游侠 | 攻速、散射、暴击、流血、血羽追击 | 散射命中多个敌人时，暴击目标释放血羽；散射 Lv5 变为扇形铺场 + 血羽追击 | `血羽游侠` 承接暴击生血羽、流血死亡碎片和有冷却的血羽风暴 |
| 兽王赦令 | Q / E / R 三只主力野兽、手动下令、倒地复苏、兽群协同 | 解锁首领化和光环；对应野兽技能 Lv5 获得专属首领动作 | `兽王赦令` 承接复苏缩短、协同攻击、首领化弱光环和精英压制 |
| 蓝晶契约 | 蓝晶充能、冷却返还、技能过载、区域控制 | 解锁蓝晶过载；拾取蓝晶降低冷却或扩大下一次技能；区域 Lv5 变为持续领域 + 脉冲 | `蓝晶契约` 承接充能效率、过载脉冲、蓝晶领域和精英减速持续伤害 |

共同护栏：

- 构筑未完成时，一次技能可以清掉一片炮灰，但精英仍需要技能循环或走位处理。
- 核心技能 Lv5 + 正确装备 / 套装搭配后，关键技能可以轰掉一片炮灰和一片低 / 中预算精英。
- Boss 不能被处刑、血羽风暴、兽群压制或蓝晶领域直接跳过，只能受到易伤、破盾、减速、持续压迫等受控影响。
- 局内等级和蓝晶经验不直接提高生命、攻击、攻速、移速、技能伤害或技能冷却等基础属性。

### 长期成长循环

长期成长建议只保留少数清晰系统，避免破坏 Roguelite 的单局随机感。

保留成长：

- 金币
- 装备强化、装备分解和材料库存
- 关卡完成记录
- 通关带出的史诗以上装备仓库
- 通关完整结算或死亡 / 失败 30% 结算后的自动分解材料；主动退出不保留自动分解材料收益
- 里程碑记录
- 天赋点余额和后续已解锁天赋

不建议过早加入：

- 无上限永久属性树
- 大量材料合成
- 多货币系统

原因是当前项目最有辨识度的是弓箭技能构筑和高可读性像素战斗，过多局外系统会稀释核心体验。

天赋系统的定位应是“长期目标和构筑效率”，不是直接替代装备成为无限基础属性来源。后续设计天赋时，优先考虑解锁选项、改善构筑成型、提高拾取 / 结算 / 保底效率和少量基础保底，而不是大量堆叠攻击、生命、移速。

### 推荐新增子循环

为了让战斗更有层次，可以逐步增加三个轻量子循环。

#### 血包风险循环

敌人有概率掉落血包，但血包经常落在危险位置。玩家要判断是否冒险拾取。

实现建议：

- 血包存在时间 8-12 秒。
- 低血时提高血包掉落率。
- 怪物数量翻倍后，血包 / 治疗药水最终掉率在现有计算结果上直接乘以 0.5；低血加成仍可存在，但也要先算完再减半。
- 血包不能因为怪物数量翻倍而出现“满地补给”，它的作用是救急和制造冒险决策，不是让玩家无成本站撸。
- 血包出现时有红白十字闪光。

#### 准星方向循环

Tab 目标切换不再作为战斗决策。主动技能统一跟随鼠标准星方向或鼠标落点，让玩家的操作判断集中在“往哪里打、什么时候打、用哪一个技能打”。

- Q / E / R 只读取鼠标准星方向或落点，不读取近战 / 远程优先级。
- 普攻可以保持自动选择最近威胁目标，减轻基础操作负担。
- Boss 战中可以让自动普攻优先 Boss，但主动技能仍由鼠标准星决定。
- UI 应明确显示准星方向、技能冷却和当前技能槽，不再显示 Tab 优先级。

#### 构筑标签循环

给技能加流派标签后，奖励可以根据玩家选择产生轻微倾向。

示例：

- 连续选择穿透技能后，更容易出现重矢、风切、贯日长虹。
- 连续选择散射技能后，更容易出现三连快射、箭幕推进、鹰翼掠射。
- 连续选择野兽伙伴技能后，更容易出现猎鹰、霜狼、林熊、灵鹿等伙伴指令。

这样玩家会感觉自己在“养成一套打法”，而不是随机拿强度。

正式关卡结构以主文档为准：每个大关卡 22 层，第 3 / 6 / 9 / 12 / 15 / 18 / 21 层为精英压力点，第 22 层为 Boss 层。本文件不再维护旧版“10 层一局”节奏，避免和主文档冲突。

| 层段 | 玩家状态 | 资产 / 视觉重点 |
| --- | --- | --- |
| 1-2 | 入场识别 | 主题地面、炮灰怪、第一种主题普通怪。 |
| 3 | 首次精英 | 精英外框、警示文字、奖励反馈。 |

## 玩家幻想与操作

玩家幻想：灵活的巡林弓手，不靠硬抗，而靠距离、穿透、落点控制和走位生存。

当前操作建议维持：

- WASD / 方向键：移动
- 鼠标：瞄准主动技能方向或落点
- 左键或快捷键：释放主动技能
- Space：短距离滑步
- P / Esc：暂停
- Q / E / R：手动释放 1 / 2 / 3 号主动技能槽

重要手感目标：

- 玩家普通移动要轻快，滑步要短促明确。
- 普攻可以自动发生，但三个主动技能都由 Q / E / R 手动释放，瞄准方向和落点由鼠标决定。
- 主动技能按下后必须立即有反馈：角色抬弓、野兽响应、冷却归零动画或技能名浮现。
- 受伤、击杀、技能命中必须有短促反馈：闪白、数字、屏幕小震、像素粒子。

## 关卡节奏设计

### 1-2 层：基础压迫

敌人只出现近战怪，目标是教会玩家保持距离和走位。

资产重点：

- 近战怪轮廓简单，颜色为腐化绿。
- 房间障碍少，火把和边框帮助玩家理解战斗边界。

### 3 层：冲锋怪加入

冲锋怪有明显蓄力预警，玩家需要学会滑步横向躲避。

资产重点：

- 冲锋怪使用粉红/红色主体。
- 蓄力时头顶或身体前方出现 2-3 帧红色像素闪光。
- 冲锋路径可以用短促红色残影提示。

### 4-6 层：远程弹幕加入

远程怪开始发射扇形弹幕，玩家需要通过走位、鼠标准星和主动技能处理弹幕源。

资产重点：

- 远程怪使用冷蓝色，手持法杖或骨弩轮廓。
- 敌方弹体使用蓝白色，不要和玩家黄色箭矢混淆。

### 7-8 层：分裂怪加入

分裂怪死亡后产生小怪，制造局部拥挤。

资产重点：

- 分裂怪用亮黄绿色，身体左右有裂纹。
- 死亡时用绿色碎片爆开，并生成两个小型近战怪。

### 9 层以后：爆裂怪加入

爆裂怪被击杀后产生范围爆炸，惩罚贴脸和贪输出。

资产重点：

- 爆裂怪用橙黄主体，顶部有引信或发光核心。
- 死亡后出现 0.4 秒扩张圆形警告，再爆炸。

### 精英层：3 / 6 / 9 / 12 / 15 / 18 / 21

精英怪应像普通怪的强化体，但更大、更亮、更有符文效果。

资产重点：

- 紫色外框或头顶精英冠记。
- 血条宽于普通怪。
- 死亡时掉落职业奖励视觉物。

### 第 22 层：Boss 房

Boss 的具体身份、数值和技能以当前大关卡主题为准，必须使用主文档的 Boss 实战表。视觉上需要强调体型、阶段变化、预警线和传承掉落。

资产重点：

- 大体型，橙色/暗红主体，双角或石质面具。
- 第 1 关典狱长使用待机、移动、普通攻击、受击、死亡，以及 Attack3 / Special / RUN 三类技能素材；旧的“蓄力冲锋、弹幕释放”只属于历史占位描述，不得作为实现依据。
- Boss 房障碍减少，强调横向躲避和远距离输出。

## 职业与构筑设计

当前职业只有弓箭手，建议先把弓箭手做深，而不是马上扩职业。

### 固定被动：鹰眼专注

现有设计是每次升级提升普攻射程，后期增加穿透。这个被动很好，因为它强化了弓箭手的身份。

视觉表现：

- 射程提升：玩家身边出现淡金色瞄准环。
- 穿透提升：普攻箭矢尾羽从单色变为双层高光。

5 级质变：

- 鹰眼专注达到 5 级后，除保留普攻射程和基础箭矢穿透提升外，弓箭手的普攻和主动箭术获得暴击能力。
- 推荐数值：暴击率 +12%，暴击伤害为 175%。
- 奖励卡片需要明确写出“Lv.5 解锁：鹰眼暴击”，让玩家知道第 5 级不是单纯数值提升。

### 四个基础属性

- 生命：绿色护心像素图标，玩家周围出现短暂绿框。
- 攻击力：金色箭头或十字光。
- 攻击速度：白色小刻度环绕玩家。
- 移动速度：蓝色残影线。

## 技能流派

现有技能数量很多，建议在 UI 和资产上按三个核心构筑归类，而不是让玩家面对一长串同质箭术。区域、灼烧、减速、陷阱等可以作为技能标签存在，但不再单独作为主构筑流派。

### 技能升级质变规则

主动技能 1-4 级继续提供伤害、冷却、射程、持续时间、箭矢数量等基础成长；第 5 级必须提供一次“形态变化”或“战术变化”。这样玩家在奖励选择中会主动追求升满技能，而不是只把升级看成小幅数值增强。

奖励卡片展示建议：

- Lv.1：显示技能基础定位。
- Lv.2-Lv.4：显示本级主要数值成长，例如穿透 +1、持续时间 +0.5 秒、弹跳次数 +1。
- Lv.5：使用独立高亮文案“质变”，并写清楚新增机制。

新增通用状态：

| 状态 | 设计 |
| --- | --- |
| 暴击 | 默认暴击伤害为 175%；鹰眼专注 5 级先提供 +12% 暴击率。 |
| 传染 | 脆弱、灼烧、减速、暗蚀目标死亡后可向 90px 内敌人扩散，最多传染 2 次，每次传染保留 70% 强度。 |
| 眩晕 | 普通怪完整生效；精英和 Boss 只吃 35% 时长。 |
| 流血 | 持续 4 秒，造成本次命中伤害 45% 的持续伤害，最多叠 3 层。 |

### 野兽伙伴流

代表技能：

- 猎鹰俯冲
- 霜狼守护
- 野猪冲阵
- 林熊护卫
- 毒蛇伏击
- 灵鹿庇护

玩法定位：

- 类似兽王幻想，弓箭手不是单纯召唤箭塔，而是呼唤野兽伙伴参与战斗。
- 玩家用 Q / E / R 手动下达野兽技能指令，而不是等冷却自动触发。
- 野兽有自己的定位：进攻、控制、防御、治疗、反击。
- 适合喜欢“我和伙伴一起作战”的玩家，操作点在于选择释放时机和落点。

野兽伙伴规则：

- 野兽为半常驻伙伴，不是一次性召唤物。
- 玩家获得某个野兽主动技能后，第一次按 Q / E / R 会召唤该野兽入场，并立刻执行一次入场指令。
- 后续再次按对应按键，不重新召唤，而是对该野兽下达特殊指令。
- 野兽平时自动跟随、护卫、攻击附近敌人；真正的爆发、防御、控制由玩家手动释放。
- 同时最多存在 3 只主力野兽，对应 Q / E / R 三个主动技能槽。
- 野兽会受伤、倒地、复苏，但不永久死亡。
- 倒地后进入复苏计时，复苏完成后回到玩家附近并恢复部分生命。
- 野兽不会完全替代玩家输出，主要提供战术窗口。
- 野兽受技能等级影响：特殊技能伤害、护盾量、控制强度、复苏效率和指令冷却。

野兽类型建议：

| 野兽 | 定位 | 手动技能 | 玩法用途 |
| --- | --- | --- | --- |
| 猎鹰 | 进攻 | 沿鼠标方向俯冲穿刺 | 打远程怪、补刀低血目标 |
| 霜狼 | 控制 | 跃向落点撕咬并减速 | 控制冲锋怪和精英 |
| 野猪 | 冲阵 | 直线冲撞并击退 | 打开包围圈 |
| 林熊 | 防御 | 守在玩家附近嘲讽近战怪 | 给玩家制造喘息空间 |
| 毒蛇 | 伏击 | 在落点潜伏，敌人靠近后毒爆 | 控制窄口和障碍边 |
| 灵鹿 | 支援 | 给玩家短暂护盾和移速 | 高压层保命 |

Q / E / R 操作示例：

- Q 装备猎鹰俯冲：朝鼠标方向打一条高伤穿刺线。
- E 装备林熊护卫：在玩家身前召唤林熊，短时间吸引近战怪。
- R 装备灵鹿庇护：低血时手动开护盾，配合滑步撤离。

半常驻伙伴状态：

| 状态 | 说明 |
| --- | --- |
| 正常 | 跟随玩家、自动攻击、可执行指令 |
| 指令中 | 执行 Q / E / R 特殊技能，期间有独立动作和特效 |
| 受伤 | 短暂闪白或后退，不中断基础行为 |
| 倒地 | 不能攻击，不能执行指令，技能槽显示复苏倒计时 |
| 复苏 | 倒计时结束后回到玩家附近，恢复部分生命 |

兽群协同：

- 同时存在 2 只主力野兽时，野兽基础攻击速度小幅提高。
- 同时存在 3 只主力野兽时，指令命中后获得短暂协同增益。
- 猎鹰 + 霜狼：猎鹰俯冲命中被减速敌人时额外暴击。
- 林熊 + 灵鹿：林熊嘲讽期间，灵鹿护盾量提高。
- 毒蛇 + 野猪：野猪把敌人撞进毒蛇陷阱时立即触发毒爆。
- 百兽协猎期间：主力野兽立即恢复一部分指令冷却。

1-5 级成长与第 5 级质变：

野兽伙伴流第 5 级不应只是提高伤害，而应给玩家清楚的“首领化 / 数量 / 光环”变化。野兽仍然是半常驻伙伴，Q / E / R 负责下达指令。

| 技能 | 5 级质变 |
| --- | --- |
| 霜狼护阵 | 召唤首领霜狼；护阵内玩家攻速 +12%，敌人移速 -20%。 |
| 灵鹿庇护 | 灵鹿变为守护灵鹿；每 5 秒给玩家一个小护盾，护盾值为玩家最大生命 8%。 |
| 林熊护卫 | 林熊变为老熊首领；指令附带 1 秒嘲讽，玩家受到近战伤害 -10%。 |
| 毒蛇伏击 | 额外召唤 1 条小毒蛇；毒蛇命中叠毒，3 层后爆毒。 |
| 野猪冲阵 | 野猪群数量 +2；冲撞命中首个精英或 Boss 时造成短暂破甲。 |
| 猛禽俯冲 | 猛禽命中后给玩家 4 秒暴击光环：暴击率 +10%。 |
| 百兽协猎 | 期间所有主力野兽首领化；若已有 3 只野兽存活，额外召唤 1 只临时协猎兽。 |

资产关键词：

- 野兽轮廓要比玩家略低，避免遮挡主角。
- 每只野兽至少需要待机、移动、普攻、指令技能、受击、倒地、复苏动作。
- 猎鹰用金褐色高速残影。
- 霜狼用浅蓝鬃毛和冰晶脚印。
- 野猪用厚重深棕轮廓和冲撞尘土。
- 林熊用大块深绿/棕色身体和护盾符文。
- 毒蛇用黄绿色细长身体和地面毒圈。
- 灵鹿用米白身体、金色鹿角和绿色治疗粒子。

## 武器装备与资产方向

武器不再是铁匠铺出售的永久商店条目，而是正式并入装备系统的 `武器` 槽。武器拥有稀有度、装备分数、强化等级、普通副属性、核心大词缀和套装标签；它可以和胸甲、头盔、戒指、项链等部位共同组成套装。

初始武器由系统赠送，定位为低强度开局装备。后续武器主要来自怪物、精英和 Boss 掉落：

- 普通武器：普通怪和精英低概率掉落，紫色以下按最终结算状态处理；通关自动分解，死亡 / 失败只保留 30% 材料，主动退出不产出材料。
- 史诗武器：精英、高层普通怪和关键战利品低概率掉落，提供流派小形态变化。
- 传承武器：指定 Boss 掉落，属于本关主题传承装备。
- 传奇武器：Boss 极低概率掉落，服务终局构筑追求，不作为通关必需。

## 环境资产

### 室外村庄

当前项目村庄必须按室外森林村庄制作，定位为安全区和成长中心。视觉质量以 `docs/visual-quality-standard.md` 和参考图 `public/assets/reference/archer-village-dungeon-sheet.png` 为准。

资产清单：

- 村庄地图背景：按 `1920x1280` 输出效果验收，不能直接整图贴参考图。
- 草地与泥路：不规则边缘，至少 4 种草地细节、3 种道路边缘细节。
- 铁匠铺：独立建筑，屋顶、墙体、炉火、烟囱、台阶和阴影完整。
- 铁匠 NPC：门口打铁，至少 2 帧锤击动作和火花。
- 篝火：32x32 到 64x64，4 帧火焰，周围有凳子和地面光晕。
- 地牢传送门：64x96 到 96x128，4 帧循环发光。
- 职业告示牌：64x48 到 96x64，放在传送门旁边。
- 村长小屋：独立蓝顶/木屋视觉，门窗、屋顶高光和投影完整。
- 装饰物：树、草丛、花、石块、木围栏、箱子、酒桶、武器架。
- 地图边界：树群、围栏、遗迹或水体自然封边，不能只靠纯色墙。

### 无限战斗地图

战斗地图后续改为受控伪无限地图。视觉上不再依赖固定房间边框，而是通过可循环地面、主题障碍、远景暗化和环境危险表现“玩家正在持续深入契约战场”。

地图资产仍然需要保持高密度和高可读性，但必须支持区块化复用：

- 地面 tile 需要能无缝拼接，避免区块边缘出现明显断层。
- 每个关卡至少需要 4-6 种地面细节，用于区分普通地面、危险区域边缘、路径痕迹和主题污染。
- 障碍物必须有清晰碰撞轮廓，不能让玩家误判能否通过。
- 大型障碍需要拆成视觉主体和碰撞代理，碰撞代理必须比视觉边缘略保守。
- 远景或地图边缘不能作为硬墙使用，除 Boss 层契约封锁领域外，普通层不出现不可解释的边界。

地砖：

- forest-ruin-floor-a：32x32 或 48x48，暗绿石砖
- forest-ruin-floor-b：32x32 或 48x48，苔藓石砖
- forest-ruin-floor-crack：32x32 或 48x48，裂纹砖
- forest-ruin-floor-root：32x32 或 48x48，树根砖
- forest-ruin-floor-flower：32x32 或 48x48，低密度花草点缀

普通层不再需要完整墙边与边框，但仍需要以下软边界和过渡资产：

- fog-edge：32x32 或 48x48，远景雾化边缘
- terrain-blend：32x32 或 48x48，不同地面过渡
- danger-edge：32x32 或 48x48，毒沼、血池、熔岩等危险边缘
- contract-rift：64x64 到 96x96，层目标完成后出现的契约裂隙，4-6 帧循环

障碍：

- pillar：32x32
- crate：32x32
- wagon：48x32
- ruin：48x32

所有障碍都必须有高光、暗面和落影；不允许直接使用纯矩形块作为最终资产。

区块化障碍需要遵守：

- 小障碍用于制造走位绕行，但不能阻断主要路径。
- 大障碍用于制造聚怪点和区域技能价值，但周围必须有可通行空间。
- 主题危险物必须先有预警边界，再造成伤害或减速。
- Boss 层可以使用契约雾、血幕、树墙、潮汐墙、火山裂缝等软边界资产，但这些边界必须有清楚提示。

### 村庄信息页文案精简

怪物图鉴、物品仓库和关卡选择都是高频查看页面，不应像说明书一样堆长段落。默认状态只保留玩家做决定需要的信息；解释性内容放到悬停、选中详情或二级展开里。

通用规则：

- 一个面板只保留 1 个标题层级，不同时出现“传送门目标 / 选择要进入的战役”这类重复标题。
- 默认卡片最多 3 行核心信息；超过 3 行必须折叠到详情。
- 尽量用短标签和数值表达，例如“Boss”“掉落”“威胁”“推荐”，不用整句解释。
- 空状态不写长说明，统一用“暂无装备”“未解锁”“未获得”“无精英”。
- 主要按钮只保留动词，例如“进入”“穿戴”“强化”“分解”“锁定”“卸下”。
- 不在默认列表中展示教学句、系统解释、完整构筑说明；这些内容只在详情或告示说明页出现。

关卡选择：

### 开发者资产管理后台

当前项目怪物、Boss 和野兽召唤物越来越多，不能继续依赖人工改代码确认素材是否接入。需要新增一个仅开发环境可见的资产管理后台，用于查看、替换和校验怪物与召唤兽动作素材。

入口：

- 入口放在当前页面 `测试` 按钮位置，但该按钮只允许在本地运行时出现。
- 本地运行时点击 `测试` 后，优先打开开发者面板；面板内保留原有生命无限、不攻击等测试开关。
- “生命无限”仅授权用于 Boss 浏览器验收，并可在为抵达目标 Boss 层的同一次正式流程中保持玩家存活；它必须从开发者面板状态连续传入正式 `开始游戏` 创建的战斗快照，不得在开局时被重置。该开关不得用于普通怪、地图、掉落、数值或其他非 Boss 功能验收，默认关闭且验收结束后必须关闭。
- 生产构建、线上环境和任何非本地运行时必须隐藏 `测试` 按钮、开发者面板及生命无限、不攻击、Boss E2E 等全部子功能，不能让玩家进入或通过直接调用绕过。
- 2026-07-27 实现状态：正式 `开始游戏` 与重开已保留当前本地内存中的 `debugControls`，默认值仍为关闭且不写入玩家存档；测试入口、开发者 / 本地战斗面板、Store 测试 actions 与 E2E 全局接口已统一使用“非生产构建 + localhost / 127.0.0.1 / ::1”守卫。最新串行全量测试 `518/518`、生产构建和差异检查通过；生命无限的 Boss 正式流程与本地运行时 UI 边界仍须分别由 C、D 独立浏览器复验。

后台定位：

- 这是开发者工具，不是玩家功能。
- 只允许配置素材路径、动作映射、帧参数、锚点和预览。
- 不允许在后台直接改怪物数值、装备词缀、技能伤害、掉率、存档或经济。
- 不允许自动压缩、拉伸或降低素材质量；所有 UI / UX 和素材预览仍按“最高清晰度 + 最高素材密度”标准执行。

## 设计落地建议

短期不要一次性替换所有程序化矩形 sprite。更稳的做法是：

1. 先保留当前 `sprites.ts` 的绘制逻辑。
2. 引入一张小型 enemies sprite sheet，只替换敌人。
3. 再替换玩家、箭矢、技能场。
4. 最后把地牢 tile 和村庄交互物件统一到 asset manifest。

这样可以避免资产流程影响核心玩法迭代，同时马上提升战斗可读性。

- `damage` 是所有暴击、背击、正面防御、格挡、护盾、易伤、破防、Boss 护栏和其他修正完成后，目标生命实际减少的值。伤害为 `0`、被无敌完全阻止或只命中护盾而未减少生命时不写入本日志。
- 过量伤害按目标本次实际减少的生命记录，不把超出剩余生命的部分计入日志。
- 显示数字使用现有伤害数字的统一舍入规则，但内部累计保留原精度；同一事件不得因浮字与日志分别取整而产生明显不同的整数。

### 来源归因规则

#### 玩家侧

- Q / E / R 主动技能使用 `ARCHER_ACTIVE_SKILL_MAP` 或后续同一权威技能表中的中文名称。
- 自动普通攻击使用“普通攻击”。
- 天赋独立造成的伤害使用天赋中文名，例如“穿透魂火”“魂爆初醒”“血羽印记”“暴击羽裂”“血裂追击”“吸晶回响”“脉冲共鸣”。
- 持续伤害使用施加该状态的技能或天赋来源。由“流血箭簇”施加的流血记录为“流血箭簇”；不得统一写成内部枚举 `bleed`。
- 野兽普通攻击使用对应伙伴名称，例如“猎鹰攻击”；由战斗天赋触发的独立指令伤害使用天赋名，例如“指令突袭”“协同撕咬”“百兽合围”。
- 装备、套装和区域反应的独立伤害使用其玩家可见中文效果名；不得错误归因给最后按下的 Q / E / R。
- 多段技能每段均使用同一技能名，但反曲回箭出程与返程仍由实际分段命中、背击和暴击规则分别结算。

#### 怪物侧

- 怪物名称优先使用实体 `displayName`，缺失时使用正式怪物数据卡中文名；不得显示稳定 ID 或内部 archetype。
- 普通接触/近战攻击使用该实体数据卡的基础攻击中文名；若当前实体尚无更具体的已确认基础攻击名，统一使用“普通攻击”。
- 怪物主动技能、Boss 技能、投射物和持续区域使用正式技能中文名。
- 由某只怪物创建的地雷、毒雾、缩圈、火焰区域等伤害，仍归因给该怪物和对应技能。
- 无怪物来源的纯地图环境伤害不写入本日志，因为不满足用户确认的怪物句式；不得伪造怪物名称。

### 高频伤害合并与容量

- 同一 `side + attackerId + sourceId + targetId` 在连续 `0.5秒` 窗口内产生的高频持续伤害或同帧重复伤害合并为一条，`damage` 累加并实时更新最后一条文案。
- 不同目标、不同技能/天赋来源、不同攻击方不得合并。普通多段技能打中同一目标时可以按上述 0.5 秒窗口合并，但不能跨技能合并。
- 首次命中立即创建可见记录，不等待 0.5 秒窗口结束；窗口内后续伤害只更新该条。
- 内存最多保留最近 `120` 条聚合记录，超过后从最早记录开始删除。新对局、本地测试重新开始、主动退出或返回村庄时清空；暂停和层间奖励期间保留并停止变化。
- UI 默认显示最近 `8` 条，最新记录位于底部并自动滚动。面板允许鼠标滚轮查看当前对局保留记录，但滚动和悬停不得暂停战斗或拦截角色键盘控制。

### 左下角 UI 规则

- 面板放在现有 `combat-vitals-hud` 正上方，底部间距以不重叠生命 HUD 为准；桌面宽度建议约 `360-520px`，以真实句子不溢出为验收依据。
- 使用与现有 HUD 一致的深色半透明底、细边框和清晰中文正文字号，不使用巨大标题、卡片嵌套或覆盖战场中心的面板。
- 玩家造成伤害和怪物造成伤害可以使用不同文字颜色，但完整句子必须可读，不能只靠颜色区分方向。
- 长怪物名或技能名允许正常换行，单条记录不得截断关键的怪物名、技能名和伤害数字；8 条记录与生命 HUD、技能 HUD 在桌面和窄视口均不得重叠。
- `idle`、首页、村庄、猎手之家、告示牌和非战斗弹窗不显示日志。`running`、`paused`、层间奖励和本地战斗测试可显示当前对局已产生的日志。

### 实现边界

- A1 负责统一玩家伤害和玩家受伤的最终结算入口、来源归因、结构化事件、0.5 秒聚合语义，以及把原 40 个战斗天赋接入真实伤害/状态管线。
- B 负责事件类型与存储边界配合、左下角日志组件、固定中文格式、120 条容量、8 条视窗、滚动/响应式，以及原 40 节点 HUD/奖励归因展示。B 不得在 UI 中计算伤害或天赋触发。
- 当前代码中存在多个直接 `player.hp -=`、`enemy.hp -=` 路径。实现必须逐一审计并接入统一事件入口；不得只覆盖 `damageEnemy` 或弹体碰撞后声称日志完整，也不得借统一入口改变原伤害数值。
- C 验收原 40 节点真实战斗效果和玩家/怪物伤害归因；D 验收日志布局、格式、聚合、容量、滚动和界面不重叠。两者都必须使用正式浏览器战斗证据，不得只看测试桥摘要。

### 通过条件

1. 原 40 个节点逐项有真实消费路径，不存在静默忽略、错误别名或仅 UI 生效。
2. 通用、死契、血羽、兽王、蓝晶各至少完整复现一条从选择、进度、触发、伤害到日志的链路。
3. 玩家主动技能、普通攻击、天赋独立伤害、持续伤害和野兽伤害均能以正确中文来源写入玩家句式。
4. 普通怪近战、远程投射物、怪物技能和 Boss 技能均能以正确怪物名和技能名写入怪物句式。
5. 正面防御、背击必暴、破防、易伤等修正后的日志伤害与目标实际生命减少一致；0 伤害和纯护盾吸收不写入。
6. 高频持续伤害按 0.5 秒窗口正确聚合，不同目标或不同来源不串行；最多保留 120 条、默认严格完整显示最近 8 条。
7. 战斗中、奖励层和暂停层均可通过滚轮、触控板和触摸手势上下查看历史记录，滚动不穿透；位于底部时自动跟随新记录，离开底部查看历史时保持当前位置，主动回到底部后恢复跟随。
8. 三种日志表面的背景 alpha 均为 `0.6`，文字、数字与边框保持原不透明度和可读性。
9. 左下角日志不遮挡生命 HUD、技能 HUD、准星、奖励弹窗和暂停菜单；窄视口无关键文案截断或界面重叠。
10. 新增 32 个形态天赋仍未进入实现、候选或展示范围。
