## 2. 战斗塔身与朝向

- 继续消费 A1 已实现的每塔 `horizontalFacing` 只读状态：新塔默认右；实际射击目标在左／右时分别选用同形态的左／右原图；目标正上／正下、无目标或待机时保留上次方向。多塔各自独立。不改目标选择、真实箭矢起点／方向／碰撞或攻击时间。
- **完全取消此箭塔的渲染镜像**：不以 `scaleX(-1)`、负画布缩放、CSS 翻转、位图翻转或其他手段由右图生成左图。左右分别直接绘制用户对应原图；不纵翻、不旋转、不新增攻击动画。其他实体既有朝向逻辑不受影响。
- 三形态的可见高度仍为玩家稳定站立基准的 `1.5` 倍（当前 `41 × 1.5 = 61.5` 世界／逻辑单位）。逐张测量实际非透明边界，按可见高度等比缩放；逐张以可见底部中心锚定同一塔地面坐标。切换左右时不得跳位、漂浮或改变碰撞体；保持像素画面的既有 nearest 绘制口径。
- 保留既有血条、狂暴／嘲讽／共鸣反馈、实际投射物和伤害日志，以及世界遮罩与 HUD 绘制层级。资源未就绪不得拿旧 V1 图或镜像图伪装完成；加载门控与失败重试按第4节处理。
