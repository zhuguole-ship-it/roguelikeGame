# 物品仓库简化与装备信息悬停设计

状态：**已实现，自动化通过；C/D 条件通过，部分浏览器边界未充分验证。**

## 目标

把物品仓库收敛为“左侧已穿戴装备 + 右侧图标背包”。装备具体信息按鼠标悬停按需展示，材料进入背包筛选；移除封印及所有不再服务该目标的仓库信息区。

## 不变边界

- 不改装备模板、装备属性、说明、来源、套装实际效果、掉落、经济、材料数量/消费规则或正常战斗结算。
- 不改装备图鉴的独立展示规则；本设计仅作用于物品仓库。
- 右侧背包中仅调整展示和筛选，不改变真实仓库/穿戴/卸下链路。

## 1. 装备封印彻底移除

- 移除装备封印相关的 UI、操作、运行时判断、存档字段、持久化/恢复逻辑和测试。
- 历史本地存档中的封印状态在加载/迁移时一律清除；原先封印的装备恢复为普通、可穿戴/卸下/整理的装备。
- 不得留下“封印”“解封”、锁定图标、不可操作限制或旧字段回写；除装备封印外的任何物品状态不受影响。

## 2. 左侧已穿戴装备

- 保留已穿戴装备名称；鼠标悬停名称打开装备信息弹窗。
- 弹窗仅显示：**属性、说明、套装效果（如适用）、来源**。名称已在触发位置可见，弹窗不重复展示无关字段。
- 移除左侧装备下方的“属性”汇总区与“材料”区。
- 移除套装进度、下一件提示及其所有辅助文案/计算。

## 3. 右侧背包与悬停信息

- 背包“装备”筛选统一容纳所有武器和防具，不再提供武器、头盔、胸甲、护肩等部位筛选，也移除旧“视图”筛选。
- 装备条目只显示图标；不在格子内显示装备名称、属性或套装进度。
- 鼠标悬停图标打开弹窗。弹窗顶部显示**装备名称**，随后仅显示：**属性、说明、套装效果（如适用）、来源**。
- 触屏/键盘焦点必须提供与 hover 等价的信息回退，不能令无 hover 输入方式无法读取装备详情。

### 与猎手之家装备图鉴同源的定位（后续确认，待实现）

- 仓库左侧已穿戴名称与右侧背包装备图标的信息展示，必须与“猎手之家 → 装备图鉴”使用同源的悬停弹窗行为与视觉样式：弹窗锚定在当前悬停的名称或图标附近，并在视口内自动避让。
- 移除仓库中作为背包栏底部详情区的装备信息展示及其预留空间；悬停、键盘焦点和点击回退均使用同一类贴近触发目标的详情弹窗。
- 字段边界不变：左侧不重复装备名称；右侧顶部显示装备名称；其余只展示属性、说明、适用时的套装效果与来源。弹窗内不放置穿戴、替换或卸下操作按钮。

### 装备操作：拖拽与双击

- 信息弹窗不保留“穿戴 / 替换 / 卸下”等操作按钮，弹窗仍只承载已列出的信息字段。
- 玩家可把右侧背包装备图标拖至左侧对应装备位：空位即穿戴，有装备即替换；拖至不匹配部位不执行任何装备变更。
- 玩家可把左侧已穿戴装备图标拖回右侧背包区域以卸下。
- 双击右侧背包装备图标：其对应左侧装备位为空时穿戴；已有装备时替换该位现有装备。
- 双击左侧已穿戴装备图标：卸下回背包。左侧仍保留装备名称，名称 hover 只显示信息；双击操作的命中目标为图标而非名称。
- 拖拽、双击、键盘/触屏替代入口均必须最终调用同一真实仓库/穿戴/卸下链路，不能绕过封印迁移或存档规则。

## 3.1 固定装备栏与局部滚动

- 左侧已穿戴装备栏缩减为紧凑固定区；在桌面 `1440×900`（最小）至 `1920×1080`（最大）及其间的尺寸，必须完整显示所有已穿戴槽位，不得在左侧或仓库外层产生纵向滚动。
- 移除“已穿戴 / 拖拽背包图标到对应槽位，或双击图标穿戴/替换。拖拽已穿戴图标回背包，或双击图标卸下。”整段操作提示文案；拖拽与双击交互本身保留。
- 只有右侧背包的装备/材料**图标内容格**可纵向滚动。仓库外层、标题、筛选、左侧已穿戴栏及其父区域必须固定；滚动链不得冒泡到页面或导致拖拽时左栏离开视野。
- 本项响应式验收桌面范围固定为 `1440×900–1920×1080`；不将 `390×844` 作为本次布局验收门槛。

## 4. 套装效果显示条件

- 只有实际参与套装计件的装备显示“套装效果”。
- 不属于任何套装的装备不渲染“套装效果”标题、占位或空白。
- 对死契处刑者/血羽游侠的 6 核心与 Boss 替代核心，按其实际 `coreContribution=1` 显示；6 件联动散件 `coreContribution=0` 不显示套装效果，即使其有同流派联动单件效果。
- 其他装备按其真实套装计件归属决定，禁止从名称或稀有度猜测。

## 5. 材料筛选

- 右侧背包仅保留“装备”“材料”两个筛选项；默认“装备”。
- 原左侧材料区的同一材料数据移入“材料”筛选，不能复制或重置数量。
- 材料只显示图标；右下角以数字角标显示当前数量。材料悬停/焦点可显示现有材料名称与必要说明，但不套用装备属性、说明、套装效果或来源字段。

## 验收标准

1. 任意历史封印装备加载后可正常穿戴/卸下，存档中无封印残留；仓库不再出现封印操作/文案/图标。
2. 左侧装备名称 hover 与右侧装备图标 hover/focus/click 回退显示指定字段；右侧弹窗含名称，左侧不重复名称，信息弹窗无装备操作按钮。
3. 核心/替代核心显示套装效果；联动散件和非套装装备无该栏；无空白占位。
4. 左侧属性汇总、左侧材料、套装进度、下一件、视图和部位筛选均不可见且无残留交互。
5. “装备/材料”筛选准确分流，材料图标右下角数量与原数据一致。
6. `1280×720` 与 `390×844` 无横向溢出、裁切或遮挡；键盘/触屏替代交互可用，console 无新增 error/warn。
7. 类型检查、相关定向测试、生产构建与 `git diff --check` 通过；生产不暴露开发专属入口或封印旧功能。
8. 右→左拖拽的空位穿戴/占位替换、左→右拖拽卸下、右侧双击空位穿戴/占位替换及左侧图标双击卸下均调用真实链路；错误槽位拖放不改变装备。
9. `1440×900`、`1920×1080` 与两者之间的桌面尺寸中，左栏/仓库外层不滚动且完整可见；仅右侧装备/材料图标格可纵滚，拖拽时页面与左栏不离开视野，已移除指定操作提示文案。
