# 散射技能施放预览线移除 v1

状态：**已确认设计，实施中。**

## 目标

移除所有散射流派核心技能及其进化在实际施放时出现的扇形/路线预览线，包括从施法者出发的放射线、外侧弧形边框、扇形轮廓，以及双月等散射技能的同类路径框。

## 范围

- 适用于当前所有归属“散射压制”的核心技能、其已登记进化，以及作为独立散射核心的箭幕哨塔/箭塔相关散射施放。
- 删除施放预警、施放主体与命中反馈中仅用于表达散射几何的扇形轮廓、弧线、放射线和路线框；不得只删其中一个阶段而在后续阶段残留相同预览线。
- 保留实际箭矢/投射物 sprite、真实飞行、命中爆炸、落点区域、状态命中反馈及所有伤害、冷却、范围、数量和扇角的真实运行时机制。

## 不变边界

- 不改任何散射技能的几何、碰撞、命中、伤害、冷却、装备、天赋或进化数值。
- 不改非散射流派的施法效果、真实箭矢、敌方攻击预警或危险区域预警。
- 不恢复此前已移除的“散射压制逐箭飞行路径线”。

## 验收标准

- 所有散射技能及进化的施放画面不再出现粉紫/其他颜色的扇形边框、放射线或路线框。
- 实际箭矢、命中/区域效果与伤害链保持可见、可用且无数值回归。
- 至少覆盖基础散射、真扇进化、非真扇散射进化及箭塔散射施放；C/D 独立真实浏览器验收并记录未覆盖边界。
