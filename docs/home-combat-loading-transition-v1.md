## 3. 过场层级与动画时间轴

过场是位于首页、Canvas、战斗 HUD、弹窗和输入层之上的全视口顶层 UI。其显示期间，底层不得接收鼠标、键盘、触摸或游戏输入。

### 3.1 标准加载时间轴

适用于至少一个目标资源需要实际加载、下载、解码或重试的情况：

| 时间 | 表现 |
| --- | --- |
| `0.0–0.4s` | 从第0帧直接完整显示图1；不得显示白底 |
| `0.4–1.6s` | 图2在图1上方渐显，时长 `1.2s` |
| `1.6–4.0s` | 图1与图2保持完整可见，继续等待图3阶段 |
| `2.0–4.2s` | 图3与图1阶段重叠渐显并最终覆盖前两层，时长 `2.2s` |
| `4.2s` 之后 | 若资源或展示进度尚未完成，保持图3并继续平滑推进进度 |

标准过场最低总时长为 `4.2s` 有效前台可绘制时长。

### 3.2 全缓存时间轴

当本次清单中的全部资源在过场开始时均已缓存并可直接就绪时，仍需完整展示三阶段动画，不允许跳过；使用等比例压缩后的最低 `2.2s` 有效前台可绘制时间轴：

| 时间 | 表现 |
| --- | --- |
| `0.0–0.2s` | 从第0帧直接完整显示图1；不得显示白底 |
| `0.2–0.8s` | 图2在图1上方渐显 |
| `0.8–2.1s` | 图1与图2保持完整可见 |
| `1.05–2.2s` | 图3重叠渐显并成为最终画面 |

若只要一个必需资源不能在开始时直接就绪，就不得误用 `2.2s` 缓存路径，应使用标准 `4.2s` 路径。

### 3.3 结束

- 结束条件为“真实进度达到 `100%`”“展示进度平滑达到 `100%`”且“当前路径最低动画时长结束”三项同时成立。
- 条件成立后，图3、进度条和整个过场统一以 `0.4s` 淡出。
- 淡出结束后才允许首页交互，或启动战斗模拟、计时、敌人行为与玩家输入。
- 不提供点击、键盘、触摸、设置项或调试快捷键跳过过场的正式路径。
- `prefers-reduced-motion` 不得绕过加载门控或最低时长；本功能只有必要的透明度状态过渡，不增加平移、缩放、抖动或额外装饰动画。

## 5. 真实就绪与平滑展示进度条

- 进度条从图1出现的第一帧持续显示到过场淡出结束，位于视口底部安全区并水平居中。
- 使用响应式宽度；轨道为半透明深色底、暗金描边，填充色取图2标题的暗红橙色。
- 进度条中央显示平滑后的整数百分比，不增加加载提示、技巧或其他文案。
- 加载器必须分别维护“真实进度”和“展示进度”：真实进度按“已就绪必需素材数量 ÷ 本次必需素材总数量”计算；每个清单项只在满足其就绪条件后计数，真实进度单调不回退。
- 展示进度只能逐帧、单调地追赶真实进度，不得因资源批量完成而从低数值突然跳到高数值或 `100%`；展示进度任何时刻不得超过真实进度。
- 当前动画最低时长尚未结束时，展示进度还必须受当前时间轴完成比例约束。即使真实进度在开始时已经是 `100%`，展示进度也要从 `0%` 开始，沿当前 `2.2s` 或 `4.2s` 最低时间轴平滑增长；允许为了满足可见增量上限而在最低动画时长结束后继续增长，禁止为了准点结束而跳到 `100%`。
- 若最低动画时长结束时真实进度仍低于 `100%`，保持图3并让展示进度平滑追赶真实进度；后续真实进度跳升时仍不得直接跳数。真实进度未达到 `100%` 时，展示进度不得显示 `100%`。
- `2.2s`／`4.2s` 均按“有效前台可绘制时长”计算：`document.hidden` 期间不累计；主线程长任务或低帧造成相邻回调间隔超过 `100ms` 时，本次最多只累计 `100ms`，超出部分不得在恢复后补算。
- 平滑推进必须使用有效经过时间插值或等价实现，不得按固定帧数累加。后台切页、低帧率和不同刷新率下，恢复后必须从暂停前的展示值继续，不得按墙钟追赶、跳数或直接补到 `100%`。
- 可见进度以 `100ms` 为验收采样窗口时，任意相邻样本增量不得超过 `5` 个百分点；正常刷新率下应更连续。该上限同样适用于资源批量完成、页面恢复和主线程长任务恢复后的首个可绘制更新。
- 图片、图标、精灵图和动画帧：完成下载并可解码／绘制后就绪。
- 字体：完成字体加载并可供目标 UI 使用后就绪。
- BGM 与音效：完成下载并达到可用状态后就绪；不要求在过场内播放，正式播放继续服从浏览器用户交互授权。
- 配置数据：完成下载、解析和最低结构校验后就绪。
- 缓存全部命中时，真实进度可以立即达到 `100%`，但展示进度必须在不少于 `2.2s` 的全缓存动画内从 `0%` 平滑增长到 `100%`；允许实际增长时间超过 `2.2s`，不得先显示 `100%` 再空等动画结束。
- 平滑展示只改变玩家看到的数值与填充宽度，不得反向修改真实就绪状态，也不得让未就绪资源提前通过加载门控。
