# 十关卡战役与装备驱动重构方案

## 设计边界

本文只定义游戏设计，不涉及代码、UI/UX 实现或具体工程改动。

本次重构目标是把当前短局房间制推进，升级为更长期、更有刷装动力的暗黑幻想 Roguelite 战役结构：

- 游戏共有 10 个大关卡。
- 每个大关卡 22 层。
- 每个大关卡都有普通、困难、地狱、折磨四个难度。
- 10 个大关卡彼此独立，所有关卡的普通难度默认开放；每个关卡内部必须按普通 -> 困难 -> 地狱 -> 折磨逐级解锁。
- 每 3 层必定出现精英怪。
- 层数越高，精英怪数量越多。
- 所有非 Boss 层的怪物总数量在当前目标基础上整体翻倍；第 3 层之后继续用怪潮倍率、精英预算和怪物构成控制节奏，避免难度断崖。
- 玩家不再每层手动分配属性点。
- 怪物掉落蓝色晶石，拾取后增加局内经验。
- 玩家局内升级不再自动提升基础属性；局内等级只服务技能构筑推进和结算换算。
- 新增完整装备系统，装备与技能流派强绑定。
- 所有技能、装备、怪物、特效、立绘素材标准提升到最高密度与最高可读性。

## 调整后的核心原则

这版保留 10 个大关卡、每关 22 层、精英密集、刷怪爆装的方向，但需要避免三个风险：

- 220 层内容过长导致疲劳。
- 第 3 层后怪物数量突然翻倍导致难度断崖。
- 装备位和词缀一次性全开放导致信息过载。

因此采用以下原则：

- 每关 22 层按 4 个阶段理解，而不是 22 个重复房间。
- 所有非 Boss 层总怪物目标先整体翻倍，再通过层段怪潮倍率逐步增长；实现上必须明确区分“数量翻倍”和“掉率变化”。
- 精英使用“精英预算”，数量、强度、词缀共用预算，不单纯堆怪。
- 装备位逐步开放，让刷装目标分阶段出现。
- 玩家基础属性主要来自装备和后续天赋系统，蓝晶经验不再直接堆生命、攻击、攻速或移速。
- 紫色以上装备优先改变技能形态，而不是只堆数值。
- 每个大关卡必须有清晰的刷装理由：主题威胁、偏向掉落、推荐构筑强度和可追求装备要互相咬合。
- 装备联动以少数“改变技能形态的大词缀”为主，普通数值词缀为辅，避免玩家背包里充满难以判断价值的小修小补。
- 普通层使用轻结算，精英层和 Boss 层才给玩家明确的核心奖励选择，避免 22 层节奏被频繁弹窗打断。
- 每个大关卡都是独立契约任务。通关第 22 层后返回首页 / 村庄，由玩家重新选择下一次进入哪个关卡。
- 关卡之间没有线性前置关系，但同一关卡的高难度必须通过前一难度后解锁；关卡数字越大，普通难度也必须比前面关卡更强。
- 紫色以下地下城装备定位为本次战斗的临时推进燃料，离开战斗时自动分解为材料；只有史诗、传承、传奇装备进入长期仓库。
- 高关卡怪物基础生命、攻击、抗性和技能强度必须明显高于低关卡，服务有一定刷怪时长和装备积累的玩家；但怪物常驻移速不应线性失控。
- 当前战斗追击压力偏弱，普通怪常态移速需要整体上调，但只能在类别软上限内提高，不能重新回到后期异常高速贴脸的问题。
- 数量翻倍后，装备掉率和蓝晶掉率按单怪概率保持不变，不做隐藏下调，也不额外提高；治疗药水属于补给掉落，最终掉率在现有计算结果上直接减半。
- 战斗场地从固定房间升级为“受控伪无限地图”：玩家感知上没有硬边界，但系统只保留玩家周围区块、怪物、障碍和掉落，保证怪潮爽感与性能稳定。
- 素材密度提高必须服从战斗可读性。

## 世界观重构

主角不是传统英雄，而是从地牢中被释放出来的死契奴隶。

国家与主角签订“死亡契约”：主角必须进入怪物横行的边境、古堡、森林、沼泽、矿坑、迷宫与龙巢，击杀足够数量的怪物。只要契约记录中的怪物血债达到赦免标准，国家就会抹去他过去的罪行。

这让游戏的刷怪行为有明确叙事动机：

- 杀怪不是单纯冒险，而是偿还罪行。
- 装备不是宝物收集，而是活下去的刑具与赎罪工具。
- 每个关卡都是国家丢给死契者的“处刑任务”。
- 怪物阵营不是随机混搭，而是王国边境真正失控的威胁。

核心叙事基调：

- 黑暗中世纪
- 死亡契约
- 奴隶赦免
- 怪物边境
- 装备驱动的生存与复仇

### 关卡独立与四难度结构

10 个大关卡是独立契约任务，不按关卡数字线性解锁。玩家可以从任意关卡的普通难度开始挑战，用自己想刷的主题装备、Boss 武器和套装方向决定路线。但每个关卡内部必须遵守难度递进：

```text
第 N 关普通通关
-> 解锁第 N 关困难
-> 解锁第 N 关地狱
-> 解锁第 N 关折磨
```

解锁规则：

| 规则 | 设计 |
| --- | --- |
| 初始开放 | 第 1-10 关普通难度全部开放。 |
| 内部递进 | 同一关卡必须按普通 -> 困难 -> 地狱 -> 折磨解锁。 |
| 关卡独立 | 第 3 关普通通关只解锁第 3 关困难，不影响其他关卡。 |
| 高关强度 | 第 10 关普通也明显强于第 1 关普通，甚至强于部分低关卡困难。 |
| 刷装路线 | 玩家可自由选择想刷的关卡主题，但要逐步攻克该关高难。 |

怪物强度统一使用后文“怪物属性与爽感解锁曲线”的后期公式作为唯一实现口径。四难度只作为额外乘区，不再维护前期旧版小系数表。

```text
怪物最终生命 =
怪物定位生命基准 x 关卡生命系数 x 层数强度系数 x 难度生命系数

怪物最终攻击 =
怪物定位攻击基准 x 关卡攻击系数 x 层数强度系数 x 难度攻击系数

怪物最终移速 =
怪物移速基准 x 难度移速系数 x 行为修正，之后受类别软上限裁切
```

其中：

- 怪物定位生命 / 攻击 / 移速基准，以后文“怪物定位基础值”表为准。
- 关卡生命 / 攻击系数，以后文“关卡强度系数”表为准。
- 层数强度系数，以后文“层数强度系数”表为准。
- 难度生命 / 攻击 / 移速 / 数量 / 精英预算 / 高价值掉落权重，使用下表。

四难度额外系数：

> 最高难度统一命名为「折磨」。如果旧存档或旧代码中仍存在 `nightmare` / 「噩梦」标识，实现时只能做兼容映射，UI 和新文档口径使用「折磨」。

### 层数通关奖励节奏

每层通关奖励需要服务“继续刷下去”的节奏，而不是每层都打断玩家做复杂选择。新的奖励节奏分为轻结算、节点奖励和本关结算三类。

| 层数类型 | 奖励定位 | 奖励内容 |
| --- | --- | --- |
| 普通层 | 快速推进 | 自动吸附剩余蓝晶、少量金币、记录本层装备掉落、显示自动分解预估 |
| 3 / 6 / 9 / 12 / 15 / 18 / 21 精英层 | 构筑强化点 | 技能升级机会、较高装备掉率、材料包、精英专属词缀装备 |
| 13 / 14 主题机制层 | 关卡特色补强 | 本关抗性、本关环境克制材料、本关印记小额掉落 |
| 19 / 20 Boss 前置层 | Boss 前补给 | 回血、下一层输出强化、Boss 掉落权重提升三选一 |
| 22 Boss 层 | 本关大结算 | 本关传承装备保底、紫色以上装备带回、通关记录、返回首页 |

普通层结算只显示一条简洁信息，不弹出复杂奖励选择：

- 本层获得经验来自蓝晶，不再额外给属性点。
- 本层获得金币直接入账。
- 本层掉落装备只突出关键装备数量和品质。
- 紫色以下装备显示“离开战斗后自动分解预估材料”。
- 如果本层掉落史诗及以上装备，才弹出关键战利品提醒。

精英层和 Boss 前置层允许出现奖励选择，因为这些层本身就是节奏节点：

- 精英层优先给技能升级、构筑强化、精英词缀装备或流派材料。
- Boss 前置层只给短期补给，不产生长期仓库负担。
- Boss 层给完整结算，但结算后不自动进入下一关。

### 单关通关与返回首页

每个大关卡是一个独立的死亡契约任务。玩家进入第 N 关后，只在该关第 1-22 层内部推进。

通关规则：

1. 击败第 22 层 Boss 后，本关立即结束。
2. 系统展示本关结算，包括击杀、蓝晶经验、金币、保留装备、自动分解材料和首次通关记录。
3. 结算后返回首页 / 村庄。
4. 玩家从首页传送门重新选择要进入的关卡。
5. 不自动进入第 N+1 关。

Boss 结算建议按钮：

| 按钮 | 作用 |
| --- | --- |
| 返回首页 | 完成本关并回村，是默认主按钮 |
| 查看战利品 | 查看本关保留的史诗、传承、传奇装备 |
| 选择其他关卡 | 返回传送门关卡选择 |
| 再战本关 | 回首页后重新选择当前关卡，不在结算页直接连战 |

这样可以让每个大关卡都像一次明确的契约派遣，而不是 220 层连续爬塔。玩家的长期目标变成“根据装备和构筑选择刷哪一关”，而不是被系统自动推到下一关。

### 每关刷装理由与主题威胁

每个关卡都必须承担一个明确的刷装目标。高层关卡的怪物基础数值可以明显强于低层关卡，但强度来源优先来自生命、攻击、精英机制、主题压迫和地形风险，移动速度只做有限提升，避免玩家感觉怪物异常高速贴脸。

| 关卡 | 主题定位 | 主要刷装理由 | 推荐进入状态 | 主题威胁 | 数值构筑护栏 |
| --- | --- | --- | --- | --- | --- |
| 1 死契地牢 | 新手入门、死契处刑 | 死契处刑者、穿透直线、基础武器/胸甲/鞋子/戒指 | Lv1-Lv2 主动技能，灰白绿装即可尝试 | 史莱姆潮、骷髅战士队列、地狱犬火焰、骷髅骑士冲锋 | 怪物速度接近基准，只用数量和精英层制造压力 |
| 2 吸血鬼古堡 | 暴击、流血、生命汲取反制 | 血羽游侠、暴击散射、吸血抗性、处决收益 | 至少 2 个主动技能 Lv2，绿色/蓝色混装 | 蝙蝠群、血池、吸血恢复、远程血矢 | 提高生命和恢复压力，速度只小幅高于第 1 关 |
| 3 狼人黑森林 | 野兽流、机动和流血 | 兽王赦令、野兽伤害、流血抗性、移速/闪避 | 核心技能 Lv2-Lv3，有一件蓝装更稳 | 狼群包抄、跳扑、撕裂流血、月怒加速 | 用短突进表现速度感，常态移速不能超过软上限 |
| 4 女巫沼泽 | 区域控制、毒雾和减速 | 区域范围、持续时间、毒/减速抗性、控制联动 | 至少一组区域或散射技能成型 | 毒沼、诅咒、减速、女巫召唤物 | 降低直线追击速度，用地面区域逼迫走位 |
| 5 兽人战争营地 | 护甲、击退、正面压制 | 散射压制、护甲穿透、格挡/击退、战鼓反制 | Lv3-Lv4 技能，蓝装为主 | 盾兵推进、战鼓强化、投矛、冲锋兵 | 高生命和护甲，速度中等，避免重甲怪还高速追人 |
| 6 精灵失落圣林 | 精准远程、冷却和束缚 | 穿透/散射精准词缀、冷却、暴击、解控 | 至少 1 个 Lv4 技能，紫装开始有价值 | 游侠风筝、藤蔓束缚、治疗结界、幻影 | 远程威胁升高，近战速度保持可读 |
| 7 巨魔与地精矿坑 | 材料、爆炸、陷阱和厚血目标 | 蓝晶契约、锻造材料、爆炸区域、破甲 | 1 个 Lv5 或多个 Lv4，紫装为主 | 地雷、炸桶、巨魔再生、地精工程 | 生命/护甲显著提高，速度仍低于轻型怪 |
| 8 鱼人潮汐神殿 | 控场、拾取范围、潮汐位移 | 区域控制、拾取范围、减速抗性、水/雷联动 | Lv5 技能开始成为主力，有稳定紫装 | 水潮推拉、鱼人群涌、潮汐祭司、链雷 | 用位移和区域威胁制造难度，不堆高速追击 |
| 9 牛头人迷宫 | 高压近战、眩晕和 Boss 准备 | 防御、眩晕抗性、重矢/穿透、精英处决 | Lv5 核心技能，橙装或强紫装联动 | 冲锋、迷宫障碍、重击眩晕、护卫墙 | 高攻击和冲锋预警，常态追击速度严格封顶 |
| 10 巨龙审判火山 | 终局构筑、传承/传奇追求 | 橙色传承、亮橙传奇、跨流派终局词缀 | 至少 1-2 个 Lv5 核心技能，橙装构筑成型 | 岩浆、龙裔、火山喷发、Boss 多阶段 | 主要强度来自伤害、血量、阶段机制和环境，不靠怪物高速碾压 |

数值设计要求：

- 后续关卡的基础生命、攻击和精英机制可以明显更强，但普通怪常态移速只允许小幅阶梯增长；需要速度感时使用“有预警的短突进/冲锋/跳扑”，而不是永久高速。
- 同一关卡内怪物要有快慢层次：炮灰负责数量，主题怪负责机制，精英负责压迫。不能让全部怪物都同时高血、高攻、高速。
- 推荐进入状态只是提示，不是硬性门槛；低强度玩家可以进高关卡体验压力，但掉落效率、清怪速度和生存成本会自然劝退。
- 每关掉落偏向只提高对应构筑出现概率，不应该锁死其他流派基础装备，避免玩家被迫刷单一路线。

### 无限地图战斗结构

后续战斗地图不再使用固定房间边界，而是改为“受控伪无限地图”。玩家可以朝任意方向持续移动，镜头跟随玩家，画面中不出现传统硬墙或矩形房间边框。

这里的无限地图不是无上限地保留所有世界内容，而是通过玩家周围的地图区块生成和回收，让玩家感知上拥有无限空间，同时控制性能、刷怪和掉落节奏。

核心目标：

- 去掉固定房间带来的贴墙、卡角和狭小空间拥挤感。
- 承载中后期高同屏怪潮，让主动技能有更完整的清屏爽感。
- 让每个关卡主题通过地面、障碍、环境物和危险区域持续出现，而不是只换一张背景。
- 保留每层明确击杀目标，不改成无尽生存模式。
- 避免玩家靠无限逃跑完全规避战斗。

#### 地图生成规则

地图使用区块生成，推荐每个区块为 512x512 或 768x768。系统只保留玩家周围 3x3 到 5x5 区块，远离玩家的区块进入回收池。

每个区块由以下因素确定：

```text
区块内容 = 关卡编号 + 层数 + 区块坐标 + 本局随机种子
```

这样可以保证同一局中地图生成稳定，不会因为镜头抖动或反复进出边缘导致障碍闪烁。

区块内容包括：

- 地面主题纹理。
- 小型装饰物。
- 可碰撞障碍。
- 环境危险预留点。
- 怪物刷新候选点。

#### 障碍物刷新规则

障碍物必须服务走位和聚怪，而不是随机阻塞玩家。

通用规则：

- 玩家半径 280 像素内不生成新障碍。
- 玩家当前移动方向前方保留至少一条可通行走廊。
- 不允许生成完全封闭玩家的障碍环。
- 大型障碍之间必须保留足够宽度，允许玩家和怪潮通过。
- 障碍物不能直接生成在 Boss、精英、传送裂隙、关键掉落上。

障碍密度随层段变化：

| 层段 | 障碍密度 | 设计目的 |
| --- | ---: | --- |
| 1-2 | 低 | 让玩家适应无限地图和主题怪 |
| 3-8 | 中低 | 提供基础绕障碍和聚怪点 |
| 9-15 | 中 | 形成更多拉怪路线和区域技能落点 |
| 16-21 | 中高 | 高压刷装阶段，但不能堵死移动 |
| 22 Boss | 独立 Boss 场域 | 障碍数量由 Boss 机制决定 |

不同关卡使用不同障碍风格：

| 关卡 | 障碍主题 |
| --- | --- |
| 死契地牢 | 断墙、铁笼、锁链柱、碎石堆 |
| 吸血鬼古堡 | 石棺、烛台、破败家具、血池边缘 |
| 狼人黑森林 | 树干、倒木、巨石、爪痕灌木 |
| 女巫沼泽 | 毒沼、蘑菇群、巫毒桩、烂木 |
| 兽人战争营地 | 木栅栏、兽皮帐篷、战旗、火盆 |
| 精灵失落圣林 | 树根、圣林石碑、藤蔓、星辉祭坛 |
| 巨魔与地精矿坑 | 矿车轨道、炸药桶、支架、矿石堆 |
| 鱼人潮汐神殿 | 珊瑚、潮池、贝壳石柱、水蚀石块 |
| 牛头人迷宫 | 迷宫墙残片、石柱、铜门碎片、祭坛 |
| 巨龙审判火山 | 熔岩裂缝、黑曜石、龙骨、火山喷口 |

#### 短时路线目标

无限地图不能只让玩家绕圈拉怪，需要在战斗中持续给玩家“往哪里走”的短期判断。路线目标是可选收益点，不是通关必需品，作用是制造风险收益、改变走位路线、提高技能轰怪爽感。

| 路线目标 | 持续/触发 | 奖励 | 风险 | 适用阶段 |
| --- | --- | --- | --- | --- |
| 蓝晶富集裂点 | 出现 12-16 秒，靠近后激活 | 裂点范围内蓝晶经验 +20%-25%，额外喷出小批蓝晶 | 激活后刷出一小波炮灰和 1 个主题怪 | 所有关卡，前 5 层最多 1 个 |
| 精英巡逻旗 | 地图边缘预告 18 秒，击杀巡逻队长 | 提高本层关键装备/材料掉落权重 | 巡逻队含 1 个高威胁单位，但不额外叠移速 | 第 3 层后 |
| 契约火印 | 站入范围 2.5-3 秒充能 | 下一次 Q/E/R 技能获得 +10%-15% 效果强度 | 充能时两侧刷出拦截怪，打断走位节奏 | 第 4 层后 |
| 遗物碎箱 | 普攻或技能打碎 | 少量材料、装备提示或一次临时补给 | 打碎后触发伏击，怪物从非正面方向进入 | 第 6 层后 |
| 主题危险区 | 血池、毒雾、岩浆、潮汐等周期出现 | 区域内击杀提高对应主题掉落权重 | 地形伤害、减速、推拉或视野压迫 | 按关卡主题启用 |

生成与数值护栏：

- 1-5 层同屏最多 1 个路线目标，6-14 层最多 2 个，15-22 层最多 3 个。
- 路线目标不在玩家 260px 内直接生成，不与 Boss 入口、传送门、关键掉落重叠。
- 路线目标奖励总量不能超过本层基础奖励的 15%-25%，不能直接产出橙色或亮橙装备；橙色和亮橙仍主要来自 Boss 与高层关键掉落。
- 路线目标带来的额外怪物只增加压力类型，不添加隐藏速度倍率。额外高威胁单位数量不超过当前怪潮上限的 5%-8%。
- 目标过期后自然消失，未参与也不惩罚玩家，避免路线目标变成强制任务。

#### 怪物刷新规则

怪物不再从固定房间边缘生成，而是从玩家视野外的环形区域刷新。

推荐刷新区域：

- 最小距离：玩家视野边缘外 120-180 像素。
- 最大距离：玩家视野边缘外 480-720 像素。
- 不生成在玩家正脚下、障碍内部或不可达区域。
- 刷新点优先分布在玩家前侧和侧翼，少量从后方追击，避免玩家只向一个方向跑就完全安全。

刷新构成仍沿用现有怪潮结构：

- 腐蚀史莱姆作为 60%-70% 的炮灰层。
- 主题普通怪作为 20%-30% 的关卡识别层。
- 高威胁怪作为 5%-10% 的打断与走位压力。
- 精英只在精英层或特殊预算中出现。

远离玩家的普通怪可以回收或重新投放到玩家外圈，但必须满足：

- 精英和 Boss 不回收。
- 已经进入攻击或技能状态的高威胁怪不立即回收。
- 回收不能让玩家看见怪物凭空消失。
- 重新投放不额外增加击杀目标和掉落收益。

#### 防无限逃跑规则

无限地图不能让玩家只靠直线逃跑绕过关卡。

当玩家持续远离怪潮或长时间没有击杀时，可以触发轻量压力机制：

- 在玩家前方侧翼生成小型拦截怪群。
- 临时提高刷新环的前方权重。
- 生成关卡主题环境危险，例如毒雾、血池、地雷、火山裂缝。
- 让少量追猎型高威胁怪从侧后方进入。

限制：

- 不通过无限叠加移速追玩家。
- 不在玩家脚下直接刷怪。
- 不用看不见的墙硬拦。
- 压力机制必须有视觉或文本提示。

#### 掉落与蓝晶回收

无限地图下，玩家不应因为持续移动而漏掉大量奖励。

蓝晶规则：

- 蓝晶生成后短时间停留，形成刷怪反馈。
- 距离玩家过远或层目标完成后，自动进入长距离吸附。
- 普通层轻结算时自动吸附本层剩余蓝晶。

装备规则：

- 掉落装备进入本层掉落记录。
- 史诗以下地下城装备可以临时拾取和装备，但离开战斗自动分解。
- 史诗、传承、传奇装备需要有更明显的屏幕边缘提示，避免玩家在无限地图中错过。
- 距离过远的装备可以转入“待处理战利品池”，在轻结算或 Boss 结算中展示。

#### 层目标与契约裂隙

每层仍以击杀目标推进，不改成无尽清怪。

当击杀数达到本层目标后：

1. 停止普通怪新增刷新。
2. 剩余普通怪可以减速、撤离或被契约裂隙吸收。
3. 在玩家附近安全位置生成“契约裂隙”。
4. 自动吸附远处蓝晶。
5. 玩家靠近或短暂等待后进入轻结算 / 节点奖励 / 下一层。

契约裂隙的作用是替代固定房间通关后的“房间清空”反馈，让无限地图也有明确层结尾。

#### Boss 层场域

Boss 层不使用完全开放的无限逃跑空间，而是生成大范围“契约封锁领域”。

Boss 场域规则：

- 场域比旧房间大，允许玩家拉怪和绕障碍。
- 场域边缘不是硬墙，而是契约雾、血幕、树墙、潮汐墙、火山裂缝等主题软边界。
- 玩家进入软边界时获得警告，继续深入会被推回、减速或受到环境伤害。
- Boss 不会因为玩家远离而丢失。
- Boss 召唤的护卫在场域内刷新，不能抢走 Boss 识别度。

Boss 战仍以机制压迫为核心，不能依赖超高速追击解决无限地图问题。

#### 性能与状态边界

无限地图必须保持模拟状态和渲染状态分离。

模拟层保存：

- 玩家世界坐标。
- 当前激活区块坐标。
- 敌人、投射物、掉落、障碍的可序列化数据。
- 本层随机种子。
- 本层击杀、掉落和结算记录。

渲染层负责：

- 根据玩家坐标偏移绘制地面和实体。
- 只渲染镜头附近内容。
- 处理粒子、残影、动画和屏幕提示。

性能目标：

- 同屏 200+ 怪潮时仍保持稳定推进。
- 激活区块数量有上限。
- 远离玩家的普通投射物、粒子和低价值掉落可以回收。
- 需要提供调试信息：当前区块数、敌人数、掉落数、回收数、帧耗时。

#### 验收标准

无限地图版本至少需要满足：

- 玩家向任意方向移动 2 分钟，不触发硬边界或坐标异常。
- 障碍不会生成在玩家身上，也不会形成不可逃离封闭圈。
- 第 1、5、10 关进入后都能生成对应主题障碍和怪物。
- 第 10 关高层 200+ 同屏压力下，区块和实体数量不无限增长。
- 玩家持续逃跑时会被刷新和环境机制重新施压，但怪物移速不失控。
- 达成击杀目标后能稳定生成契约裂隙并进入结算。
- 死亡、主动放弃、Boss 通关仍正常回村并触发紫色以下装备自动分解。

### 精英数量增长规则

每个大关卡内部，精英压力随层数提高。这里使用“精英预算”而不是死板数量，避免后期只靠堆精英造成混乱。

| 精英层 | 推荐精英预算 |
| --- | --- |
| 3 | 1 个普通精英 |
| 6 | 1 个强精英或 2 个弱精英 |
| 9 | 2 个普通精英或 1 个队长精英 |
| 12 | 2 个普通精英 + 1 个小精英 |
| 15 | 3 个普通精英或 1 个队长精英 + 1 个普通精英 |
| 18 | 1 个队长精英 + 2 个普通精英 |
| 21 | 2 个强精英，或 1 个守门队长 + 3 个小精英 |

大关卡越靠后，同一精英层的数量和词缀强度也应提高：

- 第 1-2 关：以 1-2 只精英为主。
- 第 3-5 关：常规出现 2-3 只精英。
- 第 6-8 关：精英开始带双词缀。
- 第 9-10 关：精英可带双词缀或小型队长机制。

精英预算换算：

- 小精英 = 0.5 预算。
- 普通精英 = 1 预算。
- 强精英 = 1.5 预算。
- 队长精英 = 2 预算。
- 双词缀精英额外 +0.5 预算。

## 全层数量翻倍与第 3 层后怪潮倍率

第 1-3 层用于让玩家识别本关主题怪物，但当前战斗怪潮偏稀，所有非 Boss 层的总怪物目标需要在当前版本基础上整体翻倍。从第 4 层开始继续进入更高密度怪潮区间，形成刷怪、刷晶石、刷装备的主要节奏。这里的“翻倍”指总击杀目标、剩余刷怪预算和普通怪刷怪批次需要同步提高，不等于提高掉率。

建议倍率规则：

- 第 1 层：旧基础数量的 200%。
- 第 2 层：旧基础数量的 240%。
- 第 3 层：旧基础数量的 280%，加入 1 只精英。
- 第 4-5 层：旧基础数量的 320%-360%，进入高密度预热。
- 第 6-8 层：旧基础数量的 360%-400%。
- 第 9-15 层：稳定在旧基础数量的 400%-420%。
- 第 16-20 层：旧基础数量的 440%-460%。
- 第 21 层：旧基础数量的 480%，作为 Boss 前压力峰值。
- 第 22 层：按 Boss 机制生成护卫，不直接套用怪潮倍率。

设计注意：

- 翻倍主要作用在普通怪、小型怪和腐蚀史莱姆；主题高威胁怪和精英只按原有比例/预算增长。
- 精英数量按精英层规则计算，不直接翻倍。
- Boss 层的护卫数量要服务 Boss 机制，不能抢走 Boss 识别度。
- 怪物数量增加后，蓝色晶石吸附、掉落亮度和拾取反馈必须足够清晰。
- 实现时允许同屏硬上限按性能小幅提高，但不能为了翻倍无限堆实体；如果同屏达到上限，剩余怪物通过更密集波次和更快补刷完成。
- 装备掉率和蓝晶掉率按单怪概率保持当前规则，不因为数量翻倍而隐藏下调，也不额外提高。预期总收益会随击杀数量自然增加，但不再叠加额外掉落倍率。

### 高同屏怪潮与炮灰怪规则

为了让 Q / E / R 主动技能产生“一发轰掉一片”的爽感，怪潮不能只靠少量高血怪填充。每层需要由大量低血炮灰、主题普通怪、高威胁怪和少量精英共同组成。

所有炮灰怪统一使用此前设计的“腐蚀史莱姆”：

- 腐蚀史莱姆是跨关卡通用炮灰单位，用于承载清屏爽感。
- 它不替代每个关卡的主题怪物，只作为怪潮填充层出现。
- 不同关卡可以通过轻微颜色污染、地面残渣或环境附着物做主题区分，但动作基底、受击反馈和死亡爆浆逻辑保持一致。
- 腐蚀史莱姆血量低、威胁低、数量多，主动技能命中后应成片死亡。
- 腐蚀史莱姆死亡时掉落少量蓝晶，形成大面积吸附轨迹和刷怪回收反馈。

同屏怪物目标分为常态密度、爆点密度和硬上限：

| 关卡段 | 常态同屏 | 爆点同屏 | 硬上限 |

设计底线：

- 高同屏数量主要由腐蚀史莱姆承担，不能把 200 只高威胁怪同时压给玩家。
- 腐蚀史莱姆应该低血、可读、容易被技能连片击杀。
- 主题怪和精英负责“危险”，腐蚀史莱姆负责“数量”和“爽感”。
- 清屏后必须有明显死亡爆浆、蓝晶掉落、吸附轨迹、金币 / 材料反馈。

### 怪物属性与爽感解锁曲线

高同屏怪潮不能让玩家在 0 时间投入时就获得完整清屏爽感。腐蚀史莱姆虽然是炮灰，但它也要跟随关卡和层数提高基础数值，保证大规模清屏是玩家通过技能等级、装备联动、关卡推进和操作聚怪逐步获得的结果。

核心规则：

- 第 1 关前几层只给“小爽”，让玩家知道技能能清怪，但不能一发清半屏。
- 第 3-5 关开始给“成片清怪”，需要 Lv.3-Lv.4 技能和基础装备支持。
- 第 6-8 关要求玩家有成型构筑，否则腐蚀史莱姆数量变多但不能轻松秒光。
- 第 9-10 关提供终局大怪潮，只有 Lv.5 质变、橙装 / 传奇联动和良好聚怪才能打出大清屏。

怪物最终属性建议使用：

```text
最终属性 = 怪物定位基础值 x 关卡强度系数 x 层数强度系数
```

## 高关卡怪物基础数值与移速控制

高关卡本质上是为已经有一定刷怪时长、装备积累和技能理解的玩家准备的内容。因此，第 6-10 关怪物的基础数值必须明显强于第 1-3 关，不能只靠数量或移速制造难度。

难度目标不是让玩家一路变简单，而是形成反复阶梯：

```text
打不过
-> 回村分解装备、强化装备、调整技能与套装
-> 勉强打过
-> 装备和技能成型后获得清屏爽感
-> 进入更高关卡或更深层再次打不过
-> 再刷装、再强化、再优化循环
-> 再次打得过并获得更大爽感
```

推荐用“推荐战力”描述关卡门槛，但不硬锁进入。玩家低于推荐战力时仍可进入高关卡，只是清怪效率、生存压力和 Boss 成功率会自然劝退；玩家高于推荐战力回刷低关卡时，可以快速清炮灰和刷材料。构筑未完成时，精英仍是打法考试；核心装备和核心技能正确搭配后，玩家可以用关键技能轰掉一片低 / 中预算精英。Boss、Boss 环境机制和高预算精英仍保留最低处理要求。

| 玩家状态 | 目标体验 | 怪物数值表现 | 奖励效率 |
| --- | --- | --- | --- |
| 明显低于推荐 | 打不过或打得很慢 | 炮灰也需要多次命中，主题怪明显抗揍 | 低，死亡或放弃频繁 |
| 接近推荐 | 勉强打过 | 需要 Q / E / R 循环、滑步和聚怪 | 中，能推进但不稳定 |
| 略高于推荐 | 开始爽 | 炮灰成片死亡，主题怪仍需处理 | 高，适合刷装 |
| 明显高于推荐 | 回刷碾压 | 普通层推进很快，精英和 Boss 仍有机制窗口 | 稳定，但高价值掉落受关卡限制 |

单层体验应拆成“压迫、破局、收割”三段。压迫段用多方向刷怪和主题怪制造危险；破局段让玩家通过鼠标准星释放 Q / E / R 打穿怪潮；收割段让炮灰死亡、蓝晶吸附和掉落反馈集中出现。这样玩家的爽感来自“处理压力后释放”，而不是进图无成本清屏。

### 玩家基准属性与战力护栏

第一版玩家基准以弓箭手为唯一职业。玩家基础值保持克制，主要成长来自装备、装备强化、套装、局内技能构筑和后续天赋，而不是局内经验自动加属性。

| 属性 | 初始值 | 第一版常态上限 | 爆发 / 临时上限 | 说明 |
| --- | ---: | ---: | ---: | --- |
| 最大生命 | 120 | 320 | 临时护盾另算 | 生存主要来自装备、防御词缀、兽王护主和血包决策。 |
| 普攻伤害 | 12 | 等效 3-5 倍 | 终局短窗可更高 | 装备、套装和技能联动提供主要输出。 |
| 攻击速度 | 1.10 次 / 秒 | 2.60 次 / 秒 | 3.20 次 / 秒 | 超过常态上限只能来自短时爆发。 |
| 移动速度 | 100 | 135 | 155 | 短时加速不能让玩家永久甩脱全部近战怪。 |
| 暴击率 | 5% | 45% | 60% | 血羽流可以接近上限，但不能常驻 100%。 |
| 暴击伤害 | 150% | 230% | 260% | Boss 和高预算精英仍按机制处理。 |
| 拾取范围 | 72 | 140 | 160 | 蓝晶契约和局外便利天赋主要改善手感。 |
| 滑步 | 160 距离 / 4.5s CD | CD 2.8s | CD 2.4s | 滑步是躲机制，不是永久无敌移动。 |

技能与冷却护栏：

| 项 | 上限 |
| --- | --- |
| 技能冷却缩减 | 常态总上限 45%。 |
| 技能命中冷却返还 | 总返还上限 25%，且需要触发间隔。 |

战力验收目标：

- 第 1-2 关普通难度，初始属性 + 少量蓝装应能完成基础教学。
- 第 3-5 关普通 / 困难，玩家需要至少 1 条明确流派路径和 2-4 件有效装备。
- 第 6-8 关地狱前后，需要核心技能 Lv5、紫装 / 橙装联动和强化装备。
- 第 9-10 关地狱 / 折磨，目标是完整流派、套装承接、Boss 机制熟悉和足够长期天赋点投入。

### 基础数值成长原则

关卡越靠后，怪物应主要通过以下维度变强：

- 最大生命提高。
- 攻击伤害提高。
- 护甲、抗性或异常抗性提高。
- 技能冷却更短，但仍需要清晰前摇。
- 精英和 Boss 获得更复杂的技能组合。
- 主题环境机制更频繁地参与战斗。

推荐以“关卡强度系数”控制基础数值：

| 关卡段 | 目标玩家状态 | 怪物基础数值建议 |
| --- | --- | --- |
| 第 1-2 关 | 新玩家、低装备积累 | 作为教学和基础构筑阶段，生命和攻击较低 |
| 第 3-5 关 | 已有基础装备和 1-2 个稳定流派 | 生命、攻击、抗性明显提高，开始要求技能循环 |
| 第 6-8 关 | 有多件紫装或成型构筑 | 基础生命和攻击大幅提高，精英可带双词缀 |
| 第 9-10 关 | 长线刷装玩家和终局构筑 | 基础数值显著高于前期，Boss 和精英依靠机制压迫 |

设计底线：

- 高关卡怪物必须更硬、更疼、更会配合。
- 不应让高关卡普通怪只因为“跑得很快”而显得强。
- 玩家装备提升后，应感受到自己能打穿更高基础数值的怪，而不是只被高速追逐压死。
- 同战力下，腐蚀史莱姆应在普攻 1-2 下或一次主动技能中成片死亡；主题普通怪需要 3-5 次普攻或主动技能补刀；高威胁怪需要 1-2 个主动技能或持续风筝；构筑未完成时精英怪需要 2-4 轮技能循环；核心装备 + Lv.5 技能搭配正确后，关键技能可以击杀一片低 / 中预算精英，但高预算精英仍需要处理。Boss 以机制考试为核心，不靠单纯堆血拖时间，也不能被构筑直接跳过核心阶段。

### 移速控制原则

靠后的关卡可以有更快的怪物，但怪物常驻移速必须有软上限。后期难度应由基础数值、技能组合、怪潮密度、精英词缀和环境机制共同承担。

推荐怪物速度规则：

```text
怪物常驻移速 = 怪物类型基础速度 x 关卡小倍率 x 层段小倍率 x 词缀倍率
```

当前版本怪物追击压力偏弱，需要在不破坏后期可读性的前提下提高常态移速。实现建议：

| 怪物类别 | 本次提速目标 |
| --- | --- |
| 腐蚀史莱姆 / 低威胁炮灰 | 基础移速提高 12%-16%，让怪潮能形成包围压力 |
| 普通近战主题怪 | 基础移速提高 10%-14%，保证玩家不能无压力拉开距离 |
| 普通远程怪 | 基础移速提高 6%-10%，主要用于重新找射击位置，不追求贴脸 |
| 软泥、重型怪、召唤怪 | 基础移速提高 5%-8%，保持笨重识别度 |
| 狼、蝙蝠、刺客等高速怪 | 基础移速提高 6%-10%，更多速度感交给跳扑、短冲锋和前摇技能 |
| 精英怪 | 在同类基础上提高 8%-12%，疾行词缀仍受软上限约束 |

这次提速是“全局手感修正”，不是后期关卡隐藏加速。程序实现上应该优先提高怪物类型基础速度或一个可测试的全局追击倍率，再经过关卡小倍率、层段小倍率和软上限裁切。

不要使用总层数线性叠加移速。第 10 关第 1 层可以更强，但不应该因为总层数靠后而出现普通怪异常高速贴脸。

常驻移速建议上限：

| 怪物类别 | 常驻移速上限 |
| --- | --- |
| 普通近战 | 82-92 |
| 普通远程 | 60-76 |
| 软泥、召唤、重型怪 | 50-70 |
| 狼、蝙蝠、刺客等高速怪 | 105-122 |
| 精英疾行词缀 | 不超过同类普通上限的 120% |
| Boss | 平时可读，爆发技能可短时间高速 |

冲锋、扑击、闪现可以很快，但必须满足：

- 有明显蓄力前摇。
- 有方向预警。
- 爆发时间短。
- 结束后有可输出窗口。

### 近战普通攻击站位与锁定

当前近战怪贴脸后容易出现“挤进玩家坐标再靠重叠扣血”的观感。后续实现必须把所有怪物的近战普通攻击改成清晰的站位攻击：

- 所有近战普通攻击必须使用下表的绝对战斗逻辑距离，不再使用“当前实现 x 2”这类相对描述。距离单位按战斗世界像素 / 逻辑单位理解，最终渲染缩放不改变判定距离。
- 这包括普通近战怪、精英近战怪和 Boss 的普通近战挥击；冲锋、扑击、旋风斩、Boss 技能等特殊技能不直接套用该表，而按各自预警和范围设计。

| 近战类型 | 攻击站位距离 | 触发距离 | 命中距离 | windup | active | recovery | 说明 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | --- |
| 小型撕咬 / 低威胁近战 | 28-34 | 36 | 40 | 0.28s | 0.10s | 0.28s | 用于老鼠、小型爬行怪、低威胁贴身怪。 |
| 标准人形近战 | 38-46 | 48 | 54 | 0.36s | 0.12s | 0.34s | 用于骷髅战士、腐尸、普通兽人等主力近战。 |
| 长柄 / 大型近战 | 52-62 | 64 | 72 | 0.46s | 0.16s | 0.44s | 用于长矛、巨斧、巨魔、小 Boss 护卫。 |
| 精英近战普通挥击 | 同类 +10%-15% | 同类 +15% | 同类 +15% | 不低于同类 | +0.02s | +0.08s | 精英可以更远，但前摇必须可读。 |
| Boss 普通近战挥击 | 72-84 | 88 | 100 | 0.68s | 0.20s | 0.60s | Boss 普攻是机制间隔压迫，不应瞬发。 |

- 攻击站位距离是怪物追击停止的目标距离；怪物进入触发距离后应停在站位外沿，不能继续把身体中心推进玩家中心。
- 命中距离必须覆盖对应武器 / 爪击视觉表现。若某个素材的挥击视觉明显短于表格命中距离，应优先补挥击特效或调小该怪命中距离，不能出现“空气刀”。
- 近战怪进入普通攻击触发距离后，应停在攻击站位外沿，不再继续追到玩家中心点。
- 所有怪物播放普通攻击动画期间必须锁定移动。进入 attack windup / attack active 后，位置和朝向以攻击开始时为准，不能继续追踪、滑步、碰撞挤压或频繁左右翻转。
- 普通攻击伤害只能在攻击动画命中帧结算。windup 未完成前不能扣血，命中帧最多触发一次普通攻击伤害和一次对应命中特效。
- 如果玩家在 windup 期间走出命中距离，攻击可以落空；怪物应在攻击收招后重新追踪，而不是攻击期间继续贴脸修正位置。
- 程序验收需要覆盖：近战怪不会进入玩家中心；attack windup 中位置/朝向稳定；windup 前玩家不掉血；命中帧只结算一次伤害；远程怪、冲锋怪和特殊技能不被误锁。

后期关卡的压力来源应优先排序为：

1. 怪物基础生命、攻击和抗性。
2. 怪物技能组合和精英词缀。
3. 怪潮密度和刷怪节奏。
4. 环境机制。
5. 少量高速怪或短时间爆发位移。

## 蓝色晶石与经验系统

### 局内经验结算制

每层击杀完成后，不再奖励属性点，也不再要求玩家手动选择属性。蓝晶经验仍然保留，因为它承担“清怪 -> 吸晶 -> 本局构筑推进”的即时爽感，但它不再直接提高玩家基础属性。

新的成长分工：

- 怪物掉落蓝色晶石。
- 玩家拾取晶石获得局内经验。
- 经验条满后角色获得局内等级。
- 局内等级只用于技能选择、技能升级、被动构筑推进或本局奖励权重，不自动提高生命、攻击、攻速、移速、技能伤害、技能冷却等基础属性。
- 玩家基础属性主要来自装备、装备强化、套装、武器词缀和后续天赋系统。
- 玩家通关、死亡或放弃本局并返回首页 / 村庄后，本局等级和本局经验清零。
- 本局累计经验、最高局内等级、通关层数、精英击杀和 Boss 击杀会在结算时换算成天赋点；天赋点属于局外长期资源。

设计目的：

- 保留蓝晶吸附和升级提示的即时反馈。
- 避免玩家靠一局内吃经验包直接滚雪球成数值碾压。
- 让“装备 + 技能构筑 + 后续天赋”成为主要战力来源。
- 让失败局也有少量长期收益，但高层推进和 Boss 击杀收益显著更高。

### 蓝色晶石设计

蓝色晶石是死亡契约记录怪物灵魂残片的形式。

掉落规则建议：

| 怪物类型 | 晶石掉落 |
| --- | --- |
| 炮灰腐蚀史莱姆 | 小晶石 0-1 个，按当前单怪概率判定 |
| 普通小怪 | 小晶石 1 个 |
| 高血普通怪 / 高威胁怪 | 小晶石 1-2 个，低概率中晶石 1 个 |
| 精英怪 | 中晶石 3-5 个 |
| 队长精英 | 中晶石 4-6 个，低概率大晶石 1 个 |
| Boss | Boss 晶核 1 个 + 大晶石 6-10 个 |

蓝晶样式和经验值：

| 类型 | 视觉规格 | 经验值 | 用途 |
| --- | --- | ---: | --- |
| 小蓝晶 | 8x8，浅蓝碎晶，轻微闪光 | 3 | 普通怪和炮灰怪的主要经验反馈。 |
| 中蓝晶 | 12x12，菱形晶体，蓝白核心 | 12 | 精英、路线目标和高威胁怪奖励。 |
| 大蓝晶 | 18x18，多面晶簇，带短拖尾粒子 | 40 | 精英、队长精英和 Boss 前奖励。 |
| Boss 晶核 | 24x24，亮蓝核心 + 紫色边缘 | 120 | Boss 击杀结算感和天赋点基础收益。 |

局内经验曲线：

| 局内等级 | 升到该等级累计经验 | 预期出现阶段 |
| --- | ---: | --- |
| Lv2 | 25 | 第 1-2 层 |
| Lv3 | 60 | 第 3 层前后 |
| Lv4 | 110 | 第 4-5 层 |
| Lv5 | 180 | 第 6 层前后，首次核心质变 |
| Lv6 | 275 | 第 7-8 层 |
| Lv7 | 395 | 第 9 层前后 |
| Lv8 | 545 | 第 12 层前后 |
| Lv9 | 725 | 第 15 层前后 |
| Lv10 | 935 | 第 18 层前后 |
| Lv11 | 1175 | Boss 前高压段 |
| Lv12 | 1445 | 第 21-22 层理想上限 |
| Lv15 | 2435 | 高难 / 路线目标富集后的软上限 |

经验曲线验收：

- 普通难度完整通关通常在 Lv10-Lv12。
- 困难 / 地狱通过怪物数量、精英和路线目标可更稳定到 Lv12-Lv15。
- 如果第 6 层之前稳定到 Lv7 以上，说明蓝晶经验过量。
- 如果第 12 层仍低于 Lv6，说明经验曲线过硬或蓝晶掉落反馈不足。

数量翻倍后的蓝晶规则：

- 单只怪物的蓝晶掉落概率和掉落规格保持当前规则，不因为怪物数量翻倍而降低。
- 不额外添加“数量翻倍补偿倍率”或“高层蓝晶隐藏加成”，避免蓝晶收益被多套倍率放大。
- 预期每层蓝晶总量会随击杀目标翻倍自然增加，这是怪潮爽感和升级反馈的一部分；如果后续升级过快，应优先调整升级经验曲线，而不是暗改单怪蓝晶掉率。
- 路线目标、蓝晶富集裂点等额外奖励仍受各自奖励上限约束，不能和数量翻倍叠成无限经验。

拾取体验：

- 晶石颜色必须高亮蓝色。
- 晶石有轻微闪烁和上下浮动。
- 玩家靠近后自动吸附。
- 大量掉落时应形成清晰的蓝色轨迹。
- 晶石被吸收时要有清脆音效和小型蓝色粒子。

### 治疗药水 / 血包掉率调整

怪物数量翻倍后，补给如果维持原掉率会让玩家在怪潮中获得过多容错，削弱“打不过 -> 勉强打过 -> 成型后爽”的阶梯。因此治疗药水 / 血包掉率需要直接砍半。

实现口径：

- 治疗药水 / 血包使用独立补给掉落表，不和装备、蓝晶掉率共用倍率。
- 最终掉率 = 当前所有补给掉率计算结果 x 0.5。也就是说，低血加成、精英加成或关卡加成都先按现有逻辑算完，再整体乘以 50%。
- 怪物数量翻倍不会让治疗药水掉率回补，也不会添加额外补给保底。
- Boss 前置层和节点奖励可以继续提供回血选项，但这属于层间奖励，不受怪物掉落药水砍半影响。
- 浏览器验收时应观察第 1 / 5 / 10 关：血包仍能救急，但不能让玩家靠频繁拾取无成本站撸。

### 局内升级反馈

局内升级需要有明显反馈，但不能显示“全属性强化”或实际修改基础属性。

每次局内升级的表现：

- 角色脚下出现蓝色契约符文。
- 经验条归零并进入下一等级。
- 若当前层允许奖励选择，则进入技能选择 / 技能升级 / 被动构筑推进。
- 若当前层是轻结算层，则只显示简短提示，例如“局内等级提升：技能构筑推进”。
- 不弹出基础属性分配界面，不显示生命、攻击、攻速、移速等属性上涨。

允许被局内等级影响的内容：

| 内容 | 是否允许 | 说明 |
| --- | --- | --- |
| 技能选择候选 | 允许 | 等级提升可以提供新的主动技能或升级已有技能 |
| 技能等级 | 允许 | 服务本局构筑成型 |
| 被动技能 / 职业被动等级 | 允许 | 仍属于本局构筑，不是永久属性 |
| 基础属性自动增加 | 不允许 | 生命、攻击、攻速、移速、冷却等不随经验自动提升 |
| 装备属性 | 不由经验直接改变 | 装备仍通过掉落、强化、词缀和套装提供属性 |
| 天赋点 | 结算后允许 | 本局经验和等级在结算页换算为局外天赋点 |

### 天赋点结算规则

天赋系统的第一版局内 / 局外节点池已在下文固定；节点 ID、前置关系、解锁消耗、候选与重掷口径已由后文“完整天赋系统第一版已确认补充内容”及对应“已确认实现口径”固定。底层结算规则仍只负责产出局外天赋点，避免经验系统继续和属性成长耦合。

天赋点来源：

- 本局累计蓝晶经验。
- 本局最高局内等级。
- 本局到达层数。
- 精英击杀数量。
- Boss 击杀和本关通关。
- 首次通关奖励。

换算原则：

- 通关层数权重最高，避免玩家只刷低层炮灰。
- 精英和 Boss 提供明显加权，鼓励挑战节点。
- 蓝晶经验提供基础收益，但不能线性无上限兑换。
- 每局天赋点有软上限；超过软上限后收益递减。
- 死亡局也给少量天赋点，避免失败完全无收益。
- 放弃本局可以结算已获得收益，但系数低于死亡 / 通关，避免玩家频繁进退刷点。

第一版公式口径：

```text
原始天赋点 =
floor(本局累计蓝晶经验 / 160)
+ floor(最高局内等级 x 0.8)
+ floor(到达层数 / 3)
+ 精英击杀数 x 1
+ Boss 击杀数 x 4
+ 首通奖励

最终天赋点 = floor(原始天赋点 x 难度倍率 x 结算状态倍率)
```

难度倍率：

| 难度 | 倍率 | 单局软上限 | 说明 |
| --- | ---: | ---: | --- |
| 普通 | 1.00 | 32 | 熟悉关卡和基础刷装。 |
| 困难 | 1.25 | 46 | 需要明确流派和强化装备。 |
| 地狱 | 1.55 | 64 | 高压刷装和核心构筑验证。 |
| 折磨 | 1.90 | 86 | 终局长期追求。 |

结算状态倍率：

| 状态 | 倍率 | 说明 |
| --- | ---: | --- |
| 通关 / Boss 击杀后返回 | 1.00 | 标准结算。 |
| 死亡结算 | 0.75 | 保留失败收益，但低于通关。 |
| 主动放弃 | 0.45 | 防止频繁进退刷点。 |

首通奖励：

| 难度 | 首通奖励 |
| --- | ---: |
| 普通 | 6 |
| 困难 | 10 |
| 地狱 | 16 |
| 折磨 | 24 |

其中 `累计经验` 只作为基础分；`到达层数`、`精英击杀`、`Boss 击杀` 和 `首通奖励` 才决定收益上限和挑战价值。超过单局软上限后收益进入递减：超出部分按 35% 计入，避免高难长局一次性给出过多长期点数。

### 第一版契约流派设计

四个契约流派不是传统职业切换，而是局内构筑的方向锚点。玩家开局或局内早期选择流派后，系统应提高对应技能、被动、装备词缀和套装件的出现权重，让玩家能感知“这一局正在朝某个 Build 成型”。局内天赋优先改变技能行为，其次才提供小幅数值。

统一边界：

- 局内等级 5 是第一轮核心联动点，玩家应开始看到流派循环成型，而不是只获得数值上涨。
- 构筑未成型时，技能可以清掉一片炮灰，但精英仍需要处理。
- 核心技能 Lv5 + 正确装备 / 套装搭配后，关键技能可以轰掉一片炮灰和一片低 / 中预算精英。
- Boss 不允许被流派循环直接跳过。Boss 只接受标记增伤、破盾、易伤、减速、持续压迫等机制，不吃秒杀和无限控制。

#### 死契处刑

定位：标记、穿透、斩杀、魂爆，偏精准连锁。

局内天赋核心：

- 箭矢命中后施加 `死契标记`。
- 标记敌人低血量时进入 `处刑线`。
- 穿透类技能命中标记敌人时，额外触发魂火伤害。
- 击杀标记敌人后产生小范围 `魂爆`，并尝试给附近敌人扩散标记。
- 精英怪不吃秒杀，但可以被处刑伤害打出破防、硬直或短暂易伤。
- Boss 不吃处刑秒杀，只吃标记增伤、破盾和短暂虚弱。

局内等级 5 联动：

- 解锁第一轮“标记 -> 击杀 -> 魂爆 -> 再标记”的循环。
- 若穿透类技能已经达到 Lv5，穿过第一个标记敌人后强化下一段穿透伤害。
- 5 级后可出现处刑核心天赋，例如“标记敌人死亡时，附近敌人短暂易伤”。
- 体验目标是开始能一箭清掉一小片炮灰，但精英仍需要补伤害或等待处刑窗口。

装备 / 套装承接：

- 武器词缀：处刑线阈值提高、标记扩散范围提高、穿透后魂火伤害提高。
- 戒指 / 项链：提高标记持续时间、魂爆半径、对精英破防效率。
- `死契处刑者` 套装：
  - 2 件：命中有概率附加死契标记。
  - 4 件：击杀标记敌人触发魂爆。
  - 6 件：魂爆命中精英时叠加破防；命中 Boss 时转化为短暂易伤，不触发秒杀。

#### 血羽游侠

定位：攻速、散射、暴击、流血，偏高速铺场。

局内天赋核心：

- 普攻和散射技能叠加 `血羽` 或 `流血`。
- 暴击额外生成血羽碎片。
- 血羽碎片自动追踪附近敌人，造成小额追加伤害。
- 流血层数达到阈值后触发 `血裂`，对周围炮灰造成扩散伤害。
- 适合攻速、散射、暴击和流血装备。

局内等级 5 联动：

- 解锁第一轮“血羽连射”核心节点。
- 散射箭命中多个敌人时，每个暴击目标都有机会释放血羽。
- 若散射技能达到 Lv5，散射从“扇形打击”升级为“扇形铺场 + 血羽追击”。
- 成型前主要清炮灰；成型后可以靠流血爆发打残低 / 中预算精英群，但 Boss 仍需要走位叠层。

装备 / 套装承接：

- 武器词缀：散射角度提高、额外血羽数量、暴击生成血羽概率。
- 手套 / 戒指：提高攻速、暴击率、流血层数上限。
- `血羽游侠` 套装：
  - 2 件：暴击生成血羽。
  - 4 件：流血敌人死亡时释放血羽碎片。
  - 6 件：散射箭命中 5 个以上目标时触发一次血羽风暴，有内置冷却。

#### 兽王赦令

定位：召唤、指令、协同、光环，偏伙伴体系。

局内天赋核心：

- Q / E / R 分别绑定三只主力野兽，例如猎犬、鹰、巨熊。
- 野兽半常驻跟随玩家，倒地后进入复苏倒计时。
- 玩家可以手动下令：突袭、牵制、守护、集火。
- 不同野兽组合触发协同，例如猎犬咬住目标后，鹰俯冲造成额外暴击。
- 核心体验不是一次性爆发，而是持续压制、战场控制和伙伴保护。

局内等级 5 联动：

- 解锁第一轮“首领化”方向。
- 当前主力野兽获得光环，例如猎犬提高玩家移速，鹰提高暴击，巨熊提供减伤。
- 若 Q / E / R 对应野兽技能达到 Lv5，该野兽获得专属首领动作。
- 体验目标是让玩家感到“我有一套兽群战术”，而不是只多一个召唤物。

装备 / 套装承接：

- 武器词缀：野兽指令冷却降低、野兽攻击继承玩家伤害提高。
- 护甲 / 项链：提高野兽生命、复苏速度、光环范围。
- `兽王赦令` 套装：
  - 2 件：野兽复苏时间缩短。
  - 4 件：玩家释放技能后，最近野兽执行一次协同攻击。
  - 6 件：一只野兽首领化时，其他野兽获得弱化光环；兽群集火精英时造成短暂压制。

#### 蓝晶契约

定位：经验、冷却、能量、区域，偏技能循环。

局内天赋核心：

- 拾取蓝晶仍只推进局内经验、局内等级和技能构筑，不直接提高基础属性。
- 蓝晶契约让蓝晶产生额外战斗效果，例如吸收时释放小型能量波。
- 技能命中敌人后积累 `蓝晶充能`。
- 充能满后强化下一次 Q / E / R。
- 擅长区域技能、冷却缩短、能量爆发和控场。

局内等级 5 联动：

- 解锁第一轮 `蓝晶过载`。
- 拾取蓝晶会短暂降低技能冷却，或让下一次技能扩大范围。
- 若区域控制技能达到 Lv5，会从普通范围伤害变成“持续领域 + 蓝晶脉冲”。
- 该流派前期不一定最强，中期技能循环成型后清场节奏明显变快。

装备 / 套装承接：

- 武器词缀：蓝晶充能效率提高、过载技能范围提高、技能命中返还冷却。
- 项链 / 戒指：提高拾取范围、蓝晶吸收速度、技能冷却恢复。
- `蓝晶契约` 套装：
  - 2 件：拾取蓝晶获得短暂技能冷却加速。
  - 4 件：蓝晶过载时，下一次技能附带额外脉冲。
  - 6 件：连续释放 3 次技能后生成蓝晶领域；炮灰会被快速清理，精英受到减速和持续伤害，Boss 只受到削弱和持续压迫。

### 第一版局内天赋池

第一版局内天赋池共 40 个节点。每局不展示全部节点，而是根据玩家选择的契约流派、已拥有技能、装备标签和当前层数，从池子里生成一张小型局内天赋图，建议每局展示 12-15 个可达节点。局内天赋只服务本局构筑，返回首页 / 村庄后清空；它不提供永久属性。

#### 局内天赋抽取与保底规则

局内升级奖励只展示构筑相关选择：主动技能、已有技能升级、被动 / 局内天赋节点。不得展示基础攻击、生命、攻速、移速等直接属性加点。

每次局内等级提升弹出 3 个候选，玩家选择 1 个。若局外天赋或高难奖励提供额外候选，单次最多 4 个候选。候选生成顺序如下：

1. 先根据玩家开局选择的契约流派建立本局主池：8 个通用节点 + 8 个主流派节点 + 3-5 个已拥有技能 / 装备标签关联节点 + 1-2 个弱关联跨流派节点。
2. 再根据当前局内等级开放节点层级。Lv2-Lv4 只开放通用、基础流派和技能入门节点；Lv5 开始开放对应流派的 Lv5 质变节点；Lv8 以后开放进阶循环节点。
3. 最后按权重抽取候选，并执行保底和互斥规则。

候选权重基准：

| 条件 | 权重修正 |
| --- | ---: |
| 属于开局选择流派 | +35 |
| 直接影响已装备技能 / 已召唤野兽 / 已拥有区域技能 | +30 |
| 与当前穿戴装备核心词缀同标签 | +25 |
| 与当前关卡主题掉落方向同标签 | +10 |
| 属于弱关联跨流派节点 | -25 |
| 与当前构筑冲突，例如无野兽时抽高级野兽节点 | 暂不进入候选 |

权重叠加必须遵守已有护栏：同类候选权重总增益不超过 +45%，装备候选权重总增益不超过 +45%，传承候选权重总增益不超过 +30%。

保底规则：

- Lv2 第一次升级至少出现 1 个主动技能或已有主动技能升级，避免玩家早期只拿到被动。
- Lv3-Lv4 至少累计出现 2 次开局流派相关候选。
- 若连续 2 次升级没有出现开局流派候选，下一次升级必定出现 1 个开局流派候选。
- 若某个主动技能达到 Lv4，之后 2 次升级内必须出现 1 次该技能 Lv5 质变候选；如果玩家未选择，该候选回到正常权重池，不再连续强制。
- Lv5 当次升级至少出现 1 个“开局流派 Lv5 联动”或“已拥有技能 Lv5 质变”候选；若条件不足，则出现 1 个流派桥接节点，帮助玩家继续成型。
- 每次候选最多出现 1 个弱关联跨流派节点，防止构筑被随机奖励带偏。
- 同一局已选择节点不再重复出现；同类唯一节点只能被升级或强化，不能以不同名称重复叠加。
- 死亡、通关、放弃回村后，局内天赋和候选保底计数全部清空，只保留结算获得的局外天赋点。

重掷规则：

- 每局基础重掷 1 次，只作用于局内升级奖励。
- 重掷后不得原样返回完全相同的 3 个候选。
- 重掷不清除 Lv5 质变保底；若当前奖励被保底锁定，重掷后仍必须保留至少 1 个同类核心候选。
- 封存 / 屏蔽只影响奖励类型或具体节点进入候选池，不得屏蔽全部主流派候选。

验收标准：

- 玩家未成型前，每局至少能稳定拿到 1 条主流派路径，但不会保证所有关键节点全拿齐。
- 到 Lv5 时，玩家一定能看到至少 1 个和当前技能 / 流派相关的质变方向。
- 构筑成型需要技能等级、局内天赋、装备词缀和套装共同配合，不能只靠局内天赋直接获得完整爆发循环。

#### 局内天赋已确认实现口径

局内天赋节点 ID 使用模块前缀 + 两位顺序号，顺序严格等于下文表格顺序。显示名称必须来自表格中文名，不能从 ID 反推。

- 重掷后至少替换 1 个候选；若合法池不足导致无法变化，返回 `rerollBlockedReason`，不消耗重掷次数。

局外前置规则：

- `meta_common_01` 默认可解锁且消耗为 0，用于开启局外天赋系统和天赋点记录。
- 基础通用树按表格顺序线性解锁，后一节点要求前一节点已解锁。
- 四流派基础树各自线性解锁；每支第 1 个节点要求 `meta_common_01` 已解锁。
- 四难度精通树按难度分组线性解锁。普通分组要求 `meta_common_01`；困难、地狱、折磨分组分别要求任意关卡已解锁对应难度。
- 十关契约精通要求对应关卡普通难度已通关，并要求 `meta_common_01` 已解锁。
- 四流派进阶树各自线性解锁；每支第 1 个进阶节点要求对应流派基础树第 6 个节点已解锁。
- 终局通用树线性解锁；`meta_endgame_01` 和 `meta_endgame_02` 要求任意关卡已解锁地狱难度，`meta_endgame_03` 至 `meta_endgame_06` 要求任意关卡已解锁折磨难度。

### 第一版天赋数值与联动草案

以下数值是第一版设计基准，供程序实现和后续平衡测试使用。所有数值都必须经过战斗实测，不能只按表格实现后直接视为完成。若局内天赋、装备词缀、套装和技能 Lv5 同时影响同一机制，必须优先遵守上限护栏。

| 项 | 规则 |
| --- | --- |
| 局内天赋 | 本局生效，回村清空。 |

##### material-drop 战斗材料奖励

`material-drop` 只作用于战斗内“材料奖励”入口，目标包括：

- `nightmare-elite`：噩梦 / 折磨难度精英击杀产生的材料奖励。
- `campaign-7`：campaignId 为 7 的战斗内材料奖励。

- 总加成上限 `+25%`，最终倍率不超过 `1.25`。
- 不影响装备掉率、蓝晶掉率、金币、血包、Boss 传承 / 传奇概率。

验收口径：

- 单测至少覆盖 hard elite、nightmare elite、campaign 7、生效 cap、不影响自动分解。
- 浏览器 / E2E 至少能读到 target、base、multiplier、final、cap。

##### cooldownRefundMultiplier 冷却返还

冷却返还只作用于玩家主动技能槽 `Q/E/R` 的当前冷却，不作用于普攻、怪物技能、Boss 技能、召唤物自主攻击或装备被动。

触发规则：

- 每次玩家主动施法生成一个 `castId`。
- 同一个 `castId` 不论多弹体、持续区域、DOT、召唤派生命中多少次，最多触发 1 次冷却返还。
- 冷却返还只在该次施法造成有效命中时触发。
- 总返还上限 `25%`，返还量按该技能基础冷却与当前剩余冷却中较小值裁切，不得把冷却降为负数。
- 每个技能槽每 0.35 秒最多接受 1 次返还，防止同帧连锁。

验收口径：

- 单测覆盖单次命中、多弹体一次、DOT 一次、召唤派生不重复、cap 25%、不影响普攻 / Boss。
- 浏览器 / E2E 至少能读到技能槽、castId、baseCooldown、remainingBefore、refund、remainingAfter。

- 测试覆盖余额不足、成功扣费、点数返还、前置重新锁定、存档恢复、ledger 记录。

- 史诗、传承、传奇武器进入长期仓库，作为长期刷装目标。

### 装备位开放节奏

12 个装备位会提供很强的长期刷装空间，但不建议一开始全部开放。推荐按照关卡逐步开放，让玩家每推进几关就获得新的刷装目标。

| 开放阶段 | 装备位 | 设计目的 |
| --- | --- | --- |
| 第 1 关 | 武器、胸甲、鞋子、戒指 1 | 让玩家先理解伤害、生存、移动和一个特殊词缀位 |
| 第 2-3 关 | 头盔、手部、项链 | 引入经验、暴击、核心构筑强化 |
| 第 4-6 关 | 护肩、手腕、披风 | 引入技能范围、冷却、闪避与防御流派 |
| 第 7 关后 | 腿部、戒指 2 | 开放完整装备构筑和刷装终局 |

开放规则建议：

- 未开放装备位可以在设定上显示为“契约封印”，但本文不定义 UI。
- 未开放装备位不进入掉落池，避免玩家获得不能使用的装备。
- 新装备位开放时，该关精英和 Boss 提高对应部位掉率，帮助玩家快速感受到新系统。

### 掉率建议

装备掉落必须按副本难度分层。普通难度给基础反馈；困难和地狱提高刷装效率；折磨明显提高装备掉落率，但传奇仍然极稀有。设计目标是：玩家在折磨难度完整刷 Boss 十几到二十次后，才比较可能见到一件传奇装备。

掉落判定口径：

- 以下装备掉率均按“单只怪物 / 单个掉落判定”计算。怪物数量翻倍只增加可击杀目标数量，不暗改单怪装备率、蓝晶率或补给倍率。
- 蓝晶与装备分开判定。蓝晶掉落按怪物数据卡的蓝晶字段执行；装备先判定是否掉装，再进入互斥稀有度池。
- 普通怪、精英怪和 Boss 的装备掉落表按“互斥掉落池”理解，不能把破碎、普通、优质、精良、史诗、传承和传奇分别独立判定后同时掉出多件。
- 难度可以提高“是否掉装”的单怪概率，也可以通过高价值掉落权重提高史诗、传承和传奇在已掉装装备中的占比；不能让数量翻倍再额外乘一次隐藏掉率。
- 紫色以下装备离开战斗自动分解；史诗、传承、传奇进入长期仓库，默认需要保护和锁定提示。
- Boss 橙色必掉 1 件，但这件属于“本关传承装备”，词缀主题固定服务当前关卡和当前 Boss。
- 每个 Boss 都有专属传承武器掉落权重。Boss 保底传承不必每次都是武器，但武器必须在本关传承池中，并受到定向掉落、首通、复刷和已发现装备权重规则影响。

已发现传承 / 传奇装备的追刷权重：

- 当某件传承或传奇装备首次掉落时，系统记录该装备的 `equipmentId`。
- 后续只要进入该装备所属的传承或传奇候选池，该装备本身的候选权重乘以 2。
- 该规则只作用于“已进入传承 / 传奇候选池后，具体是哪一件装备”的权重，不提高全局传承率、全局传奇率，也不提高同关所有 Boss 装或同类型所有武器。
- 同一件装备只记录已发现 / 未发现两种状态；掉落一次后固定 `x2`，不会因重复掉落叠到 `x4` 或更高。
- 例：掉过「黑月兽骨弓」后，只提高「黑月兽骨弓」后续在对应 Boss 传承池内的候选权重，不提高所有弓、所有传承武器或所有狼人黑森林 Boss 装。

### 装备库存与过期装备处理

装备掉落必须形成资源循环，否则中后期会出现大量过期装备占仓库、玩家不愿拾取的问题。

设计目标：

- 战斗中只负责拾取和临时自动装备，不打断战斗节奏。
- 灰色、白色、绿色、蓝色地下城装备可以在本次战斗内临时提供强度，但离开战斗后自动分解。
- 只有史诗、传承、传奇装备进入长期仓库，避免玩家被低品质装备管理拖慢。
- 紫色以上装备即使分数低，也可能因为词缀有构筑价值，需要保护机制。
- 回收资源要能反哺当前构筑，而不是只变成无意义金币。

装备处理流程：

1. 战斗中拾取装备。
2. 紫色以下装备可以在本次战斗内临时装备、临时替换或作为战利品记录。
3. 史诗及以上装备进入关键战利品队列，允许立即装备、锁定或稍后处理。
4. 离开战斗时，所有紫色以下地下城装备自动分解为锻造材料。
5. 离开战斗后，只有史诗、传承、传奇装备保留到长期仓库。
6. 自动分解材料用于强化、副属性重铸、Boss 传承重铸和流派定向。

离开战斗的触发场景：

- 通关第 22 层 Boss 并返回首页。
- 玩家死亡后进入结算。
- 玩家主动放弃当前关卡并返回首页。
- 未来如果加入中途撤离，也视为离开战斗。

保留例外：

- 系统赠送的新手武器属于剧情起始装备，不参与自动分解，除非玩家主动替换并选择分解。
- 剧情或系统赠送的永久装备不参与自动分解，除非明确标记为地下城临时装备。
- 当前正在穿戴的紫色以下地下城装备，离开战斗时仍然自动分解，避免低品质装备长期占位。

装备保护规则：

| 情况 | 默认处理 |
| --- | --- |
| 灰色、白色、绿色地下城装备 | 战斗内临时使用，离开战斗自动分解 |
| 蓝色地下城装备 | 战斗内临时使用，可作为本局过渡，离开战斗自动分解 |
| 蓝色但带经验、掉落、拾取范围属性 | 战斗内高亮提示，但离开战斗仍自动分解 |
| 紫色及以上 | 默认锁定，不参与一键分解 |
| 橙色 / 亮橙色 | 必须二次确认才能分解 |
| 带当前 Q / E / R 技能词缀 | 自动标记为构筑相关 |

| 消耗入口 | 作用 | 设计限制 |

| 词缀保留 | 当前阶段不开放 | 完整天赋系统阶段再执行 |

一键分解规则：

- 面板的一键分解主要服务史诗及以上装备管理，不再让玩家手动清理大量低品质装备。
- 灰色、白色、绿色、蓝色地下城装备在离开战斗时自动分解，不需要进入长期仓库。
- 一键分解永远跳过锁定装备、当前装备、橙色 / 亮橙色装备。
- 分解前显示预计获得材料。
- 最近 1 关获得的史诗及以上装备保留“新”标记，避免玩家误分解还没看过的装备。
- 离开战斗结算页必须显示紫色以下装备的自动分解数量和材料收益。

推荐资源循环：

```text
刷怪 / 精英 / Boss
-> 获得装备
-> 紫色以下装备作为本局临时强度或材料来源
-> 史诗以上装备立即替换、锁定或带回仓库
-> 离开战斗自动分解紫色以下装备
-> 材料强化当前装备、重铸词缀或提高定向掉落权重
-> 形成更明确构筑
-> 继续挑战更高层和更高关卡
```

仓库文案精简：

- 仓库弹窗标题用“仓库”，不再使用“物品仓库”等长标题。
- 左侧角色装备区标题用“装备”，右侧列表标题用“背包”。

- 铁匠铺已不卖武器，仓库也不再出现“前往铁匠铺购买武器”之类旧文案。
- 背包装备卡默认只显示装备名、评分、核心词缀和操作按钮；完整副属性、材料明细和红绿对比放入选中详情。

## 装备与技能联动

装备必须让玩家愿意刷怪，而不是只追求数值。

### 核心大词缀收敛规则

装备词缀分为两层：普通数值词缀负责补强，核心大词缀负责改变技能形态。紫色以上装备必须优先提供可感知的核心大词缀，但每个流派的大词缀数量要收敛，避免玩家看到大量小幅、重复、难判断的词条。

设计数量建议：

- 每个主流派保留 2 个紫色核心词缀、2 个橙色核心词缀、1-2 个亮橙传奇词缀。
- 紫色词缀让技能“明显更好用”，橙色词缀让技能“改变打法”，亮橙词缀允许改变流派循环，但必须有冷却、触发条件或资源约束。
- 同一技能同时受多件装备影响时，优先叠加形态差异，其次数值提升；不能让多个小词缀无限堆同一种弹道数量、范围或召唤数量。

四大契约流派大词缀方向：

| 流派 | 紫色核心词缀方向 | 橙色核心词缀方向 | 亮橙传奇方向 |
| --- | --- | --- | --- |
| 死契处刑 | 穿透箭矢 +1、穿透后小爆裂、死契标记 | 双线处刑、精英贯穿、标记魂爆 | 贯日审判：每数次手动释放形成终局贯穿线 |
| 血羽游侠 | 扇形更密、中心箭强化、流血叠层 | 箭幕墙、散射命中叠压制、血羽追击 | 星雨裁决：短时间多波箭幕，但范围和冷却受限 |
| 兽王赦令 | 下令强化、护主拦截、野兽临时护盾 | 首领化、双兽协同、倒地复苏缩短 | 兽王号令：短时间兽群爆发，但有复苏/冷却窗口 |
| 蓝晶契约 | 区域半径 / 持续小幅提升、吸晶回响 | 区域重叠反应、蓝晶过载、牵引 / 冻结 / 灼烧连锁 | 天穹晶域：多个区域共鸣，但同屏数量有上限 |

数值护栏：

- 紫色单件核心词缀的等效输出提升控制在 +8%-15%，或提供等价生存/控制价值。
- 橙色核心词缀的等效输出提升控制在 +18%-30%，但需要条件，例如命中精英、手动释放、区域重叠或野兽存活。
- 亮橙传奇可以改变循环，但不能常驻无条件碾压；必须有触发次数、冷却、持续时间、召唤上限或危险代价。
- 弹道增加：紫色通常 +1；橙色可 +1 且附带条件效果；亮橙可在限定窗口 +2 或每 N 次释放翻倍，不能无上限叠加。
- 区域范围提升控制在 +8%-18%，持续时间提升控制在 +10%-22%，不允许单个普通装备让区域覆盖整屏。
- 野兽临时数量上限一般为 2-3 只，临时召唤持续 4-8 秒；复苏和冷却缩短总上限为 25%。
- 套装、装备和技能 Lv5 同时生效时，需要按“成型爽感但不崩坏”校验：中后期可以一轮技能清掉一片炮灰；核心装备 + 核心技能正确搭配后，可以在合适窗口清掉一片低 / 中预算精英；但不能无操作清空全部高威胁怪、高预算精英或跳过 Boss 机制。

紫色以上装备的优先级：

1. 改变技能形态。
2. 增加新的触发条件。
3. 强化流派打法。
4. 最后才是单纯提高伤害数值。

设计原则：

- 蓝色及以下装备主要提供数值和基础副属性。
- 紫色装备开始给技能增加“小形态变化”。
- 橙色装备应能让玩家围绕它调整技能槽。
- 亮橙色装备可以改变构筑规则，但不能成为通关必需品。

技能形态变化示例：

| 流派 | 装备效果方向 |
| --- | --- |
| 死契处刑 | 单线变双线、穿透后爆裂、命中精英后追加平行箭、标记魂爆 |
| 血羽游侠 | 扇面扩大、箭矢回旋、每数次释放变成双倍箭幕、暴击生成血羽 |
| 兽王赦令 | 额外野兽协助、野兽死亡触发护盾或爆发、野兽技能附带嘲讽 |
| 蓝晶契约 | 区域扩大、区域结束爆发、蓝晶过载、区域中心高伤害 |

### 四大契约流派联动

当前弓箭手核心构筑按四大契约流派收敛：

- 死契处刑：穿透、标记、处刑线、魂爆。
- 血羽游侠：散射、攻速、暴击、流血、血羽追击。
- 兽王赦令：半常驻野兽、手动下令、倒地复苏、首领光环。
- 蓝晶契约：蓝晶充能、冷却返还、区域控制、过载脉冲。

区域、减速、灼烧、陷阱仍可以作为技能 / 装备副标签，但它们在主流派归属上优先服务 `蓝晶契约`，不能再作为第五个独立主流派。

## 装备套装方向

套装不是单纯展示文字，而是把局内流派推到成型爽点的关键承接层。套装效果必须能和技能 Lv5、局内契约天赋、武器大词缀互相验证，但仍要遵守 Boss 不可跳过、弹道 / 区域 / 召唤数量有上限的护栏。

### 死契处刑者

定位：标记、穿透、斩杀、魂爆。

| 件数 | 效果 | 数值 |
| --- | --- | --- |
| 2 件 | 死契标记 | 穿透 / 直线技能命中时 35% 概率附加死契标记，持续 5s；Boss 持续 2s。 |
| 4 件 | 魂爆 | 标记敌人死亡时触发魂爆，半径 56，造成 45% 技能伤害；0.25s 内置冷却；魂爆命中普通怪有 20% 概率扩散 1 个标记。 |
| 6 件 | 处刑破契 | 普通怪低于 18% 生命进入处刑线；低 / 中预算精英低于 8% 生命进入处刑线；魂爆命中精英叠加 -8% 防御，最多 3 层，持续 4s；命中 Boss 时转化为 4% 易伤，持续 3s。 |

- 装备词缀重点：处刑线阈值、标记持续时间、穿透后魂火伤害、魂爆半径。
- 验收目标：成型后可以用穿透技能连锁清掉一片炮灰和低 / 中预算精英，但不能跳过 Boss 阶段。

### 血羽游侠

定位：攻速、散射、暴击、流血。

| 件数 | 效果 | 数值 |
| --- | --- | --- |
| 2 件 | 血羽入门 | 暴击率 +6%；散射技能命中附加流血，每秒造成 8% 攻击伤害，持续 4s，最多 5 层。 |
| 4 件 | 血羽追击 | 暴击或流血敌人死亡时释放 1 枚血羽，造成 65% 攻击伤害，追踪半径 180；每秒最多生成 8 枚。 |
| 6 件 | 血羽风暴 | 散射 / 暴击累计 24 次有效命中后触发血羽风暴，持续 4s，每 0.35s 发射 3 枚血羽；内置冷却 14s。 |

- 装备词缀重点：散射角度、额外血羽数量、暴击生成血羽概率、流血层数上限。
- 验收目标：成型后扇形技能可以铺场并追击残血精英，但 Boss 仍需要玩家持续走位叠层。

### 兽王赦令

定位：半常驻伙伴、手动下令、兽群协同。

| 件数 | 效果 | 数值 |
| --- | --- | --- |
| 2 件 | 兽魂复苏 | 野兽最大生命 +18%；野兽复苏时间 -20%；野兽指令冷却 -8%。 |
| 4 件 | 协同攻击 | 玩家手动释放 Q / E / R 后，最近一只存活野兽执行协同攻击，造成 85% 技能伤害；每只野兽 1s 内置冷却。 |
| 6 件 | 首领赦令 | 首领野兽光环半径 160；其他野兽获得 50% 强度的弱化光环；三只主力野兽存活并集火精英 2s 后造成压制 3s，内置冷却 8s；Boss 只受到 35% 压制效果。 |

- 装备词缀重点：野兽指令冷却、野兽继承玩家伤害、野兽生命、复苏速度、光环范围。
- 验收目标：玩家能感知 Q / E / R 三只主力野兽各有职责，首领化后形成战术循环，但不能生成永久无限兽群。

### 蓝晶契约

定位：蓝晶充能、冷却、能量爆发、区域控制。

| 件数 | 效果 | 数值 |
| --- | --- | --- |
| 2 件 | 吸晶加速 | 拾取任意蓝晶后技能冷却恢复速度 +15%，持续 2s；连续拾取只刷新持续时间，不无限叠加。 |
| 4 件 | 过载脉冲 | 蓝晶充能达到 80 后强化下一次 Q / E / R：范围 +18%，并附带 1 次蓝晶脉冲，造成 55% 技能伤害；Boss 伤害折算为 35%。 |
| 6 件 | 蓝晶领域 | 6s 内连续释放 3 次 Q / E / R 后生成蓝晶领域，半径 150，持续 5s，冷却 12s；普通怪每秒受到 35% 技能伤害，精英减速 18%，Boss 减速 6%。 |

- 装备词缀重点：蓝晶充能效率、过载技能范围、技能命中返还冷却、拾取范围和吸收速度。
- 验收目标：中期以后技能循环明显加速，但蓝晶经验不直接提高基础属性，不能变成纯刷经验数值碾压。

套装共同护栏：

- Boss 不吃处刑秒杀、永久压制、无限减速或无限冷却返还。
- 套装效果和技能 Lv5、装备大词缀叠加时，仍要遵守弹道、区域、冷却、召唤和 Boss 易伤上限。
- 套装成型后可以让关键技能轰掉一片炮灰和一片低 / 中预算精英，但高预算精英和 Boss 仍保留机制压力。

## 怪物技能与移动设计标准

怪物必须通过移动方式区分，而不是只靠血量。

### 怪物独立数据卡标准

所有普通怪、高威胁怪、精英、队长精英、Boss 护卫和召唤物都必须有独立数据卡。数据卡是程序实现、资产管理和战斗验收的共同口径，不能只写怪物名称和技能概念。

必填字段：

| 字段 | 内容 |

### Boss 实战表标准

每个 Boss 必须有一张实战表。Boss 的职责是机制考试，不是单纯堆血，也不能被成型构筑直接跳过阶段。

必填字段：

| 字段 | 内容 |
| --- | --- |
| 基础 | HP 基准、攻击基准、移速、碰撞半径、Boss 类型。 |

## 最高素材质量标准

本次重构要求所有技能、装备、技能特效、装备特效、怪物模型、怪物技能、怪物移动立绘素材的清晰度与密度提高到最高档。

最高密度不等于堆满细节。战斗中怪物数量会在中后段达到 2 倍以上，因此所有高密度素材必须先满足可读性，再追求装饰密度。

### 总标准

- 不使用纯矩形、纯色块、低密度占位作为最终资产。
- 所有角色和怪物必须有清晰轮廓、明暗层次和可识别武器/肢体。
- 怪物立绘必须能从轮廓判断其行为。
- 技能特效必须高亮但不能遮挡玩家和危险预警。
- 装备图标必须能从 24x24 或 32x32 尺寸看出装备类型。
- 橙色和亮橙色装备必须有独立视觉特效。
- 每类怪物必须固定一个主色、一个轮廓特征、一个攻击预警色和一个死亡特效色。
- 同屏大量怪物出现时，普通怪、精英、Boss、玩家技能、敌方预警不能互相混淆。

每个装备位都要有独立图标模板：

- 武器：弓形、弦光、箭袋或特殊符文。
- 头盔：帽檐、角、面罩或羽饰。
- 胸甲：胸部纹章、护甲材质。
- 护肩：左右肩轮廓必须明显。
- 手腕/手部：护腕、手套、指节。
- 腿部/鞋子：金属、皮革或布甲差异。
- 戒指：宝石颜色和戒托形状。
- 披风：布料边缘、破损、纹章。
- 项链：吊坠形状和稀有度光效。

稀有度视觉：

| 稀有度 | 视觉标准 |
| --- | --- |
| 灰色 | 暗淡、裂纹、缺口 |
| 白色 | 干净但无特效 |
| 绿色 | 轻微绿色边缘光 |
| 蓝色 | 蓝色宝石或魔法线 |
| 紫色 | 紫色符文、轻微粒子 |
| 橙色 | 橙色外发光、独立图标底纹 |
| 亮橙色 | 更强金橙发光、动态粒子、唯一轮廓 |

### 技能与装备特效密度

技能特效：

- 穿透直线流：箭轨必须细长、清楚、有起点和终点。
- 散射压制流：箭矢数量多但不能糊成一片。
- 野兽伙伴流：野兽实体和技能范围必须同时清楚。
- 区域副标签：区域边界、中心伤害点和持续时间要可读。

装备特效：

- 紫色以上装备触发特效时必须有独立颜色和图形。
- 橙色装备特效要能被玩家记住。
- 亮橙色装备特效要改变技能表现，例如双线箭、双倍箭幕、额外野兽。

## 玩家刷装动机

这套系统要让玩家有三个持续目标：

1. 推进 10 个大关卡，完成死亡契约赦免。
2. 刷精英和 Boss，获取更高稀有度装备。
3. 围绕技能流派收集特定装备，形成可感知的构筑变化。

理想体验：

- 玩家看到一个紫色词缀，就想尝试对应技能。
- 玩家拿到橙色装备后，会围绕它调整技能槽。
- 玩家刷不到亮橙色也能通过紫色/橙色搭出可玩的流派。
- 亮橙色是长期追求，不是基础通关刚需。

## 程序实现与验收清单

本节用于把设计转成实现任务，避免只落文案不落逻辑。

### 关卡刷装理由

- 关卡数据需要记录主题定位、主要掉落方向、推荐进入状态、主题威胁和 Boss。
- 传送门 / 告示牌 / 结算入口需要能读出每关主要刷装理由，不要求长文案，但要让玩家知道“这关适合刷什么”。
- 掉落权重必须能体现关卡偏向，例如第 1 关更容易出死契处刑 / 穿透基础件，第 3 关更容易出野兽伙伴件，第 10 关承担终局传承与传奇追求。
- 测试需要断言每关掉落偏向存在，但不能锁死其他流派基础装备。

### 村庄信息页文案精简

怪物图鉴、物品仓库和关卡选择需要从“说明文档式页面”收敛为“短标签 + 关键决策信息”的游戏内页面。

通用实现要求：

- 弹窗内只保留一个主标题层级，删除重复 eyebrow / title 组合。
- 默认列表不展示长段落；每张卡最多 3 行核心信息。
- 说明性内容移动到选中详情、tooltip、折叠区或详情按钮。
- 空状态统一短文案：`暂无装备`、`未装备`、`封印`、`未获得`、`无精英`。
- 按钮只保留短动词：`进入`、`穿戴`、`强化`、`分解`、`锁定`、`卸下`。

关卡选择实现要求：

- 弹窗标题建议为 `关卡` 或保留 `关卡选择`，但内部不要再出现 `传送门目标` / `选择要进入的战役` 双标题。
- 关卡卡片默认只显示：第 N 关、关卡名、Boss、主掉落、推荐状态。
- 选中详情只显示：`掉落`、`威胁`、`推荐` 三行和一个 `进入` 按钮。
- 删除“将使用该战役的主题怪物池、精英词缀、Boss 技能和掉落倾向”等解释句。

物品仓库实现要求：

- 弹窗标题用 `仓库`。
- 左侧标题用 `装备`，右侧标题用 `背包`。
- `角色装备面板`、`全部装备列表`、`核心角色属性` 等长标题改为 `装备`、`背包`、`属性`。
- 默认属性只保留核心战斗属性和当前流派关键加成；次级属性进入折叠详情。
- 装备列表 tab 只显示 `部位 + 数量`，没有装备的 tab 置灰。
- 无装备时显示 `暂无装备`。
- 不再出现任何购买武器相关旧文案。

怪物图鉴实现要求：

- 面板标题用 `图鉴` 或 `怪物图鉴`，内部标题用 `怪物`，不再叠加 `按战役/层数查看`。
- 每个战役默认只显示：第 N 关、关卡名、Boss、精英层提示、怪物预览。
- 刷装理由、推荐状态、主题威胁只在选中战役详情展示，不要在每个战役卡里铺三列长文本。
- 每层列表压缩为三列：`层`、`类型`、`怪物`。
- 怪物卡默认只显示名称、定位和短技能标签，例如 `吐息`、`冲锋`、`分裂`、`自爆`、`旋风斩`。
- 技能长描述、动画帧说明和素材说明不进入默认图鉴列表。

### 无限地图短时路线目标

- 至少实现 2-3 种可验证路线目标：蓝晶富集裂点、契约火印、遗物碎箱可以先作为第一批。
- 路线目标必须受同屏数量上限控制：1-5 层最多 1 个，6-14 层最多 2 个，15-22 层最多 3 个。
- 路线目标奖励不能超过本层基础奖励的 15%-25%，不能直接产出橙色或亮橙装备。
- 路线目标带来的额外怪物不能添加隐藏移速倍率，额外高威胁单位数量不超过当前怪潮上限的 5%-8%。
- 浏览器验收需要在第 1 / 5 / 10 关各跑一段，确认路线目标不会导致卡顿、闪烁、怪物异常高速或奖励爆炸。

### 核心大词缀

- 紫色以上装备需要区分普通数值词缀和核心大词缀。
- 每个主流派优先落地少数大词缀，而不是生成大量弱小、重复、难判断的小词条。
- 大词缀必须实际改变技能行为，例如弹道、区域、野兽指令、复苏、重叠反应，而不是只改说明文字。
- 测试需要覆盖弹道上限、区域范围上限、临时野兽数量上限、复苏 / 冷却缩短上限和等效输出护栏。

### 数值稳定性

- 后续关卡的怪物可以明显更强，但常态移速必须遵守软上限；第 9-10 关不能因为总层数或关卡编号导致普通怪异常高速。
- 爽感目标是“构筑未完成时炮灰被成片清掉、精英仍要处理；核心装备 + 核心技能搭配正确后，关键技能可以轰掉一片炮灰和一片低 / 中预算精英”。如果成型前就能一轮清空整屏，或成型后完全无视高威胁怪、高预算精英和 Boss 机制，数值都需要回调。
- 自动化测试之外，需要实际进入第 1 / 5 / 10 关，分别验证早期小爽、中期成片清怪、后期终局怪潮的节奏差异。

### 铁匠铺与武器系统调整

- 铁匠铺必须移除武器售卖入口，只保留分解、强化和后续重铸入口。
- 旧版购买武器系统需要迁移：当前装备武器转为 `weapon` 装备并穿戴；已购买未装备武器转入仓库并锁定；未购买武器不再显示为商店条目。
- 武器必须进入装备掉落池、稀有度系统、强化系统、套装系统和自动分解系统。
- Boss 掉落表必须包含本关专属传承武器；Boss 保底传承不必每次都是武器，但武器要能通过本关 Boss 复刷追求。
- 金币不再直接购买武器，改为强化、重铸、词缀保留和高稀有装备处理的手续费。
- 测试需要断言铁匠铺不出现购买武器按钮；分解和强化仍可用；武器装备可通过掉落或测试构造进入仓库；武器可触发套装件数。

### 难度阶梯与爽感验收

- 实现时需要把推荐战力、关卡强度、层数强度和怪物定位分开计算，避免单一总系数导致某些关卡突然过快或过脆。
- 低于推荐战力进入高关卡时，怪物主要表现为更硬、更疼、更会配合，而不是隐藏增加常态移速。
- 高于推荐战力回刷低关卡时，允许快速清炮灰，但精英和 Boss 必须仍保留机制窗口。
- 同战力 TTK 需要落在文档目标内：炮灰 1-2 下或主动技能成片清；主题普通怪 3-5 下；高威胁怪 1-2 个主动技能；构筑未完成时精英 2-4 轮技能循环；核心装备 + Lv.5 技能搭配正确后，关键技能可击杀一片低 / 中预算精英，但高预算精英仍需要额外处理。
- Boss 验收单独计算：成型构筑可以显著压低 Boss 血量和缩短阶段，但 Boss 技能命中仍应具备致死风险，玩家必须通过走位、预警识别和手动释放窗口取胜。
- 单层节奏需要能体现压迫、破局、收割三段：浏览器验收时至少观察第 1 / 5 / 10 关各一层，确认不是开局无成本清屏，也不是全程刮痧。

### 怪物数量、移速与补给掉率调整

- 所有非 Boss 层的总击杀目标、剩余刷怪预算和普通怪刷怪批次需要在当前实现基础上整体翻倍；Boss 层护卫仍按 Boss 机制处理。
- 同屏硬上限可按性能小幅提高，但不得因为总数量翻倍导致实体无限堆积、卡顿或遮挡关键预警。
- 怪物常态移速需要按类别提高：炮灰约 +12%-16%，普通近战约 +10%-14%，远程约 +6%-10%，重型约 +5%-8%，高速怪约 +6%-10%，精英约 +8%-12%，并继续经过软上限裁切。
- 装备掉率和蓝晶掉率必须保持单怪概率不变；测试需要断言数量翻倍没有修改装备/蓝晶基础掉率常量或额外倍率。
- 治疗药水 / 血包最终掉率需要在现有所有补给计算结果上乘以 0.5；测试需要覆盖普通血量、低血加成和精英/特殊来源下的最终掉率。
- 浏览器验收需要至少进入第 1 / 5 / 10 关各跑一层：确认怪物明显更积极、数量明显更多、药水不泛滥、装备和蓝晶掉落反馈仍清晰，且地图和技能预警不被怪潮遮挡。

### 开发者资产管理后台

- 开发环境 `测试` 入口需要升级为开发者面板入口，面板内继续保留生命无限、不攻击等测试开关。
- 正式环境必须隐藏开发者资产管理后台。
- 后台需要覆盖普通怪、精英怪、Boss 和弓箭手野兽召唤物。
- 后台可以配置待机、移动、普通攻击、施法、技能、受击、死亡，以及野兽倒地、复苏、首领化等动作槽。
- 每个动作槽需要能配置素材路径、帧尺寸、帧数、FPS、循环、左右翻转、显示缩放、图鉴预览帧和锚点。
- 需要新增统一资产 manifest 层，例如 `monsterAssetManifest` 和 `beastAssetManifest`。后续渲染、图鉴和战斗预览应优先读取 manifest，不应继续把素材路径散落在多个渲染分支里。
- 后台所有修改先进入草稿状态，保存前必须通过校验；支持回滚到上一次已保存配置。
- 校验必须覆盖缺少必填动作、帧规格不匹配、素材路径不存在、图鉴/战斗素材未同步、技能锚点缺失、四足剪影不合格、攻击锚点异常。
- 需要提供 `战斗实测预览`：玩家假人 + 当前怪物/野兽 + 锚点/攻击范围/弹体出生点显示，用于验证地狱犬吐息、骷髅挥剑、骷髅骑士冲锋和野兽指令技能。
- 后台只能改素材配置和动作映射，不能改怪物数值、技能伤害、装备词缀、掉率、经济或存档。
- 程序测试需要覆盖：开发环境入口存在、正式环境入口隐藏、动作槽配置读写、缺资源校验、锚点校验、草稿保存/回滚、怪物与野兽 manifest 均可渲染预览。
- 浏览器验收需要实际打开开发者面板，选择骷髅战士、地狱犬和至少 1 只野兽召唤物，确认 idle / move / attack / skill 预览、锚点显示和战斗实测预览都可用。

### 完整天赋系统前置验收顺序

完整天赋系统会同时碰 UI、存档、奖励和战斗效果，必须等以下四个前置阶段按顺序完成后再进入实现。

1. Boss 传承重铸 / 副属性重铸可执行闭环。
   - 两个重铸入口必须按“重铸执行规则”实现并完成程序验证。
   - `npm test -- --run`、`npm run build`、`git diff --check` 必须通过。
   - `git diff --name-status -- public/assets/monsters public/assets/village-main-menu-background.png` 必须没有输出。
   - 浏览器验收必须覆盖副属性重铸成功、副属性重铸材料不足失败、Boss 传承重铸成功、Boss 传承重铸材料不足失败、旧装备 rolls 缺失时显示 100%。
   - 本阶段不得实现锁词重铸、完整天赋树、局内天赋候选、天赋战斗效果。
2. 10 个 Boss 全流程浏览器实战验证。
   - 验收方式使用 E2E 或测试入口直接进入指定大关的第 22 层 Boss 战，不要求手动刷完前 21 层。
   - 普通难度必须逐一验证第 1 关至第 10 关全部 Boss。
   - 折磨难度必须验证第 1 关、第 5 关、第 10 关 Boss。
   - 每个 Boss 必须验证进入第 22 层、Boss 名称显示、Boss 血条显示、第一阶段技能、第二阶段技能、第三阶段技能、预警显示、范围判定、冲锋或召唤行为、护卫数量上限、玩家受伤、Boss 可被击杀、结算弹窗、传承掉落进入待领取或仓库、返回村庄、浏览器控制台无错误。
   - 每个 Boss 必须保存验收记录，字段为：大关编号、难度、Boss 名称、第 22 层进入结果、第一阶段证据、第二阶段证据、第三阶段证据、护卫或技能证据、击杀结果、掉落结果、返回村庄结果、控制台结果、截图或日志路径、验收结论、返工负责人。
   - 开发 / 测试环境必须提供专用 E2E helper：`window.__ROGUELIKE_E2E__.forceBossFight(options)`，用于浏览器直接进入指定大关第 22 层 Boss 战。该 helper 不作为正式 UI，不进入生产入口，不写入玩家正式存档，不改变玩法规则。
   - `forceBossFight(options)` 入参为：`campaignId`（第 1-10 关 ID 或编号）、`difficulty`（`normal | hard | hell | torment`，分别映射普通 / 困难 / 地狱 / 折磨）、`floor`（只能为 `22`，默认 `22`）、`playerPreset`（可选，只能为 `standard | durable | highDamage` 三种测试预设）。
   - `forceBossFight` 必须直接创建指定关卡、指定难度、第 22 层 Boss 战状态，并使用当前文档和代码已有 Boss 表、怪物表、掉落表、难度系数；不得新增 Boss 技能、不得改 Boss 数值、不得改掉落规则。
   - 进入 Boss 战后必须走真实浏览器战斗渲染、HUD、伤害、阶段切换、掉落、结算、回村流程；不得用引擎测试或直接写状态冒充浏览器全流程通过。
   - 开发 / 测试环境必须提供观测接口：`window.__ROGUELIKE_E2E__.bossSummary()`，返回大关编号、难度、当前层、Boss 名称、Boss 血量、当前阶段、最近 Boss 技能 ID、护卫数量 / 上限、玩家受伤记录、是否出现预警、是否有待领取掉落、是否进入结算、是否返回村庄、控制台错误摘要。
   - 开发 / 测试环境允许提供控制接口：`forceBossPhase('p1' | 'p2' | 'p3')` 只用于阶段验证，把 Boss 血量压到对应阶段阈值附近，不改技能表；`killBoss()` 只用于验证掉落 / 结算 / 回村链路；`dismissBossLoot()` 可沿用现有奖励流关闭待领取掉落。
   - 若浏览器自动化工具无法直接调用页面主世界 `window.__ROGUELIKE_E2E__`，开发 / 测试环境必须通过现有 `测试` 入口提供非正式 `Boss E2E` 验证面板或标签页。该面板只作为浏览器验收桥，不是正式 UI，不进入生产构建，不写入玩家正式存档，不改变玩法规则。
   - `Boss E2E` 验证面板只能调用已确认的 `forceBossFight`、`bossSummary`、`forceBossPhase`、`killBoss`、`dismissBossLoot` 接口，不得新增 Boss 技能、Boss 数值、掉落规则、怪物 AI、正式存档字段或素材。
   - `Boss E2E` 验证面板控件仅限：选择第 1-10 关、选择 `normal | hard | hell | torment` 难度、选择 `standard | durable | highDamage` 玩家预设、进入第 22 层 Boss、切换 P1 / P2 / P3、击杀 Boss、领取 / 关闭 Boss 掉落、返回村庄。
   - `Boss E2E` 验证面板必须在 DOM 中显示 `bossSummary()` 的核心字段：大关编号、难度、当前层、Boss 名称、Boss 血量、当前阶段、最近 Boss 技能 ID、护卫数量 / 上限、玩家受伤记录、是否出现预警、是否有待领取掉落、是否进入结算、是否返回村庄、控制台错误摘要。浏览器验收以这些 DOM 字段和真实渲染 / HUD / 弹窗 / 回村流程作为证据。
   - `Boss E2E` 验证面板的实现归 UI / 数据结构 / 配置线程负责；战斗内核线程只能使用该面板完成 10 个 Boss 浏览器验收，若发现战斗行为不符合已写入文档，只能按文档在战斗侧做最小修正。
   - E2E helper 分工：UI / 数据结构 / 配置线程负责暴露 helper、测试入口状态字段、结算 / 掉落 / 回村观测字段；战斗内核线程负责 Boss 战斗行为、阶段、技能、护卫、掉落消费路径验证与修正。
   - 战斗机制、数值、掉落、阶段切换、渲染读取问题归战斗内核线程修复。
   - 结算弹窗、掉落展示、返回村庄按钮、验收工具入口问题归 UI / 数据结构 / 配置线程修复。
   - 本阶段只做浏览器实战验收和缺陷返工，不新增 Boss 设计，不改 Boss 视觉素材本体。
3. 资产后台全怪物逐实体 QA / 素材缺帧清单闭环。
   - QA 范围必须覆盖普通怪、高威胁怪、精英怪、Boss、Boss 护卫、弓箭手野兽召唤物。
   - 后台必须能逐实体选择并显示每个实体的资产配置。
   - 每个实体的每个动作槽必须显示当前状态，状态只能为完整、缺帧、缺动作、待人工验收、草稿未保存、配置来源缺失。
   - 缺帧清单字段为：实体 ID、实体名称、实体类型、动作槽、当前帧数、目标帧数、配置来源、影响界面、影响程度、是否阻断完整天赋系统、返工负责人。
   - 影响界面只能填战斗渲染、图鉴预览、资产后台预览、战斗实测预览。
   - 影响程度只能填不影响流程、影响辨识、影响关键战斗、导致报错。
   - 只有三类问题阻断完整天赋系统：浏览器白屏或崩溃、Boss 或核心怪物无法辨识、素材路径缺失导致运行时报错。
   - 普通缺帧、普通动作缺失、预览美术不完整不阻断完整天赋系统，但必须保留在缺帧清单中。
   - 浏览器验收必须覆盖骷髅战士、地狱犬、骷髅精英、任意 1 个 Boss、任意 1 只弓箭手野兽召唤物。
   - 后台列表、动作槽状态、缺帧清单、草稿保存、回滚、上传交互问题归 UI / 数据结构 / 配置线程修复。
   - 战斗渲染读取 manifest、战斗预览渲染、素材 fallback 导致运行时报错问题归战斗内核线程修复。
   - 本阶段不得编辑、生成、删除怪物视觉素材本体。
4. 完整天赋系统。
   - 只有重铸闭环、10 Boss 全流程浏览器实战验证、资产后台全怪物逐实体 QA / 素材缺帧清单闭环都通过或被用户明确接受后，才能进入完整天赋系统实现。
   - 完整天赋系统实现前必须再次核对 UI、存档、奖励、战斗效果四个边界，避免两个线程同时大改同一核心文件。

## 待实现：局内经验与天赋点结算

该功能需要在 Boss 传承重铸 / 副属性重铸可执行闭环、10 个 Boss 全流程浏览器实战验证、资产后台全怪物逐实体 QA / 素材缺帧清单闭环全部完成或被用户明确接受后再进入程序实现，避免多个大任务互相抢上下文。

### 实现范围

- 蓝晶拾取仍然增加局内经验。
- 经验条满后仍然产生局内等级。
- 局内等级不再自动提升基础属性。
- 删除或禁用所有由经验升级直接增加生命、攻击、攻速、移速、技能伤害、技能冷却等基础属性的逻辑。
- 局内等级只允许推动技能选择、技能升级、职业被动 / 构筑被动或结算展示。
- 玩家通关、死亡、放弃或返回首页 / 村庄时，本局经验和本局等级清零。
- 结算时把本局累计经验、最高局内等级、到达层数、精英击杀、Boss 击杀和首通记录换算为天赋点。
- 天赋点作为局外长期资源保存。
- 天赋节点池和流派方向按上文设计预留；当前程序实现阶段暂不要求完整天赋树 UI、节点解锁消耗、前置线和逐项数值，只保留天赋点余额、获得记录和结算展示。

### 天赋点换算护栏

- 通关层数权重高于单纯经验值。
- 精英击杀和 Boss 击杀提供明显加权。
- 低层反复刷炮灰不能获得接近高层推进的收益。
- 每局天赋点存在软上限，超过后收益递减。
- 死亡局有少量收益，通关收益明显更高。
- 放弃本局收益系数低于死亡和通关。

### 程序验收

- 拾取蓝晶后经验条和局内等级仍能正常变化。
- 升级后玩家基础属性不变化；测试需要断言生命、攻击、攻速、移速、技能伤害、技能冷却不会因为经验升级自动增加。
- 升级奖励页面只展示技能 / 被动构筑相关选择，不展示基础属性加点。
- 返回首页 / 村庄后局内经验和局内等级清零。
- 死亡、通关、放弃三种结算都能生成天赋点记录。
- 天赋点余额会持久化，下一局仍保留。
- 下一局开始时局内经验和等级从 0 / 1 的初始状态开始，不继承上一局等级。
- 现有装备属性、套装属性和装备强化仍然正常影响玩家属性。
- `npm test -- --run`、`npm run build`、`git diff --check` 必须通过。
- 浏览器验收至少覆盖：第 1 关拾取蓝晶升级、进入结算、返回首页、重新开局、确认等级清零且天赋点保留。
